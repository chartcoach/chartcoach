## How to Improve

<!--
  RENAMED FROM "Repair" - More positive, growth-oriented language.
  STRUCTURED IN TIERS - Acknowledges real-world time/effort constraints.

  Provide actionable steps to fix or improve when issues are present.
  Structure these by effort and impact to help users make practical decisions.

  FOR HUMANS: This is incredibly practical. It acknowledges you might not have time for a total redesign.
              It provides options for different scenarios, showing empathy for constraints.
              The tiered structure helps you make informed trade-offs.

  FOR AI AGENTS: The agent can parse these tiers (Quick Fix, Better Fix, Best Fix) to offer appropriate
                 advice based on context. It can ask: "Are you looking for a quick change, or are you
                 open to a more thorough redesign?" and provide the corresponding tier.

  STRUCTURE:
  - **Quick Fix:** Minimal effort, immediate impact. Band-aids and workarounds that help right now.
  - **Better Fix:** Moderate effort, substantial improvement. More thorough but still practical.
  - **Best Fix:** Highest effort, optimal solution. The ideal implementation of this guideline.

  Be specific about HOW to make the change, not just WHAT to change.
  Include tool recommendations if relevant.

  Examples:
    - **Quick Fix: Add Data Labels.** If you must use a pie chart, add direct labels (e.g., "42%")
      to each slice. This lets viewers read exact values instead of comparing angles.

    - **Better Fix: Unstack Your Bars.** Switch from a stacked bar chart to a grouped bar chart.
      This puts every bar on the same baseline, making comparisons much easier.

    - **Best Fix: Use Position on a Common Scale.** Switch to a bar chart or dot plot. Position along
      a common scale is the most accurate way for people to compare quantitative values (Cleveland & McGill, 1984).
-->

- **Quick Fix:** Smallest change with biggest impact. A workaround or band-aid solution.

- **Better Fix:** More thorough improvement requiring moderate effort. Addresses root issues.

- **Best Fix:** Optimal solution. Highest effort but fully implements this guideline.
