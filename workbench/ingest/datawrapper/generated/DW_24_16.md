## Guidance

To show a temporal trend for each row in a table, embed a miniature line chart (a sparkline) instead of just showing start and end points.

## Why

A sparkline provides a compact, high-resolution view of a trend over time. It reveals volatility, seasonality, or other patterns that are completely invisible when only showing a start and end value or a simple percentage change. It enriches the table by combining the precision of numbers with the visual shape of a trend.

### Core Principle

Maximize data density by integrating small, effective graphics directly with the corresponding data.

## When it applies

- When your table has rows representing entities (e.g., companies, countries, products).
- When you have time-series data for each of those entities.
- When you want to show the 'journey' of a value, not just its destination.

## Exceptions

- If the trend is a simple, monotonic increase or decrease for all rows, a sparkline might be overkill; a simple change percentage might suffice.
- If direct comparison of magnitude between rows is the primary goal, sparklines with independent axes are the wrong choice.

## Trade-offs

- **Incomparable Magnitudes:** By default, most sparkline tools scale each chart's Y-axis to its own local min/max. This maximizes the visibility of the *shape* of the trend for each row, but it means you **cannot** visually compare the absolute values or magnitude of change between different rows' sparklines.

## Signs of Trouble

- **Lost Context:** A table shows values for "2010" and "2024" but gives no clue about what happened in between. Was it a steady rise, a dip and recovery, or a volatile path?
- **Misleading Comparison:** A user incorrectly assumes that two sparklines of the same height represent the same magnitude of change, when their Y-axes are actually scaled differently.

## How to Improve

- **Quick Fix: Add a Sparkline Column.** Add a new column to your table and insert a sparkline chart for each row, showing the trend of the key metric. Explicitly state in a note that the charts show the trend's shape but are not comparable in magnitude.
- **Moderate Approach: Add Context.** Enhance the sparkline by adding a subtle dot for the start and end points, or by highlighting the minimum and maximum values to add more information.
- **Comprehensive Approach: Use a Scaled Alternative.** If comparability of magnitude between rows is crucial, a standard sparkline is the wrong choice. Instead, switch to a visualization that uses a shared scale, such as a proper small-multiples line chart or a slope chart. If your tool allows, set a unified Y-axis for all sparklines, but be aware this may flatten and obscure the trends in some rows.
