## Guidance

Use a classed (stepped or binned) color scale when your data is inherently discrete, such as ordinal or categorical data.

## Why

An unclassed (continuous) color gradient visually implies that intermediate values exist between the steps. For ordinal data like Likert scales ("strongly disagree", "disagree", "neutral", "agree", "strongly agree") or clothing sizes ("XS", "S", "M", "L", "XL"), there are no in-between values. Using a continuous scale misrepresents the fundamental structure of the data, suggesting a level of precision and continuity that does not exist.

### Core Principle

Visual encodings should match the structure of the data. Discrete data requires a discrete visual encoding.

## When it applies

- When visualizing ordinal data where categories have a clear order but are not continuous (e.g., survey responses, ranks).
- When data has already been grouped into distinct, non-continuous bins.

## Exceptions

None known. Violating this guideline constitutes a misrepresentation of the data's nature.

## Signs of Trouble

- **False Gradients:** A color gradient is used to represent distinct ranks like "Gold," "Silver," and "Bronze," implying there's a "Gold-ish Silver" value in between.
- **Ordinal Confusion:** A continuous legend is shown for data like clothing sizes, making it unclear what color corresponds to "Medium."

## How to Improve

- **Switch to Steps:** Change the color scale from a continuous gradient to a stepped or "quantized" scale. Assign one distinct color to each category or rank.
- **Use a Categorical Palette:** If the data is categorical without an inherent order, use a qualitative (categorical) color palette instead of a sequential or diverging one.
