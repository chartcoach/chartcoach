## Guidance

When your quantitative data has a critical, meaningful center point (e.g., zero, a national average, or a baseline), use a diverging color gradient. This palette should use two distinct hues for the endpoints and a neutral, light color for the center.

## Why

A diverging palette is specifically designed to visually emphasize values on both sides of a central point. It uses one hue for values above the midpoint and a different hue for values below, with color saturation increasing towards the extremes. This immediately draws the eye to the highest and lowest values and clearly separates positive/negative or above/below-average data.

### Core Principle

The visual encoding should match the structure of the data. Use a diverging color scheme for data that diverges from a central point.

## When it applies

- Visualizing data that can be positive or negative (e.g., profit/loss, temperature change).
- Showing how regions compare to a national average (e.g., unemployment above or below the mean).
- Visualizing poll results showing support/opposition for a policy.

## Exceptions

- Do not use a diverging palette if there is no meaningful midpoint. If your data simply runs from a low to a high value (e.g., total population), a sequential palette is the appropriate choice. Using a diverging palette in this case would be confusing.

## Trade-offs

- It can be harder to compare the magnitudes of two values if they are on opposite sides of the gradient (e.g., is a light blue value greater or less than a light red value?). The primary task for a diverging map is identifying the location and sign (positive/negative) of extremes, not fine-grained comparison across the midpoint.

## Signs of Trouble

- **Arbitrary Midpoint:** A diverging palette is used on data that doesn't have a natural center, forcing the reader to wonder what the neutral color signifies.
- **Bright Center:** The center of the diverging palette is a bright, saturated color (like white or yellow), which can incorrectly draw attention to the middle values instead of the extremes. The center should be a muted, light neutral like grey.
- **Wrong Tool for the Job:** A sequential gradient is used for diverging data, hiding the critical midpoint and making it hard to distinguish positive from negative values.

## How to Improve

- **Quick Fix: Use a Pre-built Diverging Palette.** Select a palette from a trusted source like ColorBrewer (e.g., "RdBu," "BrBG," "PiYG"). These are balanced and use an appropriate neutral center. A blue-orange palette is a very safe choice that avoids red-green colorblindness issues.
- **Moderate Redesign: Set a Meaningful Center.** Ensure your charting tool is centering the gradient on the correct data value. If you're comparing to an average of 15.3%, the center of your gradient must be set to 15.3%, not an arbitrary value like 0.
- **Comprehensive Approach: Design a Balanced Palette.** If designing your own, pick two distinct hues. Ensure the lightness steps are balanced on both sides of the light, neutral center color so that a value of +X and -X have the same perceptual weight.
