## Guidance

When you have a large number of categories to display (e.g., more than 7-10), switch from a vertical stacked column chart to a horizontal stacked bar chart.

## Why

Most display media, from phone screens to printed pages, are taller than they are wide, or can be scrolled vertically. This means horizontal space is a limited resource, while vertical space is more abundant. A stacked column chart quickly runs out of horizontal space as you add more categories, leading to skinny, cramped columns and unreadable labels. A stacked bar chart uses vertical space to accommodate more categories, allowing for clear, horizontally-read labels and reasonably thick bars.

### Core Principle
Design for the constraints of the medium. Use a layout that scales effectively with the amount of data you have.

## When it applies
- When you have a high-cardinality categorical variable (many unique values).
- When designing for responsive layouts that must work on narrow mobile screens.

## Exceptions
- If the categories have a natural horizontal order that must be preserved (e.g., time), a column chart may still be preferable, but you should consider whether you have too many categories to show effectively.
- If using very thin columns is part of a specific design aesthetic (e.g., a "barcode" style chart), though this often sacrifices readability.

## Trade-offs
- A stacked column chart might feel more "standard" for certain data types like time series, so switching to a horizontal bar chart might feel less conventional to some viewers.

## Signs of Trouble
- **Skinny Columns:** The columns in your chart are so thin they look like slivers.
- **Unreadable Labels:** The category labels on the x-axis are overlapping, truncated, or rotated at an angle, making them hard to read.
- **Horizontal Scrolling:** Your chart is so wide that it requires horizontal scrolling to view, which is a poor user experience.

## How to Improve
- **Quick Fix: Reduce Categories.** If possible, group some categories together (e.g., into an "Other" group) to reduce the total number of columns.
- **Moderate Redesign: Switch to Stacked Bars.** Change the chart type to a stacked bar chart (horizontal). This is the most direct solution to the problem.
- **Comprehensive Redesign: Consider a Different Chart Type.** If you have a very large number of categories, even a stacked bar chart can become unwieldy. Consider a treemap to show composition or a table with bar charts in it (sparklines) to show the values.
