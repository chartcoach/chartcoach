## Guidance

Utilize tools specifically designed to generate color palettes for data visualization. These tools often use perceptually uniform color spaces and incorporate accessibility checks, ensuring the generated palettes are both effective and inclusive.

## Why

General-purpose color palette generators (often based on an RGB or HSL color wheel) don't account for how the human eye perceives color differences. Data-viz specific tools are built on models like LCH or Oklab, which align with human perception. They help create palettes where colors are equally distinguishable, gradients are smooth, and accessibility is considered from the start.

### Core Principle

Design tools should match the task. For data visualization, use tools that prioritize perceptual uniformity and accessibility over simple geometric relationships in a non-perceptual color space.

## When it applies

- Whenever you need to create a new, custom color palette for a chart.
- Especially critical when designing for categorical data with more than a few categories.
- When creating sequential or diverging palettes where a smooth, even gradient is important.

## Exceptions

- If you have a very simple palette (e.g., one or two colors) or are strictly bound by pre-existing brand colors, these tools might be more complex than needed, though they can still be useful for validation.

## Trade-offs

- Learning to use these tools and understanding the underlying concepts (like LCH color space) can have a learning curve.
- Palettes optimized for perceptual distance might sometimes feel less "pretty" or "intuitive" than those picked by hand, as they prioritize function over purely conventional aesthetics.

## Signs of Trouble

You've used a generic color wheel tool and the resulting palette has issues:
- **Uneven Salience:** A bright yellow category "pops" and draws undue attention, while a dark blue one recedes, creating an unintentional visual hierarchy.
- **Similar Neighbors:** Two adjacent colors on the HSL color wheel (e.g., a blue and a purple) look almost identical when applied to small marks in the chart.
- **Bumpy Gradients:** Your color ramp has "flat spots" where the color barely changes and "hot spots" where it changes abruptly.

## How to Improve

- **Quick approach:** Instead of a generic generator, use a simple data-viz focused one like ColorBrewer to pick a pre-made, validated palette.
- **Moderate approach:** Use a tool like Viz Palette or Datawrapper's palette tool to build a palette. Use its built-in colorblindness simulators and perceptual distance analysis to guide your choices.
- **Comprehensive approach:** Use an advanced tool like Colorgorical or Huetone to generate a palette by specifying your exact needs (number of colors, perceptual constraints, etc.). Manually fine-tune the output in a perceptually uniform color space (LCH/Oklab).
