## Guidance

In an interactive map, use tooltips that appear on hover or click to provide precise data values and other relevant contextual information for each region.

## Why

Choropleth maps are excellent for showing broad patterns but poor at communicating precise numerical values. A tooltip acts as a "details-on-demand" feature, solving this problem without cluttering the main visual. It allows an engaged user to look up exact numbers, see the name of the region they are hovering over, and access additional context that wouldn't fit in a static label.

### Core Principle

Follow the Visual Information-Seeking Mantra: "Overview first, zoom and filter, then details-on-demand." Tooltips are the quintessential "details-on-demand" tool.

## When it applies

-   You are creating an interactive map for the web or a screen-based medium.
-   You need to communicate both the overall pattern and the exact underlying values.
-   Your regions may be unfamiliar to your audience, so providing the region's name on hover is helpful.
-   You are using a continuous color scale, which makes it impossible to infer exact values from color alone.

## Exceptions

-   **Static Media:** This guidance is not applicable for static formats like print or a saved image (PNG/JPG), where interactivity is impossible. In those cases, you may need to add direct labels to a few key regions.
-   **Motor Control Issues:** Relying solely on hover can be problematic for users on touch devices or those with motor control impairments. Ensure that information is also accessible via clicking/tapping the region.

## Trade-offs

-   **Information Accessibility:**
    -   **Pro:** Provides a clean, uncluttered overview while making deep detail available to those who seek it.
    -   **Con:** Hides precise information from a first glance; users must interact to discover it.

## Signs of Trouble

-   **No Path to Precision:** Your interactive map shows colors, but there is no way for a user to find out the exact value a color represents.
-   **"What am I looking at?":** A user hovers over a county or small country and has no idea what it is called.
-   **Overloaded Tooltips:** Your tooltips are crammed with so much text and so many numbers that they become mini-spreadsheets, overwhelming the user.

## How to Improve

-   **Quick Fix: Enable Basic Tooltips.** At a minimum, configure your tooltips to show the region's name and its primary data value (e.g., "California: 12.5%").
-   **Moderate Redesign: Customize Tooltip Content.** Edit the tooltip to present the information clearly. Use bolding to highlight the most important number, add units (like `%` or `$`), and include a secondary piece of context if helpful.
-   **Comprehensive Approach: Thoughtful Information Hierarchy.** Design your tooltips to be a mini-dashboard for that region. Start with the most important information, but consider adding a comparison (e.g., "vs. national average") or a related data point that enriches the story for that specific region. Keep it brief and scannable.
