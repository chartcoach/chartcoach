## Guidance

When creating a series of charts within a single report, dashboard, or article, use the same color for the same category or variable consistently. Once a color is assigned to a category, do not reuse it for a different category in the same context.

## Why

Consistency builds a "visual language" for the reader. Reusing colors for different things creates confusion, undermines comparability, and increases the risk of misinterpretation. Consistent coloring reduces cognitive load, as the reader learns the color-category association once and can apply it across all related visualizations.

### Core Principle

Establish and maintain internal consistency to create a coherent narrative and reduce the cognitive burden on the audience.

## When it applies

- In any document, dashboard, or presentation containing more than one chart where the same categories appear.
- When the same entities (e.g., countries, products, political parties) are shown in multiple visualizations.

## Exceptions

- If you are only using a single highlight color in all your charts (e.g., all charts are monochrome blue with grey context), it's acceptable for that blue to represent different key variables (e.g., unemployment in one chart, GDP in another), as it's not being used to create a categorical distinction within a multi-color palette. The role of the color is "highlight," not "identity."

## Trade-offs

- Requires more planning upfront to create a master color palette for the entire report or project.
- Can be challenging if different charts have overlapping but not identical sets of categories.

## Signs of Trouble

- **Reader Confusion:** A reader assumes the blue line in chart 2 represents the same thing as the blue bar in chart 1, but it doesn't.
- **Inconsistent Narrative:** The visual story feels disjointed and requires re-learning the color key for each new chart.

## How to Improve

- **Quick Fix: Audit and Correct.** Review all charts in your document. Create a list of all unique categories and assign a unique color to each. Update the charts to match this master palette.
- **Moderate Redesign: Create a Shared Legend.** In a dashboard, use a single, global color legend that applies to all charts, making the consistency explicit and reinforcing the connections.
- **Comprehensive Approach: Systematize Colors.** Define a color palette in your design system or style guide. For example, "USA is always blue," "Germany is always orange," "Product A is always green," etc., and apply this system programmatically.
