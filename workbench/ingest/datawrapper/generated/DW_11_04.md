## Guidance

When creating or modifying color palettes, work in a perceptually uniform color space (such as LCH, Oklab, or Lab) instead of device-dependent spaces like RGB or HSL.

## Why

Color spaces like RGB and HSL do not align with human perception. A 10-degree change in HSL's "hue" can result in a massive perceptual change in one area (e.g., greens) and a tiny, unnoticeable change in another (e.g., yellows). Perceptually uniform spaces are designed so that a given numerical change in color values corresponds to a consistent perceptual change for the human eye. This makes it much easier to create palettes where colors are evenly spaced and gradients are smooth.

### Core Principle

The tools we use to manipulate color should model how we actually see color. Using perceptually uniform spaces ensures that mathematical relationships between colors translate to meaningful perceptual relationships.

## When it applies

- Any time you are designing a color palette from scratch or making significant modifications to an existing one.
- It is especially powerful for creating sequential palettes with smooth, even gradients.
- It is the most reliable method for creating categorical palettes with perceptually equidistant colors.

## Exceptions

- For very quick, simple tasks or when you're forced to use legacy tools that don't support modern color spaces, you may have to rely on RGB/HSL and extensive manual tweaking and validation.

## Trade-offs

- Working in LCH/Oklab requires using modern tools that support it and learning a new way of thinking about color (Lightness, Chroma, Hue instead of Red, Green, Blue). The concepts can be less intuitive at first.

## Signs of Trouble

- **Bumpy Gradients:** Your sequential color ramp has "flat spots" where the color barely changes and "hot spots" where it changes abruptly. This is common in HSL-based gradients that pass through pure yellow or cyan.
- **Uneven Steps:** In your categorical palette, the visual "jump" between red and orange feels much smaller than the jump between blue and purple, despite being "evenly spaced" on an HSL wheel.
- **The "Gray Dead Zone":** When creating a diverging palette in RGB, the midpoint is a muddy, unattractive gray.

## How to Improve

- **Quick approach:** Use a web-based LCH color picker to translate your existing palette into LCH values. Observe the differences in Lightness (L) and Chroma (C) to understand why it might feel perceptually uneven.
- **Moderate approach:** Use a palette generation tool that operates in LCH or Oklab. A common technique for categorical palettes is to fix the Lightness and Chroma values, then pick colors by choosing evenly spaced Hue angles (e.g., 0°, 60°, 120°).
- **Comprehensive approach:** Integrate LCH/Oklab color definitions directly into your design system or programming environment (e.g., using CSS `oklch()` functions). Build all new palettes by systematically defining L, C, and H values to achieve the desired perceptual properties.
