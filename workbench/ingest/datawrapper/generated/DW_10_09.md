## Guidance

A color gradient used to represent quantitative data must have a clear and monotonic progression from light to dark. The gradient should be perceptually uniform, meaning the steps in lightness look consistent. Do not rely on changes in hue alone.

## Why

The human visual system is much better at perceiving order from changes in lightness than from changes in hue. A gradient that works well will still show the data's pattern if converted to greyscale. Rainbow palettes are particularly bad because they have uneven changes in lightness (e.g., yellow is much lighter than both red and blue), which distorts the data, creates false boundaries, and is not accessible to colorblind users.

### Core Principle

Lightness is the most effective color channel for communicating magnitude and order. A good gradient is essentially a greyscale gradient with color added.

## When it applies

- When designing or choosing a sequential or diverging color gradient.
- For choropleth maps and heatmaps.

## Exceptions

- None. A quantitative gradient without a strong lightness component is fundamentally flawed.

## Trade-offs

- A purely lightness-based gradient (greyscale) is clear but can be less engaging. Adding one or two hues can make it more aesthetically pleasing without compromising perceptual order (see `use-multi-hue-gradients`).

## Signs of Trouble

- **The Rainbow Problem:** The chart uses a "rainbow" or "spectral" color scale (red-orange-yellow-green-blue-purple).
- **Greyscale Test Failure:** When you view the chart in greyscale (or with a colorblindness simulator), the data pattern disappears or becomes distorted because different hues have similar lightness levels.
- **False Boundaries:** The gradient creates "stripes" of color that make it seem like there are abrupt changes in the data where none exist.

## How to Improve

- **Quick Fix: Use a Pre-built, Perceptually Uniform Palette.** Don't create your own gradients unless you are an expert. Use trusted sources like ColorBrewer, CartoColors, or the defaults in tools like Datawrapper (e.g., Viridis), which have been specifically designed to be perceptually uniform.
- **Moderate Redesign: Switch from Rainbow to Sequential.** Replace the rainbow scale with a single-hue sequential scale (e.g., light blue to dark blue) or a well-designed multi-hue sequential scale (e.g., light yellow to dark green).
- **Comprehensive Approach: Use a Perceptual Color Space.** If you must design your own palette, do it in a color space like HCL (Hue-Chroma-Luminance) or L*a*b*. Create the gradient by primarily varying luminance (lightness) in a monotonic way.
