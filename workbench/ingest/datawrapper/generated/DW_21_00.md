## Guidance

Instead of relying solely on a numerical zero for the baseline of an index or relative-change chart, add a clear text label directly on the axis to explain what that baseline represents.

## Why

A number like "0" is abstract and requires interpretation. A descriptive label (e.g., "Rate in Q3 2023" or "2019 Average") provides immediate, unambiguous context. This anchors the reader's understanding of all other values on the chart, which are relative to this baseline. It reduces cognitive load and helps prevent misinterpretation.

### Core Principle

Make the reference point of a comparison explicit and easy to understand.

## When it applies

-   When using an index, a percentage change, or any other relative measure where one point in time or a specific value serves as the reference (the "zero" point).
-   This is especially crucial for general audiences or anyone who may be unfamiliar with the specific indexed data being presented.

## Exceptions

For highly specialized audiences who are extremely familiar with the specific index being used (e.g., economists looking at the Consumer Price Index), an explicit label might be considered redundant, but it rarely hurts clarity.

## Signs of Trouble

-   **Baseline Ambiguity:** Viewers ask, "What does the zero line mean?"
-   **Context Hunting:** Readers must hunt through the title, subtitle, or notes to decipher the reference point.
-   **Misinterpretation:** Viewers mistake relative values for absolute ones (e.g., thinking a value of 0 on an employment index chart means "zero employment").

## How to Improve

-   **Quick Fix:** Add an annotation pointing to the baseline with an explanatory text.
-   **Comprehensive Approach:** In your charting tool, directly replace the '0' tick mark label with a descriptive text label. Many tools, like Datawrapper, allow for custom axis labels to achieve this.
