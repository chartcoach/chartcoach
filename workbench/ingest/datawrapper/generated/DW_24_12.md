## Guidance

If a table contains data that individual readers will want to find themselves in (e.g., by location, name, or company), add interactive search and sorting capabilities.

## Why

When readers see a table that includes their hometown, their industry, or another personal identifier, their first impulse is to find their own data. Manually scanning a large table is slow and inefficient. A search field allows them to find their data instantly. Column sorting empowers them to re-rank the data based on the metric they care about most, turning a static table into a personalized analysis tool.

## When it applies

- For any interactive table (i.e., on a website or app).
- When the table contains many rows (e.g., >20).
- When the rows represent entities that users might have a personal connection to, such as locations, companies, products, or names.

## Exceptions

- For very small, simple tables, these features are overkill.
- In a static medium like print or a PDF, this is not possible.
- If a specific sort order is essential to the story being told, allowing custom sorting could undermine the narrative. You might choose to disable sorting in this case.

## Trade-offs

- Implementing these features requires more technical effort than a static table.
- A search bar and sort icons add some visual complexity to the table header.

## Signs of Trouble

- **Ctrl+F Dependency:** Users' primary method of interacting with your table is to use the browser's "Find" function.
- **"How do I rank?":** Users ask how they can see which item is best/worst according to a specific column that isn't the default sort order.
- **Information Overload:** A user is presented with a 500-row table and has no easy way to find the single row they care about.

## How to Improve

- **Quick Fix: Add Sorting.** The easiest interactive feature to add is often column sorting. Add clickable arrows to your column headers to allow users to sort the table's contents.
- **Comprehensive Approach: Add Search and Sort.** Implement both features. Place a clear search bar above the table and add sort indicators to all relevant column headers. This provides a powerful and intuitive experience for data exploration.
