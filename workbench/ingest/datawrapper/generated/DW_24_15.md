## Guidance

Use cell background color (a heatmap) to visualize the magnitude of numbers in a table, providing a space-efficient way to see patterns. Apply color scales consistently and logically.

## Why

A heatmap allows you to add a visual layer to a table without taking up extra space. By mapping value to color intensity, you make it easy to spot high and low values, clusters, and patterns across multiple rows and columns at a glance. Correctly applying color scales is crucial for this to work.

### Core Principle

Visual encodings must be consistent to allow for valid comparisons. The same color should mean the same thing within a comparable set of data.

## When it applies

- When you have one or more columns of comparable numeric data.
- When you want to show patterns and distributions across the table grid.
- When horizontal space is too limited for bar charts.

## Exceptions

- When precise value comparisons are more important than a general overview, as judging exact values from color is difficult.
- For users with color vision deficiency, the effectiveness of a heatmap is highly dependent on the choice of color palette.

## Trade-offs

- Color is less precise than position (i.e., bar length) for making quantitative comparisons.
- A poorly chosen color gradient can obscure patterns or make text unreadable.

## Signs of Trouble

- **Inconsistent Colors:** The same value (e.g., "50") is colored dark green in one column and light green in another, because each column is on a different scale. This is highly misleading.
- **Apples-to-Oranges:** Two different metrics (e.g., Temperature and Rainfall) are shown using the same blue color gradient, falsely inviting comparison between them.
- **Unreadable Text:** The background color is too dark, making the text on top of it difficult or impossible to read.

## How to Improve

- **Quick Fix: Single-Column Heatmap.** Apply a simple, single-color sequential gradient (e.g., light grey to dark grey) to your most important numeric column.
- **Comprehensive Approach: Apply Scales Logically.**
    - **For Comparable Columns:** If you have multiple columns showing the same metric (e.g., sales for 2021, 2022, 2023), apply a **single color gradient** that is scaled across all values in all those columns. This ensures that a given color represents the same value in any of the comparable columns.
    - **For Different Metrics:** If you have heatmaps for different, non-comparable metrics in the same table (e.g., Approval % and Disapproval %), use **two clearly distinct color palettes** (e.g., a blue scale for one, an orange scale for the other). This prevents readers from incorrectly comparing the two different metrics.
