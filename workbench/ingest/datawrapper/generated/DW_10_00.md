## Guidance

Prioritize visual channels like position (dot plots) or length (bar charts) when readers need to accurately compare specific quantitative values. Reserve color gradients for showing broad patterns, especially in maps.

## Why

Humans are poor at accurately judging specific quantitative values from color shades. It's difficult to map a specific color to a precise number or to accurately gauge the difference between two similar colors. Position along a common scale is the most accurate perceptual task, making it the best choice for comparisons.

### Core Principle

Visual encodings should be chosen based on the task. For precise comparison or value lookup, use more perceptually accurate encodings like position or length. For broad pattern detection, color can be effective.

## When it applies

- When the primary goal is for the audience to compare individual data points (e.g., "Which state has a higher value?").
- When showing key metrics that require precise interpretation.
- When an alternative chart type (like a bar chart or dot plot) can represent the same data without losing essential context.

## Exceptions

- When visualizing spatial patterns on a choropleth map is the primary goal. In this case, color is the most effective channel for showing geographic distribution, and the task is pattern detection, not precise value lookup.
- When space is extremely limited and a heatmap is the only viable option. Even then, consider adding values as text within the cells.

## Trade-offs

- Using a bar chart or dot plot may lose the geographic context that a map provides. A potential solution is to show a map alongside a bar chart.
- A bar chart can take up more space than a compact choropleth map.

## Signs of Trouble

- **Value Ambiguity:** It's hard to tell if two similarly-colored regions on a map have the same value or slightly different ones.
- **Legend Overload:** Viewers must constantly refer back and forth between the chart and a complex gradient legend to interpret values.

## How to Improve

- **Quick Fix: Add Labels.** If you must use a color-encoded chart like a map, add direct text labels for the most important values to provide an escape hatch for precision.
- **Moderate Redesign: Provide an Alternative Chart.** Accompany the map with a sorted bar chart of the same data. This allows for both pattern detection (on the map) and precise comparison (on the bar chart).
- **Comprehensive Redesign: Switch the Primary Chart Type.** If precise comparison is the main goal, change the visualization from a choropleth map to a bar chart or dot plot.
