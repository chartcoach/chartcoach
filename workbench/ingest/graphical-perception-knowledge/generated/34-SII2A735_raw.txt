## Guidance

When encoding multiple categories with shape in a single, potentially cluttered plot, use a combination of open shapes (e.g., +, ×, *) and closed shapes (e.g., ●, ■, ▲).

## Why

The visual system processes "openness" and "closedness" as distinct perceptual categories. Mixing them makes it easier for viewers to pre-attentively group and segment the different categories, reducing the cognitive effort needed to tell them apart, especially in dense plots.

### Core Principle

Make the most important comparisons the easiest to see. Using perceptually distinct categories for shape encoding is a powerful way to make groups pop out from one another.

## When it applies

- When using shape to encode two or more categorical variables in a single scatterplot or similar chart.
- When the plot is dense or cluttered, making discrimination difficult.
- For tasks requiring viewers to compare groups, count items (numerosity), or assess trends within categories.

## Exceptions

- In sparse plots where categories are well-separated, the benefit is minimal.
- In separate-plot displays (small multiples) where each plot contains only one category, as discrimination is not needed within a single plot.
- When brand guidelines or aesthetic constraints require using only one family of shapes (e.g., all geometric/closed).

## Trade-offs

- This may slightly limit aesthetic choices if a design system requires using only one type of shape (e.g., all geometric).

## Signs of Trouble

- **Category Confusion:** Viewers struggle to differentiate between categories marked with similar shapes (e.g., telling the circles from the squares).
- **The Squint Test:** When you squint at the chart, the different categories of points blur together into a single, undifferentiated mass.
- **Slow Interpretation:** It takes viewers a long time to answer questions about specific categories, like "Which group has more points?"

## How to Improve

- **Quick Fix: Swap a Shape.** If you are using two closed shapes (e.g., circle and square), replace one with an open shape (e.g., a plus sign). This simple change introduces the powerful open/closed perceptual cue and immediately improves discriminability.

- **Moderate Redesign: Re-evaluate Your Shape Palette.** When selecting a palette of shapes, consciously choose a mix from the "open" family and the "closed" family to maximize their perceptual distance. Don't just rely on the defaults of your charting software.

## Guidance

In a single plot with multiple categories encoded by shape, avoid using shapes that are all from the "open" family (e.g., asterisk and plus) or all from the "closed" family (e.g., circle and square).

## Why

Shapes that share a strong perceptual characteristic like "closedness" or "openness" create more interference for the visual system. It's harder for a viewer to tell them apart at a glance, which increases cognitive load and leads to slower, more error-prone interpretation.

### Core Principle

Reduce the cognitive work required to decode your visualization. Forcing viewers to distinguish between two perceptually similar shapes is an unnecessary mental step that can be easily avoided.

## When it applies

- When selecting two or more shapes to represent different categories in a single, dense visualization like a scatterplot.
- Especially for tasks like comparing counts (numerosity) or identifying trends within specific categories, where clear separation is vital.

## Exceptions

- If aesthetics or brand guidelines strictly require using a specific family of shapes (e.g., all geometric/closed). In this case, be aware of the performance cost and consider using another, stronger visual channel like color to reinforce the distinction.
- For very sparse, clearly separated data where perceptual interference is not a significant risk.

## Trade-offs

- Following this rule means you cannot create a purely "geometric" (all closed) or "symbolic" (all open) aesthetic for your chart's shapes.

## Signs of Trouble

- **Viewer Complaints:** Users report that "the circles and squares look too much alike" or they have to "stare for a while" to tell the groups apart.
- **High Error Rates:** When asked to compare the categories, users frequently make mistakes.
- **Back-and-Forth:** Viewers have to repeatedly look between the legend and the chart to confirm which shape corresponds to which category, indicating the shapes are not easily distinguishable.

## How to Improve

- **Simple Substitution:** Replace one of the shapes with an equivalent from the opposite category. For example, if using a circle and a square (both closed), change the square to a cross (open). This immediately breaks the perceptual grouping and reduces interference.

- **Add a Redundant Encoding:** If you must use same-category shapes, add a secondary visual cue like color to help distinguish them. For example, use blue circles and orange squares. Note that this does not eliminate the shape interference but can help mitigate it.

## Guidance

When a primary task involves rapidly finding or identifying individual data points, prefer using closed shapes (e.g., circle, square, triangle) over open shapes (e.g., plus, asterisk, cross).

## Why

Research suggests that the human visual system processes closed shapes more efficiently than open shapes. This results in faster reaction times and higher accuracy when viewers are trying to identify a target mark, especially in basic perceptual tasks.

## When it applies

- In dashboards or monitoring systems where rapid target detection is crucial.
- For `lookup` tasks where a user needs to find a specific data point.
- When encoding a single categorical variable with shape, where the open/closed distinction is not needed for comparison with other categories.

## Exceptions

- When using a mix of open and closed shapes is necessary to distinguish multiple categories (see guideline `mix-open-closed-shapes`). The benefit of discriminability between categories often outweighs the small speed advantage of using only closed shapes.
- When an open shape has a strong, conventional semantic meaning in the context (e.g., an 'X' to mark a location, a '+' to indicate an addition).

## Trade-offs

- Relying only on closed shapes prevents you from using the powerful open vs. closed distinction as a way to group and separate categories.

## Signs of Trouble

- **Slow Lookup:** Users take a noticeable amount of time to find data points marked with open shapes.
- **Missed Targets:** In a cluttered display, users fail to spot marks encoded with open shapes like asterisks or plus signs.

## How to Improve

- **Quick Change:** If performance is slow for a chart using asterisks, switch to circles or squares and measure if task time improves.
- **Considered Choice:** When designing a new visualization with a single shape type, default to a closed shape like a circle unless there is a specific reason to use an open one. This optimizes for faster perception from the start.
