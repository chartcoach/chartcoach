## Guidance

For tasks that require users to quickly make high-level similarity judgments between time series, consider using colorfields (also known as heatmaps or color strips) instead of more complex representations like horizon graphs.

## Why

Colorfields simplify the visual task by encoding values as color in a simple rectangular strip. This can reduce cognitive load, as the user can often perform a faster, more holistic comparison of color patterns rather than mentally tracing the complex, high-frequency paths of a line or horizon graph. This is especially true when the overall "texture" or "rhythm" of the time series is a key part of the similarity judgment.

### Core Principle

Reducing the visual complexity of a chart can speed up high-level perceptual tasks. By abstracting values into color, colorfields offload some of the cognitive work of detailed shape tracing.

## When it applies

- When speed of judgment is a key priority for the user.
- When the task involves comparing many time series at once (as in small multiples), where the space-efficiency and scannability of colorfields are advantageous.
- When the overall pattern and density are more important than precise value lookups or detailed shape analysis.

## Exceptions

- When precise value comparison or identification of specific features (e.g., the exact peak value) is required. Line charts are superior for such tasks.
- When the similarity judgment is sensitive to temporal warping (stretching/shifting). The study found colorfields were the least effective visualization for time-warping-invariant tasks.

## Trade-offs

- **Loss of Precision:** Colorfields make it difficult to read precise values or perceive fine-grained shape details compared to line charts. You trade precision for speed and density.
- **Perceptual Biases:** The choice of color map can introduce perceptual artifacts. A non-perceptually uniform color map can make equal data changes appear unequal.
- **Less Effective for Some Similarity Types:** While fast, colorfields were shown to be less effective than horizon graphs for perceiving similarity that is invariant to time-warping.

## Signs of Trouble

- **Slow Decision Making:** Users spend a long time visually tracing and re-tracing line charts or horizon graphs to make a similarity decision.
- **Visual Clutter:** A display with many line charts is visually overwhelming and difficult to scan for patterns.
- **User Fatigue:** Users report feeling fatigued or overwhelmed after comparing many complex time series visualizations.

## How to Improve

- **Quick approach: Switch to a Colorfield.** Replace an existing line chart or horizon graph view with a colorfield representation using a simple, effective color scale (e.g., a sequential scale for positive-only data or a diverging scale for data with a meaningful zero point).

- **Moderate approach: Offer a Toggle.** Provide users with a control to switch between a line chart view (for detail) and a colorfield view (for overview and speed). This allows them to use the best representation for different stages of their analysis.

- **Comprehensive approach: Use Linked Views.** Display a compact colorfield overview of many time series. When the user hovers over or selects a colorfield, display a more detailed line chart of that series in a separate, linked panel. This provides the best of both worlds: a fast, scannable overview and on-demand detail.
