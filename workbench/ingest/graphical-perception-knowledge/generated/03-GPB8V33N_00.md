## Guidance

For tasks involving identifying clusters in multivariate data, prefer Parallel Coordinates Plots (PCPs) over scatter plot matrices or raw data tables.

## Why

PCPs represent each multi-dimensional data point as a single polyline that connects axes representing different variables. Data points that are close to each other in the multi-dimensional space will have polylines that follow similar paths, forming a visually distinct "band". This makes it perceptually easier to identify groups of similar items (clusters) compared to mentally integrating information across multiple separate scatter plots or scanning a table of numbers.

### Core Principle

Make the most important comparisons the easiest to see. For multivariate clustering, the "comparison" is the overall similarity of data points across all dimensions, which a PCP visualizes as a single, coherent shape (a polyline).

## When it applies

- When your primary task is to identify groups or clusters of similar items in a dataset.
- When your data has three or more quantitative variables (i.e., is multivariate).
- When you need to compare items across all of their attributes simultaneously.

## Exceptions

- **Low Dimensionality:** For data with only two variables, a single scatter plot is more direct and effective for showing clusters.
- **Audience Unfamiliarity:** If the audience is completely unfamiliar with PCPs and there is no opportunity for explanation, the learning curve may be a barrier. A scatter plot matrix, while less effective, might be more approachable.
- **Extreme Data Scale:** With very high dimensionality (e.g., >20 axes) or a very large number of data points, visual clutter from overplotting in a PCP can obscure patterns, reducing its effectiveness without interactive features like filtering or aggregation.

## Trade-offs

- **Learnability:** PCPs are less familiar to a general audience than scatter plots and may require a brief explanation to interpret correctly.
- **Clutter:** As the number of data points increases, overplotting can obscure clusters. This often necessitates interactive features like brushing, linking, or adjusting opacity to explore the data effectively.
- **Axis Order:** The order of the axes in a PCP can significantly affect which patterns are visible. Discovering the optimal order is a non-trivial problem.

## Signs of Trouble

- **Cross-Plot Confusion:** Viewers struggle to track individual data points or groups across a matrix of different scatter plots.
- **Table Overload:** Viewers are presented with a large table of numbers and are unable to spot any patterns or groupings.
- **"Which one is it?":** Viewers repeatedly ask how to connect a point in one scatter plot to its corresponding point in another.

## How to Improve

- **Quick Fix: Enhance Scatter Plots.** If you must use a scatter plot matrix, use consistent coloring for categories and implement brushing-and-linking, where selecting a point in one plot highlights it in all other plots. This helps, but does not fully solve, the cognitive load problem.

- **Comprehensive Redesign: Switch to a Parallel Coordinates Plot.** Replace the scatter plot matrix or data table with a PCP. This directly visualizes the multivariate relationships and makes clusters more apparent as bands of similarly-pathed lines.
