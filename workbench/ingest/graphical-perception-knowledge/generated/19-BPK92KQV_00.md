## Guidance

To help viewers quickly and accurately identify the single largest change between two datasets, use an animated transition that morphs the first chart into the second.

## Why

During an animated transition, the velocity (speed) of each moving mark becomes a powerful, emergent visual cue. The mark corresponding to the largest data change will move the fastest, causing it to perceptually "pop out" and capture the viewer's attention. This offloads the cognitive work of comparing individual values and instead leverages the human visual system's innate sensitivity to motion.

### Core Principle

Make the most important comparison the easiest to see. By linking the magnitude of change directly to the perceptual salience of motion, you make the "biggest mover" task trivial.

## When it applies

-   When the primary goal is to find the single data point with the maximum delta (increase or decrease) between two states or datasets.
-   This technique is particularly effective for **bar charts** and **donut charts**.
-   When you are comparing only two datasets, as the effect may not scale to multiple simultaneous animations.

## Exceptions

-   **For judging overall similarity (correlation):** Animation is not effective for assessing the overall correlation between two datasets. In the study, it performed poorly for this task.
-   **For slope charts:** Overlaid (static) slope charts were found to be more effective than animation for the "max delta" task. The explicit line slopes in the static version already encode the change effectively.
-   **When multiple changes are large:** If many values change significantly, the resulting complex motion can be disorienting and counterproductive.
-   **For static media:** This technique is impossible in print or static image formats.

## Trade-offs

-   **Ephemeral Nature:** The insight is only available while the animation is playing, requiring user interaction (e.g., a "play" button) and focused attention.
-   **Scalability:** The perceptual benefit degrades quickly as the number of datasets increases beyond two.
-   **Potential for Disorientation:** Large, uncontrolled changes can create a chaotic visual effect that is more distracting than informative.

## Signs of Trouble

-   **Comparison Fatigue:** Viewers report having to manually scan and compare values between two static charts to find the biggest difference.
-   **Missed Insights:** Viewers fail to notice the most significant change when presented with side-by-side or stacked charts.
-   **Ineffective Animation:** An animation is used for a correlation task, leading to confusion as viewers try to track multiple movements without a clear perceptual anchor.

## How to Improve

-   **Minimal Change: Add a "Highlight Difference" Feature.** If using static charts, add an interactive element that explicitly calculates and highlights the largest difference on demand. This provides the answer without relying on perception alone.

-   **Moderate Change: Switch to an Overlaid Layout.** If animation is not feasible, change from a side-by-side layout to an overlaid (superposed) chart. This co-locates the data points and was found to be the best static alternative for this task.

-   **Comprehensive Redesign: Implement Animated Transitions.** For screen-based media, replace the static comparison with an animated transition between the two states. Ensure the animation timing (e.g., 1.5 seconds) is brief enough to be perceived as a single event. Use cubic easing to make the maximum velocity more pronounced.
