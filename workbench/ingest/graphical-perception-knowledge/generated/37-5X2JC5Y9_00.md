## Guidance

When encoding different categories of points in a scatterplot for a mean comparison task, use a salient visual channel like color (hue or luminance) instead of a less salient one like shape.

## Why

Humans can select and process groups of objects based on color more efficiently and accurately than based on shape. This pre-attentive ability to "filter" by color allows for a more rapid and reliable estimation of a group's average position, even in a cluttered display. Shape is a less "salient" cue, meaning it requires more cognitive effort to group and process, leading to lower performance on aggregation tasks.

### Core Principle

Visual cues vary in their salience, or their ability to support rapid attentional selection. More salient cues like color lead to better performance in aggregation tasks because they make the initial perceptual grouping step easier and more accurate.

## When it applies

- When viewers need to compare the average value of two or more categories presented within a single scatterplot (e.g., "which group is higher on average?").
- When you have multiple visual channels available (e.g., color, shape, size) and need to decide which to use for encoding categorical data.

## Exceptions

- If color is already used to encode a different, more important variable.
- When designing for an audience with known color vision deficiencies and a color-blind safe palette cannot be used. In this scenario, relying on shape is a necessary, though less effective, alternative. Always best to use both if accessibility is a primary concern.

## Trade-offs

- Using color for categories means it cannot be used to encode a continuous quantitative variable (e.g., via a sequential color map).
- Over-reliance on color without providing a redundant channel (like shape or labels) can create accessibility barriers for users with color vision deficiencies.

## Signs of Trouble

- **The Squint Test:** If you squint at the chart, is it difficult to distinguish the different groups of points? If they blur together, your chosen encoding may not be salient enough.
- **Slow Grouping:** Viewers take a long time to determine which points belong to which category before they can even start comparing the averages.
- **Shape Ambiguity:** It's difficult to quickly tell the difference between the shapes being used (e.g., squares vs. slightly rounded squares).

## How to Improve

- **Quick Fix: Increase Shape Contrast.** If you must use shapes, ensure they are highly distinct and easy to tell apart (e.g., circles vs. plus-signs, not circles vs. squares).
- **Comprehensive Redesign: Switch to Color.** Recode the categories using a perceptually distinct and accessible color palette (e.g., from tools like ColorBrewer or Viz Palette). This will leverage the visual system's superior ability to group items by color.
