## Guidance

To show how multiple variables correlate across a geographic area at a specific moment, arrange the data as small-multiple maps. This layout juxtaposes all spatial information for that single time slice.

## Why

Small multiples bring all relevant spatial information for a single moment into a compact, comparable view, reducing cognitive load. Viewers can focus on comparing locations within one view instead of mentally filtering and re-assembling data from multiple time-series glyphs scattered across a single map. This leads to faster and more accurate interpretation.

### Core Principle

Make the most important comparisons the easiest to see. When the task is spatial comparison, the visualization's structure should prioritize the juxtaposition of space.

## When it applies

- When the primary task is to understand the spatial pattern or correlation of variables at **one specific moment in time** (e.g., "How did sales and marketing spend correlate across all states in Q4?").
- When comparing multiple variables across a geographic area for a single time slice.

## Exceptions

- If there is only one or a very small number of locations to compare, a single view might be sufficient, and the overhead of setting up small multiples may be unnecessary.

## Trade-offs

- **Screen Space:** Small multiples inherently use more screen space than a single map.
- **Temporal Blindness:** This layout is less effective for showing temporal trends, as the viewer must scan across different, spatially separated maps to perceive change over time.

## Signs of Trouble

- **Slow Search:** Viewers take a long time to answer questions about a specific time point because they have to scan through many time-series glyphs (e.g., mini bar charts) on a single map.
- **High Error Rate:** Viewers make frequent mistakes when asked to describe the spatial pattern at one moment, suggesting they are struggling to assemble a complete mental picture.
- **User Frustration:** Users complain that it's "too hard" or "takes too long" to compare all the locations for a single year.

## How to Improve

- **Moderate Redesign: Switch to Small Multiples.** Re-structure the visualization from a single map with temporal glyphs to a series of small-multiple maps. Each small map can represent a time point, allowing easy spatial comparison within each.

- **Quick Fix: Add Highlighting.** If you must use a single map with time-series glyphs, implement interactive highlighting. Allow the user to select a single time point (e.g., by hovering over a legend) which then emphasizes that point across all location glyphs, fading out the non-selected times.
