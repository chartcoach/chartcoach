## Guidance

When creating small-multiple maps to show changes over time or across variables, use a consistent, stable base map in each multiple. Encode thematic data using symbols (like proportional circles or color) overlaid on the map, rather than by distorting the map's geometry (as in a cartogram).

## Why

A stable base map provides a consistent spatial frame of reference. This makes it trivial for viewers to locate and track the same geographic feature across different multiples. Cartograms, which change the shape and position of features in each map, force the viewer to re-find the location of interest in every panel. This increases cognitive load and makes comparisons slower and more error-prone.

### Core Principle

Reduce the cognitive work required to decode a visualization. Every unnecessary matching or re-identification step is a chance for error and slows down comprehension.

## When it applies

- When creating any small-multiple visualization where the viewer needs to compare the same location(s) across different maps.
- This is especially critical for tasks involving many small or irregularly shaped geographic units.

## Exceptions

- If the primary goal of each map is to emphasize the magnitude of the variable used for the cartogram's distortion, and comparison *across* multiples is a secondary task. For example, if you want to powerfully communicate population distribution in different decades, and seeing the trend is less important than feeling the distribution.

## Trade-offs

- **Occlusion:** Using symbols on a map can lead to occlusion, where symbols overlap and obscure each other, especially in dense areas (e.g., the Northeastern US). Cartograms can sometimes mitigate this by enlarging dense areas, but at the cost of geographic accuracy and comparability.
- **Perceptual Bias:** Encoding a key variable with symbol area on a standard map can introduce its own perceptual biases, though it avoids the re-identification problem of cartograms.

## Signs of Trouble

- **"Where's Waldo?":** Viewers struggle to find the same state or region in different panels of a small-multiple cartogram layout.
- **Mis-matching:** Viewers mistakenly compare two different locations because they have trouble tracking a single location across the shifting layouts.
- **Slow Comparisons:** Tasks that require comparing one location across multiple panels are unexpectedly slow.

## How to Improve

- **Moderate Redesign: Switch to a Stable Base Map.** Instead of using a cartogram where geography distorts, use a standard geographic base map. Encode the variable that was used for the cartogram's distortion with a different visual channel, such as the size or color of a symbol placed on the map.

- **Quick Fix: Add Persistent Labels.** If you must use a cartogram, ensure every geographic feature has a clear, persistent, and easily findable label (e.g., a state abbreviation) in every multiple. This adds clutter but provides a necessary crutch for re-identification.
