## Guidance

When encoding nominal (unordered categorical) data, use visual channels that are easily distinguishable but do not imply a quantitative order. The most effective channels, from most to least effective, are:

1.  **Position** (e.g., separating categories on an axis)
2.  **Color Hue** (e.g., blue, green, orange)
3.  **Texture**
4.  **Shape**
5.  **Length / Area / Saturation** (Avoid these, as they imply order)

## Why

Nominal data consists of unordered categories (e.g., 'Apple', 'Orange', 'Banana'). An effective visualization should make it easy to tell these categories apart without accidentally suggesting that one is "more" or "higher" than another. Channels like color hue and shape are easily differentiable without creating a ranking. In contrast, channels like length (bar charts) or area (bubble charts) are strongly perceived as representing quantity, creating a misleading order where none exists.

### Core Principle

**The Expressiveness Principle:** A visualization should express all the information in the data, and *only* the information in the data. Using a visual channel that implies order (like length) to encode data that has no order (nominal categories) violates this principle.

## When it applies

-   When choosing colors, shapes, or other visual marks to distinguish between unordered categories.
-   When deciding between a bar chart and a dot plot for a categorical axis.
-   When creating a legend for a chart with nominal data.

## Exceptions

-   If the categories have a conventional, though not strictly numerical, order (e.g., alphabetical), using position is acceptable and often helpful for lookup tasks.
-   When there is a single category, length or area is fine as there are no other categories to create a misleading comparison with.

## Trade-offs

-   **Number of Categories:** Color hue is very effective, but the number of easily distinguishable hues is limited (typically 5-8). For categories beyond this number, you may need to combine hue with another channel like shape, or choose a different chart type.
-   **Legibility:** While a dot plot is more "correct" than a bar chart for a nominal axis, audiences may be more familiar with bar charts. You might trade theoretical correctness for audience familiarity.

## Signs of Trouble

-   **Implicit Ranking:** A chart appears to rank categories that have no inherent order (e.g., a bar chart of "Sales by Department" seems to imply that the departments themselves are ranked).
-   **Ordered Colors for Unordered Data:** A sequential color palette (e.g., light green to dark green) is used to represent distinct categories like 'North', 'South', 'East', 'West'.
-   **Size Implies Importance:** Different categories are represented by circles of different sizes, suggesting some are more "important" or have a higher value that is not in the data.

## How to Improve

-   **Quick Fix: Change the Channel.** If you are using a perceptually ordered channel like color saturation or size to represent nominal categories, switch to a qualitative channel like color hue or shape.

-   **Moderate Redesign: Switch from Bar Chart to Dot Plot.** If you are using a bar chart with a nominal category axis, convert it to a dot plot. This removes the misleading length encoding while retaining the accurate position encoding for the quantitative value.

-   **Comprehensive Redesign: Use a Faceted Display (Small Multiples).** If you have many categories, instead of trying to encode them all with color or shape in a single chart, break the data into a series of small, consistent charts, one for each category. This uses position (the most effective channel) to separate the categories.
