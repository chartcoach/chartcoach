## Guidance

When comparing values between two series in a grouped bar chart, superimpose an explicit visual mark (e.g., a line or dot) that encodes the difference between the two bars in each group.

## Why

A standard grouped bar chart requires viewers to mentally estimate the height of two bars and then calculate the difference. This is cognitively demanding, slow, and error-prone, especially for identifying the *largest* or *smallest* change across many categories. By adding a "difference overlay," the task of judging the difference is transformed from a mental calculation into a direct perceptual task of comparing the position or length of the overlay marks. This leads to faster, more accurate comparisons and is highly preferred by users because it provides both the original values (the bars) and the change (the overlay) in a single view.

## When it applies

- When using a grouped bar chart to compare values between two series (e.g., this year vs. last year).
- When the key tasks include identifying the category with the maximum change, measuring the difference for a specific category, or getting a quick sense of the magnitude of changes.

## Exceptions

- When comparing more than two series, as multiple difference overlays can become visually cluttered and confusing.
- If the sole task is to show the difference and the original values are unimportant, a dedicated "difference chart" (showing only the differences) might be simpler. However, users often lose valuable context with this approach.

## Trade-offs

- **Visual Clutter:** Adding overlays introduces more ink to the chart, which can slightly increase visual complexity. However, for two series, this trade-off is generally worthwhile for the large gain in performance and clarity.
- **Design Familiarity:** This pattern is less common than a standard grouped bar chart, so it may require a brief moment of orientation for a first-time viewer.

## Signs of Trouble

- **Mental Math:** Viewers are scanning back and forth between two bars in a group, trying to subtract one from the other.
- **Slow Comparisons:** It takes a long time for a viewer to answer "Which category had the biggest increase?"
- **Inaccurate Judgments:** Viewers incorrectly identify the category with the largest or smallest difference.
- **Loss of Context:** A chart shows only the differences (e.g., a difference chart) but viewers keep asking "What were the original sales numbers?"

## How to Improve

- **Quick Fix: Annotate Key Differences.** If you cannot alter the chart type, manually add annotations (e.g., a text box with "+\$5K") to the one or two most important categories to highlight their change.

- **Moderate Redesign: Implement a Difference Overlay.** Modify your grouped bar chart to add the overlay. For each category, draw a line or symbol that visually represents the difference. The position of the overlay should clearly indicate the direction of the change (e.g., an overlay above a bar for an increase, below for a decrease).

- **Comprehensive Approach: Provide Interactive Overlays.** In an interactive dashboard, allow users to toggle the difference overlays on and off. This keeps the default view simple while providing the powerful comparison tool on demand. Brushing over an overlay could reveal a tooltip with the exact difference and original values.
