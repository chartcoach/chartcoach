## Guidance

In scatterplots with a high number of data points (e.g., thousands or more), avoid plotting every point as an individual, opaque mark. Instead, use aggregation techniques (like binning or density estimation) or representative sampling to reveal the underlying data distribution and density.

## Why

When too many points are plotted in a small area, they overlap, a problem called "overplotting" or "overdraw." This obscures the true density of the data, hides clusters and patterns, and can make a dense region look the same as a sparse one. Individual points lose their identity, and the visualization becomes a misleading "ink blob."

## When it applies

- When creating a scatterplot where the number of data points is large relative to the available screen space, leading to significant point overlap.
- When the primary task is to understand the distribution, density, or clustering of the data, rather than inspecting every single point.

## Exceptions

- If the primary task is to identify and interact with every single data point, and you have powerful interactive tools like zooming and panning, plotting all points might be necessary. However, an aggregated overview should still be provided as the initial, default view.
- For datasets with low point density where overplotting is not an issue.

## Trade-offs

- Aggregation techniques sacrifice the ability to see and interact with individual data points in favor of showing the overall distribution. You lose granular detail to gain a clearer high-level summary.
- Sampling shows individual points but only a subset of them, which risks misrepresenting the full dataset if not done carefully.

## Signs of Trouble

- **"Ink Blobs":** Large areas of the chart are solid blocks of color where individual points are indistinguishable.
- **Hidden Density:** A region with 10,000 points looks identical to a region with only 1,000 points, masking the true density.
- **Lost Outliers:** Outliers located near dense regions are completely covered by other points and become invisible.
- **Performance Lag:** The visualization is slow and unresponsive because it is trying to render too many individual marks.

## How to Improve

- **Quick Fix: Reduce Opacity.** Reduce the opacity (alpha) of the points. This allows overlapping points to create darker areas, giving a rough, qualitative sense of density. This is a simple first step but becomes less effective with extreme overdraw.

- **Moderate Approach: Use 2D Binning.** Group the data into a grid of rectangular or hexagonal bins. Use a color scale to encode the number of points in each bin, effectively creating a heatmap-like overview of the scatterplot space.

- **Comprehensive Approach: Use Density Estimation.** Use a continuous kernel density estimation (KDE) to create a contour plot or a density-based representation like a Splatterplot. This provides a smoother, often more accurate view of the data distribution and can be combined with techniques to show outliers that fall outside the dense regions.
