## Guidance

To enable the most accurate perception of quantitative data, encode values using position along a common, aligned scale. Position is perceptually superior to length, angle, area, and color.

## Why

Humans are far more accurate at judging and comparing positions on a shared scale than they are at judging other visual attributes. Jock Mackinlay's foundational 1986 model ranks visual encodings by their perceptual accuracy for different data types. For quantitative data, the ranking is:
1.  **Position** (most accurate)
2.  Length
3.  Angle / Slope
4.  Area
5.  Color Saturation / Lightness
6.  Color Hue (least accurate)

Choosing a more effective encoding, like position, reduces interpretation error and helps the audience understand the data more truthfully.

## When it applies

- When the primary goal is for users to accurately compare, rank, or look up quantitative values.
- When designing common charts like bar charts, line charts, dot plots, and scatter plots, which rely on the position channel.

## Exceptions

- **Geographic Data:** When visualizing data on a map, position is already used to encode location. Other channels like color (for choropleths) or size (for bubble maps) must be used for the quantitative values.
- **High-Level Overview:** When the goal is to show a general "sense" of scale or composition rather than precise comparison (e.g., in a treemap), using a less accurate channel like area may be acceptable.

## Trade-offs

- Using position to encode multiple variables often requires more screen space (e.g., faceting into small multiples) compared to encoding secondary variables with color or size on a single chart.

## Signs of Trouble

- **Inaccurate Comparisons:** Viewers struggle to state with confidence which value is larger when the data is encoded using bubble size or pie slice angle.
- **Reliance on Tooltips:** The chart is nearly unreadable without hovering over every mark to see the exact value in a tooltip, indicating the visual encoding itself is failing.
- **Encoding Mismatch:** The most important quantitative comparison in a chart relies on a less effective channel (like color), while a less important variable occupies the primary x- or y-axis.

## How to Improve

- **Moderate Redesign: Switch Chart Type.** If you are using a pie chart, bubble chart, or treemap for precise comparisons, switch to a bar chart or dot plot. This remaps the quantitative data from a weaker channel (angle, area) to the strongest one (position).
- **Comprehensive Redesign: Re-evaluate Encodings.** Review all variables in your chart. Ensure the variable that requires the most accurate interpretation is encoded using position. Demote less critical variables to other channels like color or shape.
