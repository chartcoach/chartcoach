## Guidance

Do not use visual channels that imply magnitude or order, such as area, size, or color saturation/lightness, to represent distinct, unordered (nominal) categories.

## Why

Area (the size of a shape) and color saturation (the intensity from gray to a pure hue) are perceived as ordered quantities. A larger shape is interpreted as "more" than a smaller one; a more saturated color is seen as "stronger" or "higher value" than a less saturated one. Using these channels for nominal data, which has no inherent order, creates a false and misleading visual hierarchy. This violates the fundamental "expressiveness principle" of visualization: the visual representation should only express the properties of the data, and not create new, unsupported ones.

## When it applies

- When encoding nominal data (unordered categories), such as `Country`, `Department`, or `Product Type`.
- When choosing between using color hue, shape, or size to differentiate categories.

## Exceptions

- **Highlighting:** You can legitimately use size or saturation to draw attention to a specific category of interest, but this should be a conscious choice for emphasis, not the primary encoding for all categories.
- **Composite Glyphs:** In complex visualizations, size might be used to encode a *second, quantitative* variable associated with a category (e.g., on a map, use color hue for the country and the size of the dot for its population). In this case, size is correctly encoding quantitative data, not the nominal category itself.

## Trade-offs

- Using shape as an alternative can also have issues. Some shapes are more visually salient than others, and using too many different shapes becomes a "key-value" lookup problem that is cognitively demanding.

## Signs of Trouble

- **Misleading Magnitude:** A bar chart uses different shades of the same color (a sequential scheme) to represent different continents. This makes it appear as if one continent is "higher" or "lower" than another on some imaginary scale.
- **False Ranking with Size:** A visualization uses differently sized circles to represent different political parties. This incorrectly implies that parties with larger circles are more "important" or have "more" of some unstated quantity.
- **Bubble Grid for Categories:** A chart shows categories as a grid of bubbles of different sizes. This is an incorrect application of a bubble chart, which should use size to encode a quantitative value.

## How to Improve

- **Quick Fix: Switch to Hue.** If you are using saturation (shades of one color), replace the palette with a categorical one using distinct hues (e.g., blue, green, orange).
- **Moderate Redesign: Switch to Shape.** If you are using size, change the encoding to use different shapes (e.g., circles, squares, triangles) of the *same size*. This is effective for a small number of categories.
- **Comprehensive Approach: Use a Combination.** For a larger number of categories, consider a multi-channel approach. For example, use a few distinct hues for major groups, and then different shapes within those color groups for subgroups. Ensure that neither the hues nor the shapes imply an unintended order.
