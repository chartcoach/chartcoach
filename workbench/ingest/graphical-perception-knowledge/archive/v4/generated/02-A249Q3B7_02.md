## Guidance

When analyzing correlations over a *time interval* (not a single point or all time), the optimal visualization strategy depends on the spatial scope. There is a trade-off between juxtaposing space (small multiples) and juxtaposing time (single map with glyphs).

## Why

The most efficient design is the one that minimizes the amount of information a user needs to visually scan and collate. If the task involves few locations, it's better to group time data together. If it involves many locations, it's better to group spatial data together.

## When it applies

- When the task involves analyzing a subset of time steps and a subset of locations (e.g., "What was the correlation in the West from 2003-2006?").
- **For a few spatial locations:** Use a single map with time-series glyphs. The user only needs to check a few glyphs, and the relevant time interval is easy to find within each.
- **For many spatial locations:** Use small multiples. The user has to check multiple maps (but only a subset of them), and identifying the many locations on each is easier than checking many complex glyphs.

## Exceptions

- The study found inconclusive results for tasks involving a medium number of locations (a "region"). The performance trade-off is balanced, and no single technique was clearly superior. In this "middle ground," other factors like user preference or familiarity may be more important.

## Trade-offs

- A static visualization cannot easily adapt to a user's changing analytical focus. An optimal layout for analyzing a few locations will be inefficient for analyzing many, and vice versa.
- Implementing an adaptive interface that switches layouts based on user interaction requires more development effort.

## Signs of Trouble

- **Task-Layout Mismatch:** A user is analyzing a single state's trend over a few years but has to scan across multiple small-multiple maps to do so.
- **Inverse Mismatch:** A user is analyzing a pattern across the entire country for a few years but has to decode dozens of complex bar-chart glyphs on a single map.
- **User Frustration:** Users express that the information they need is "scattered all over the place."

## How to Improve

- **Minimal Approach: Add Guidance.** Instruct users on the most efficient way to read the current chart for their task (e.g., "To see the trend for Texas, focus only on its bar chart and ignore other states").
- **Moderate Approach: Offer Both Views.** In an interactive setting, provide a toggle that allows users to switch between a small multiples view (juxtaposing space) and a single-map glyph view (juxtaposing time).
- **Comprehensive Approach: Use an Adaptive Visualization.** Build an interactive system that detects the user's focus (e.g., through selection or filtering). If the user filters to a few locations, the system could automatically switch to a single-map glyph view. If they filter to a few time steps, it could switch to a small multiples view.
