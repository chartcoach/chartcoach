## Guidance

When the primary task is to help a user understand the relationship or correlation between two quantitative variables, the most effective visualization is a scatter plot.

## Why

A scatter plot directly maps the two variables to the x and y axes, encoding each data point's values as a position. This allows the human visual system to pre-attentively perceive patterns in the distribution of points, such as linear trends, clusters, and outliers, which are the hallmarks of correlation. Empirical studies have confirmed that viewers can judge the strength of a correlation more accurately from a scatter plot than from other visualizations like parallel coordinates.

## When it applies

- When you want to see if two numerical variables are related (e.g., "Is there a relationship between a person's height and weight?").
- When you are looking for clusters, outliers, or non-linear relationships in bivariate data.
- When choosing between a scatter plot and a dual-axis line chart or parallel coordinates for showing a relationship.

## Exceptions

- **Multiple Variables (>2):** If the goal is to see correlations across *many* variables simultaneously, a scatter plot matrix (multiple small scatter plots) or a parallel coordinates plot can be used. However, be aware that judging the correlation between any two variables in a parallel coordinates plot is less accurate than in a dedicated scatter plot.
- **Time-Series Data:** If one of the variables is time, a line chart is the standard and most effective convention. If you are comparing two time-series variables, plotting them on the same line chart (with a single, shared y-axis if possible) is appropriate.

## Signs of Trouble

- **Dual-Axis Line Chart:** Using a line chart with two different y-axes to imply a correlation is highly misleading and should be avoided. The perceived relationship can be manipulated arbitrarily by changing the scale of either axis.
- **Separate Charts:** Presenting two separate bar or line charts and asking the viewer to mentally compare them to find a correlation is cognitively demanding and ineffective.
- **Overplotting:** In a scatter plot with a very large number of data points, the points can plot on top of each other, obscuring the density and true distribution. This is known as overplotting.

## How to Improve

- **Quick Fix (for overplotting): Reduce Opacity.** If you have overplotting, reduce the opacity of the points. This allows areas with high density to appear darker, revealing the underlying distribution.
- **Moderate Redesign: Switch to a Scatter Plot.** If you are using a dual-axis chart or two separate charts, combine the data into a single, correctly-scaled scatter plot.
- **Comprehensive Approach (for overplotting): Use Aggregation.** For very dense scatter plots, use techniques to address overplotting directly. This can include:
    - **Binning:** Group the points into 2D bins and use color to show the density in each bin (creating a 2D histogram or heatmap).
    - **Contour Lines:** Show the density of points using contour lines, similar to a topographical map.
    - **Sampling:** Plot only a random sample of the data points if the overall trend is more important than individual points.
