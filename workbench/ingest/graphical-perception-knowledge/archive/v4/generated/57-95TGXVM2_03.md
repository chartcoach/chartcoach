## Guidance

When using a difference overlay to compare two series, explicitly encode the original values for *both* series (e.g., with a grouped bar chart) rather than showing only one series and forcing viewers to mentally calculate the other.

## Why

Showing only one series' value as a bar and asking viewers to mentally add or subtract the difference overlay to find the second series' value is highly confusing and error-prone. This design imposes a significant cognitive load, especially for tasks like finding the minimum or maximum value of the non-explicitly shown series. People are much more accurate and confident when both original values are directly represented (e.g., as two bars side-by-side), with the difference overlay serving as a helpful supplement rather than a necessary component for calculation.

## When it applies

- Any time a difference overlay is used to compare two series.
- When it is important for the user to be able to accurately perceive or look up values from *both* of the original series, not just one of them.

## Exceptions

- If the value of the second series is truly unimportant and never needs to be read or compared, showing only one bar with an overlay might save space. However, this is a risky assumption, as users often need more context than designers anticipate.

## Trade-offs

- **Space:** A grouped bar chart showing both series takes up more horizontal space than a single bar chart.
- **Simplicity:** A single bar chart might appear simpler at first glance, but this simplicity is deceptive and comes at the cost of high cognitive load and potential for error.

## Signs of Trouble

- **Calculation Errors:** Viewers are making mistakes when asked about the values of the series that isn't directly shown as a bar. For example, they report the difference value instead of the calculated series value.
- **User Confusion:** Viewers express confusion, saying things like "It's hard to imagine the previous year's value" or "I have to stop and do math to figure it out."
- **Task Avoidance:** When given a chart with only one bar and an overlay, users struggle or give up on tasks related to the second (unseen) series.

## How to Improve

- **Quick Fix: Add Redundant Labels.** On a chart with a single bar and an overlay, add text labels for the values of *both* series. This reduces the need for mental math, though it doesn't fix the underlying flawed visual representation.

- **Moderate Redesign: Switch to a Grouped Bar Chart with Overlay.** Change the chart type from a single bar chart with an overlay to a grouped bar chart with an overlay. This directly represents both original values, making all comparison tasks easier and more accurate.

- **Comprehensive Approach: Re-evaluate the Core Task.** If space is the primary constraint preventing the use of a grouped bar chart, reconsider if another chart type is more appropriate. For example, if comparing many categories is the goal, a dot plot with lines connecting the two series' values for each category could be a space-efficient and clear alternative.
