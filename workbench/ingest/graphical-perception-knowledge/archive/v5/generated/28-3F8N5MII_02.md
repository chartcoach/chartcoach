## Guidance

To represent quantitative data for comparison or ranking tasks, encode the values using position along a common scale. Use color as a secondary, redundant encoding or for categorical data.

## Why

Human perception is far more accurate at judging differences in position and length than it is at judging differences in color saturation or hue. When values are encoded as bar lengths, point positions on an axis, or line heights, viewers can make quick and precise comparisons. When the same values are encoded only with color, these comparisons become slow, inaccurate estimations.

### Core Principle

Match the visual encoding channel to its perceptual effectiveness for the task. For quantitative comparisons, position is the most effective channel.

## When it applies

- When the primary goal is for the viewer to accurately compare, rank, or look up quantitative values.
- This applies to a wide range of charts, including bar charts, line charts, and scatter plots, which are all based on the position channel.

## Exceptions

- **Showing Geographic Patterns:** In a choropleth map, color is the only feasible channel to fill geographic regions. The primary goal is to show spatial patterns, not enable precise value comparisons. The trade-off is sacrificing comparison accuracy for spatial context.
- **Limited Space/Overview:** In a heatmap, color is used to provide a dense overview of a large matrix of values where using position (e.g., a grid of bar charts) would be impractical.
- **Highlighting:** Color can be very effective for drawing attention to specific categories or values (e.g., coloring one bar red to highlight it) even if position is encoding the primary value.

## Trade-offs

- Using position often requires more space than using color. A single choropleth map can represent data for 50 states, while a bar chart of the same data would require significantly more screen real estate.
- An over-reliance on position-based charts can lead to a lack of visual variety.

## Signs of Trouble

- **"Is this darker blue twice as much as the lighter blue?":** Viewers are unable to accurately judge the magnitude of difference between colored regions.
- **Dense, colorful maps without clear patterns:** A choropleth map is used, but the task is to rank the top 5 regions by value—a task for which the color encoding is ill-suited.
- **A bar chart where every bar is a different color:** This is a sign of redundant encoding. If the colors don't represent a meaningful category, they are just chartjunk that can increase cognitive load.

## How to Improve

- **Quick Fix: Add Labels.** If you must use a color-encoded chart like a choropleth map for comparisons, add direct data labels to the most important regions. This provides a "perceptual escape hatch" by allowing users to read the values directly.
- **Moderate Approach: Provide a Position-based Alternative.** Accompany a choropleth map with a bar chart that ranks the same data. This gives the user both the spatial context (from the map) and the ability to make precise comparisons (from the bar chart).
- **Comprehensive Approach: Switch the Chart Type.** If the primary task is comparison, not spatial analysis, change the chart type. Instead of a choropleth map of state-by-state sales, use a bar chart. This directly encodes the quantitative data using the most effective visual channel for the task.
