## Guidance

When the primary task is for users to look up a specific data value (e.g., "When Product A's sales were $500, what was Product B's?"), a simple data table is more effective than a scatter plot or a parallel coordinates plot.

## Why

Visual representations like scatter plots and parallel coordinates plots introduce perceptual and cognitive overhead for simple lookup tasks. Tracing lines (PCP) or locating corresponding points across multiple plots (scatter plot matrix) is slower than a direct row/column scan in a table. The supporting study found tables were significantly faster for this task.

### Core Principle

The most effective representation is the one that minimizes the cognitive steps required for the primary task. For simple value retrieval, direct reading from a table is more efficient than visual decoding from a chart.

## When it applies

- When the user's main goal is to find a specific value given another.
- For datasets with a relatively low number of data points and dimensions (e.g., the study used 8 points, 4 dimensions) where scanning a table is feasible.

## Exceptions

- When lookup is a secondary task and the primary task is pattern-finding (e.g., identifying correlation, clusters, or outliers). In these cases, a visual representation is superior overall.
- For very large datasets where a table would require extensive scrolling, making a visual search within it inefficient.

## Trade-offs

- Using a table sacrifices the ability to see emergent patterns like clusters, outliers, or correlations at a glance. It optimizes for specific value lookup at the expense of broader discovery.

## Signs of Trouble

- **Slow Lookups:** Users take a long time to find specific values in your scatter plot or parallel coordinates plot.
- **User Frustration:** Users express that "just showing the data" would be easier for the specific task of finding a value.
- **Inaccurate Reading:** Users misidentify points or lines when trying to trace them back to their exact values.

## How to Improve

- **Quick approach: Provide a table.** Alongside your visualization, provide access to the raw data in a searchable or sortable table. This gives users the best of both worlds.
- **Moderate approach: Add interactive lookup.** Implement hover/tooltip functionality on your visualization that displays all values for a given data point, enabling quick retrieval without leaving the visual context.
- **Comprehensive approach: Re-evaluate the primary task.** If the most common user action is value lookup, consider if a visualization is the right primary interface, or if it should be a supplement to a data table.

## Guidance

To help users identify clusters of similar data points in multivariate data, use a parallel coordinates plot (PCP) or a scatter plot matrix. Both are significantly more effective than presenting the data in a table.

## Why

Visual representations make cluster patterns emerge from the data. In a PCP, clustered data points appear as bundles of lines following similar paths. In a scatter plot matrix, clusters appear as dense groups of points. Trying to spot these patterns by reading numbers in a table is cognitively demanding and highly inaccurate.

### Core Principle

Human visual perception is excellent at identifying spatial proximity and grouping (Gestalt principles). Effective visualizations leverage this ability to make abstract data patterns, like clusters, physically visible.

## When it applies

- When the task is to find groups of data points that have similar values across multiple variables.
- When working with multivariate datasets that are not so high-dimensional as to cause extreme visual clutter.

## Exceptions

- If the dataset is extremely high-dimensional, both standard PCPs (clutter) and scatter plot matrices (too many plots) can become ineffective without additional interaction techniques like filtering, brushing, or axis reordering.

## Trade-offs

- Visualizations for clustering sacrifice the precision of a data table for the benefit of pattern discovery. It's harder to read exact values but far easier to see the overall structure.
- PCPs can be less intuitive for novice users compared to the more familiar scatter plot.

## Signs of Trouble

- **Hidden Clusters:** Users are unable to identify obvious groupings in the data when it's presented in a table.
- **Analysis Paralysis:** Users are overwhelmed trying to compare numbers across many rows and columns to find similarities.
- **Misinterpreted Patterns:** With a scatter plot matrix, users may miss a cluster that is only visible when considering three or more dimensions simultaneously.

## How to Improve

- **Moderate approach: Switch from a table to a scatter plot matrix.** This is often more familiar to a general audience and effectively reveals clusters in pairwise comparisons of variables.
- **Comprehensive approach: Use a parallel coordinates plot.** PCPs can reveal complex, high-dimensional relationships that might not be visible in any single pair of scatter plots. For best results, pair it with interactive brushing to highlight clusters.

## Guidance

When the task is to identify outliers (anomalous data points) in a multivariate dataset, a parallel coordinates plot (PCP) is the most effective choice. It outperforms both scatter plot matrices and data tables in accuracy and speed.

## Why

Outliers manifest visually in a PCP as lines that follow a path distinctly different from the main bundle of lines, making them "pop out" visually. In a scatter plot matrix, an outlier might only be apparent in one or two of the plots, making it harder to spot and confirm its anomalous nature across all dimensions.

### Core Principle

Anomalies are defined by their deviation from a pattern. Visualizations that make the dominant pattern clear (like the bundle of lines in a PCP) also make deviations from that pattern highly conspicuous.

## When it applies

- When the goal is to find data points that are abnormal or behave differently from the rest of the dataset across multiple variables.
- For tasks like data cleaning, fraud detection, or identifying exceptional cases.

## Exceptions

- The order of axes in a PCP heavily influences which patterns are visible. An outlier might be hidden if the relevant axes are far apart. Interactive reordering of axes is often necessary to fully leverage a PCP for outlier detection.
- With very large datasets, PCPs can suffer from overplotting (clutter) which can obscure both patterns and outliers.

## Trade-offs

- While powerful, PCPs can be less intuitive to novice users than scatter plots. Their effectiveness is also sensitive to axis ordering.
- Mitigating clutter in a dense PCP often requires advanced interaction techniques (e.g., brushing, filtering, transparency), which adds implementation complexity.

## Signs of Trouble

- **Missed Anomalies:** Important outliers in the data are going unnoticed by users.
- **False Positives:** When using a scatter plot matrix, users struggle to distinguish true multivariate outliers from points that are only extreme on a single dimension.
- **Pattern Obscurity:** Users cannot identify which data points deviate from the norm.

## How to Improve

- **Moderate approach: Switch to a scatter plot matrix.** While less effective than a PCP according to the study, it is still vastly better than a data table and may be more intuitive for your audience. Highlight points consistently across all plots to help users track potential outliers.
- **Comprehensive approach: Implement an interactive parallel coordinates plot.** For robust outlier detection, this is the superior method. Allow users to reorder axes and brush/highlight lines to isolate and examine potential outliers from different perspectives.

## Guidance

To compare the amount of change for multiple items across a sequence of time points or stages, use a parallel coordinates plot where each axis represents a time point. This is more effective than using a scatter plot matrix or a data table.

## Why

In a parallel coordinates plot configured for temporal data, the slope of the line segments directly encodes the rate of change between time points. A line with many steep segments represents an item with high volatility or large changes. This visual summary is much easier and faster to interpret than comparing disparate points in a scatter plot matrix or mentally calculating differences between numbers in a table.

### Core Principle

Encode the task-critical attribute directly in the visualization. For detecting change, the slope of a line is a direct and powerful visual encoding of the rate of change.

## When it applies

- When you have measurements for multiple items at several discrete time points or stages (e.g., sales for 5 products across 4 quarters).
- When the primary task is to identify which items are the most volatile, or have the largest cumulative change. This design is effectively a line chart with categorical axes representing time.

## Exceptions

- If you have many time points, a standard line chart (with time on the x-axis and one line per item) is a more conventional and often clearer representation, especially for seeing long-term trends. A PCP is best for a small number of discrete stages.
- If you have many items, the PCP will become cluttered with overlapping lines, making it hard to discern individual profiles.

## Trade-offs

- Using a PCP for temporal data treats time as categorical axes, which can be less intuitive than a standard line chart's continuous time axis. It prioritizes comparing change magnitudes between stages over seeing the continuous flow of time.

## Signs of Trouble

- **Change Blindness:** Users cannot easily spot which item's values are fluctuating the most when looking at a table or series of scatter plots.
- **Manual Calculation:** Users resort to mentally subtracting values or using a calculator to determine the magnitude of changes.
- **Difficult Comparisons:** Users find it hard to compare the "change profiles" of two different items.

## How to Improve

- **Moderate approach: Use a standard multi-series line chart.** If the number of time points is moderate to high, a line chart with time on the x-axis and a colored line for each item is a very effective and familiar alternative.
- **Comprehensive approach: Use an interactive parallel coordinates plot.** For a small number of key stages or time points, the PCP provides a powerful, direct comparison of change profiles. Combine with interactive highlighting to let users select and trace individual items through the stages.
