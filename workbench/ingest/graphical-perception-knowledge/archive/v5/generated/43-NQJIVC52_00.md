## Guidance

Do not assume a single, universal ranking of visual channels (e.g., that position is always better than length, which is always better than angle). The effectiveness of an encoding is highly dependent on the viewer's task, the number of data points, and the specific performance goal (e.g., minimizing bias vs. maximizing precision).

## Why

Classic rankings are based on the narrow task of judging the ratio between two values. Research shows these rankings break down in more realistic scenarios that involve remembering and comparing multiple values. The "best" channel for judging two values is often not the best for recalling or comparing eight values, as memory limitations and data context become the dominant factors.

### Core Principle

The effectiveness of a visual encoding is context-dependent, not universal.

## When it applies

- When choosing a chart type or visual encoding for any task that involves more than a simple, direct comparison of two values. This applies to nearly all practical data visualizations where viewers need to see patterns, find outliers, or remember information.

## Exceptions

- For the specific, narrow task of judging the ratio between two *adjacent* values that share a common baseline (as in a simple bar chart), the classic rankings (position > length > angle) generally hold.

## Signs of Trouble

- **Dogmatic Design:** A chart is chosen based on a generic "best practice" rule (e.g., "never use bubble charts") without considering if it's a good fit for the specific data volume, user task, or communication goal.
- **Poor Performance on Complex Charts:** A chart type that works well for simple data becomes difficult to read when more data is added, suggesting the initial design choice was based on a rule that didn't scale.

## How to Improve

- **Quick Fix: Question the Default.** If a chart chosen by a standard "rule of thumb" feels hard to read, consider if the encoding is mismatched for the number of data points or the primary task. For example, if a bar chart with 20 bars is hard to summarize, see if a heatmap (luminance) makes patterns clearer.
- **Moderate Redesign: Test Alternatives.** Create alternative versions of the chart using different encodings and informally test which one makes it easiest to answer key questions about the data.
- **Comprehensive Redesign: Optimize for the Goal.** Explicitly decide whether your primary goal is to minimize systematic error (bias), improve consistency (precision), or reduce overall error. Choose the visual channel that best supports that specific goal for your given data volume (e.g., position/length for low bias; area for high precision).
