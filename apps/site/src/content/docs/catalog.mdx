A ChartCoach catalog bundle contains `MANIFEST.md` and `catalog.parquet`. The manifest defines this catalog instance's section roles and label families. The parquet table stores guideline records.

The site, Python package, and JavaScript package load the same bundle.

## Guideline Records

Each entry combines:

- a **title** and **description** for the design move,
- **labels** for catalog-owned label families such as chart type, task, audience, and design lever,
- **sections** for advice, rationale, context, caveats, checks, and fixes,
- **references** for the source material.

## Manifest

`MANIFEST.md` must define these headings:

- `Section Roles`
- `Label Families`

Each section role and label family is a level-3 subheading under the matching required heading. Loaders validate that every section role and label family used by `catalog.parquet` is defined in the manifest.
