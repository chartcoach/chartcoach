A ChartCoach guideline records advice, fit conditions, failure modes, references, and source evidence.

Those files are the catalog. The site, Python package, and JavaScript package all read from them.

## Guideline Records

Each entry combines:

- a **title** and **description** for the design move,
- **labels** for chart types, tasks, audiences, and design levers,
- **sections** for advice, rationale, context, caveats, checks, and fixes,
- **references** for the source material.

## Section Roles

Most records use the same section roles:

- **advice**: what to do
- **reason**: why it helps
- **context**: where it applies
- **exceptions**: when the rule should not be used
- **costs**: what the design gives up
- **mistakes**: common failure modes
- **check**: what to inspect during review
- **fix**: how to repair the chart

Separating these roles lets readers compare two records by task, audience, caveat, or tradeoff.

## References

Inline citations point to the bibliography on each guideline page. Use them to check a recommendation, compare sources, or keep reading.
