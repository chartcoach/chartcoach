---
title: CLI Reference
description: Command groups and output contracts for the chartcoach command-line interface.
---

The `chartcoach` CLI is part of the Python package. It reads catalog artifacts, emits deterministic rows, and forwards Chroma calls to the native collection API.

```bash
uv run --package chartcoach chartcoach --help
```

## prompt

`chartcoach prompt --codex|--claude|--opencode [--source PATH] [--index-dir DIR] [--guidance-mode create|feedback|explore|debug] [--task TEXT]`

Print an agent startup prompt that references the installed ChartCoach skill, catalog source, optional semantic index, and task.

```bash
npx skills add chartcoach/catalog
codex "$(uvx chartcoach@latest prompt --codex --source guidelines)"
```

The prompt has no filesystem side effects. It does not validate the catalog or build a search index. It tells the agent to use `MANIFEST.md` for catalog-specific role and label semantics, retrieve targeted guideline evidence, and include guideline ids plus public links when guidelines constrain or justify the answer.

## Global Source

Most commands accept:

`--source PATH`

Catalog source path. Use a catalog artifact bundle directory for manifest validation. Direct parquet files remain available for table-only workflows.

## artifacts

`chartcoach artifacts --source PATH --format table|json|jsonl|csv`

List native files that other tools can open directly: manifest, source catalog, generated DuckDB path, and Chroma index paths when search extras are available.

## catalog

`chartcoach catalog build --source FOLDER --out DIR`

Build a catalog artifact bundle from an authored guideline folder. The output directory contains `MANIFEST.md` and `catalog.parquet`.

`chartcoach catalog check --source FOLDER --format table|json|jsonl|csv`

Validate a guideline folder against `MANIFEST.md` and report table counts.

`chartcoach catalog manifest --source PATH --format markdown|json|jsonl`

Print the catalog manifest or list its section roles and label families.

`chartcoach catalog duckdb --source PATH --out PATH [--overwrite]`

Write derived catalog tables into a DuckDB database file.

## sql

`chartcoach sql --source PATH QUERY [--limit N] [--format table|json|jsonl|csv]`

Run one SELECT query over the catalog DuckDB tables with external file access disabled. `--limit` bounds the returned rows.

## tables

`chartcoach tables list --source PATH --format table|json|jsonl|csv`

List queryable structured tables.

`chartcoach tables schema --source PATH [--table TABLE]... --format table|json|jsonl|csv`

List table columns and data types.

`chartcoach tables values TABLE COLUMN --source PATH [--explode] [--contains TEXT] [--limit N] [--format table|json|jsonl|csv]`

Count distinct values. Pass `--explode` for list-valued columns such as labels.

## guidelines

`chartcoach guidelines list --source PATH [--label VALUE] [--label-prefix PREFIX] [--contains TEXT] [--limit N] [--format table|json|jsonl|csv]`

List guideline ids and summaries.

`chartcoach guidelines show --source PATH GUIDELINE_ID --format markdown|json|jsonl`

Print one guideline.

`chartcoach guidelines retrieve --source PATH [--id ID] [--label VALUE] [--label-prefix PREFIX] [--contains TEXT] [--section ROLE] [--limit N] [--format markdown|json|jsonl|csv|table]`

Return deterministic evidence packets with optional section filtering.

`chartcoach guidelines search --source PATH --index-dir DIR [--where JSON] [--where-document JSON] QUERY [--format table|json|jsonl|csv|markdown]`

Run catalog-level semantic search over an existing Chroma index and return deduplicated guideline rows.

## index

`chartcoach index status --source PATH --index-dir DIR --format table|json|jsonl|csv`

Report the content-addressed Chroma path, collection name, embedding name, readiness, and document count.

`chartcoach index build --source PATH --index-dir DIR`

Create the content-addressed Chroma index if it is missing.

`chartcoach index rebuild --source PATH --index-dir DIR --yes`

Rebuild the Chroma index for the current catalog digest.

`chartcoach index query --source PATH --index-dir DIR PARAMS_JSON --format json|jsonl`

Run `collection.query(**PARAMS_JSON)` against the native Chroma collection.

`chartcoach index get --source PATH --index-dir DIR [PARAMS_JSON] --format json|jsonl`

Run `collection.get(**PARAMS_JSON)` against the native Chroma collection.

## Output Formats

`table`

Terminal table.

`json`

Single JSON object or array.

`jsonl`

One JSON record per line. Use this for shell pipelines and token-controlled agent calls.

`csv`

Comma-separated rows with a header. List-valued cells are JSON-encoded.

`markdown`

Evidence text for guideline-content commands.

## Search State

Read commands do not create Chroma state. Build the index explicitly with `chartcoach index build`, then use `index query`, `index get`, or `guidelines search` against that existing artifact.
