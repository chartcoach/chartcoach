The MCP server exposes deterministic catalog tools and optional Chroma-backed tools from the Python package.

```bash
chartcoach mcp serve --source guidelines/catalog.parquet
```

Pass `--index-dir` when tools need an existing Chroma index.

```bash
chartcoach mcp serve \
  --source guidelines/catalog.parquet \
  --index-dir "$CHARTCOACH_INDEX_DIR"
```

## Runtime Options

`--transport stdio|sse|streamable-http`

MCP transport. Defaults to `stdio`.

`--host HOST`

Host for HTTP transports. Defaults to `127.0.0.1`.

`--port PORT`

Port for HTTP transports. Defaults to `8000`.

`--log-level DEBUG|INFO|WARNING|ERROR|CRITICAL`

Server log level. Defaults to `INFO`.

## Catalog Tools

`catalog_artifacts`

Return native catalog artifact paths and suggested open commands.

`tables_list`

List queryable structured catalog tables.

`tables_schema`

Return column schemas for catalog tables.

`tables_values`

Count distinct values in a table column.

`sql_query`

Run one read-only SELECT query over the DuckDB catalog tables with external file access disabled. The response contains `columns`, `rows`, `row_count`, `truncated`, `limit`, and `catalog_digest`.

`guidelines_list`

List guideline ids and summaries with deterministic label and text filters.

`guidelines_get`

Return one complete guideline record by id.

`guidelines_retrieve`

Return guideline records with optional label, text, and section-role filters.

## Search Tools

`guidelines_search`

Run semantic search and return deduplicated guideline-level rows. Requires `--index-dir` and `chartcoach[search]`.

`chroma_query`

Run `collection.query(**params)` with direct Chroma parameters.

`chroma_get`

Run `collection.get(**params)` with direct Chroma parameters.

## Agent Contract

Use deterministic catalog tools first when exact ids, labels, sections, or table values are known. Use `sql_query` when the workflow needs joins across guidelines, sections, labels, and references. Use `guidelines_search`, `chroma_query`, or `chroma_get` only when semantic matching or native Chroma inspection is needed.

Agents that need their own SQL client can call `catalog_artifacts` and open the DuckDB artifact directly.
