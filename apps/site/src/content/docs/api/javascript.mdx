title: JavaScript and TypeScript API
description: Load ChartCoach catalog records from server runtimes, browsers, and raw parquet bytes.
---

`@chartcoach/catalog` exposes a small typed model plus one loader per runtime.

```ts
import { readCatalog } from "@chartcoach/catalog/server";

const catalog = await readCatalog("guidelines");

for (const guideline of catalog) {
  console.log(guideline.id, guideline.title);
}
```

## Entry Points

`@chartcoach/catalog`

Shared types, the `Catalog` model, `loadCatalog` for parquet bytes, `parseLabel`, `parseManifest`, and `toMarkdown`.

`@chartcoach/catalog/server`

`readCatalog(sourcePath, options?)` for server-side filesystem paths.

`@chartcoach/catalog/browser`

`fetchCatalog(catalogUrl, options?)` for browser and fetch-capable runtimes.

## Catalog

`new Catalog(guidelines = [], options?)`

Create a catalog from loaded guideline records. When `options.manifest` is provided, the constructor validates section-role and label-family coverage.

```ts
import { Catalog, parseManifest } from "@chartcoach/catalog";

const manifest = parseManifest(manifestMarkdown);
const catalog = new Catalog(guidelines, { manifest });
```

`catalog.guidelines`

Readonly array of `Guideline` records.

`catalog.length`

Number of guidelines.

`catalog.size`

Number of guidelines.

`catalog.manifest`

Parsed manifest when the catalog was loaded with manifest coverage.

`catalog.get(id)`

Return a guideline by id, or `undefined`.

`catalog.require(id)`

Return a guideline by id. Throws `CatalogError` when the id is absent.

`catalog.labels()`

Return sorted distinct label strings.

`catalog.sectionRoles()`

Return sorted distinct section role strings.

`for (const guideline of catalog)`

Iterate through guidelines in catalog order.

## Guideline

```ts
type Guideline = {
  id: string;
  title: string;
  bibliography?: string;
  description: string;
  labels: readonly string[];
  body: string;
  sections: readonly GuidelineSection[];
  references: readonly string[];
};
```

`references` contains BibTeX entries split into individual `@...` records.

## GuidelineSection

```ts
type GuidelineSection = {
  role: string;
  title: string;
  content: string;
};
```

Section roles are catalog-owned strings. `MANIFEST.md` defines the role values for each catalog instance.

## Server Loading

`readCatalog(sourcePath, options?)`

Read a catalog from a server-side filesystem path. Directories with `catalog.parquet` are treated as catalog bundles. Directories without `catalog.parquet` are treated as authored folders. Files are treated as parquet catalogs.

```ts
import { readCatalog } from "@chartcoach/catalog/server";

const bundle = await readCatalog("guidelines");
const authored = await readCatalog("guidelines-source");
const parquet = await readCatalog("guidelines/catalog.parquet", {
  manifest: "guidelines/MANIFEST.md",
});
```

`options.manifest`

Parsed `CatalogManifest`, or a manifest path. Bundle and authored-folder reads use `MANIFEST.md` beside the source when omitted.

## Browser Loading

`fetchCatalog(catalogUrl, options?)`

Fetch and decode a parquet catalog.

```ts
import { fetchCatalog } from "@chartcoach/catalog/browser";

const catalog = await fetchCatalog("/catalog.parquet", {
  manifest: "/MANIFEST.md",
});
```

`options.manifest`

Parsed `CatalogManifest`, manifest URL, or manifest path string. When provided as a string or URL, the loader fetches it and validates the catalog.

`options.request`

`RequestInit` passed to both manifest and parquet fetches.

## Raw Parquet Bytes

`loadCatalog(file, options?)`

Decode a parquet catalog from an `ArrayBuffer`, `ArrayBufferView`, or async buffer object.

```ts
import { loadCatalog, parseManifest } from "@chartcoach/catalog";

const manifest = parseManifest(manifestMarkdown);
const catalog = await loadCatalog(bytes, { manifest });
```

Typed array inputs are copied to the exact view range before decoding. This avoids reading unrelated bytes from a larger backing buffer.

## Labels

`parseLabel(value, context?)`

Parse `family:category` or `family:category:modifier`.

```ts
import { parseLabel } from "@chartcoach/catalog";

parseLabel("task:compare:average");
// { value: "task:compare:average", family: "task", category: "compare", modifier: "average" }
```

The parser trims surrounding whitespace from the label and each segment, preserves internal whitespace and case, and rejects empty segments.

## Manifests

`parseManifest(markdown)`

Parse required `Section Roles` and `Label Families` headings from `MANIFEST.md`.

```ts
import { parseManifest } from "@chartcoach/catalog";

const manifest = parseManifest(markdown);
manifest.sectionRoles.advice.description;
```

## Markdown

`toMarkdown(guideline)`

Serialize one loaded guideline record back to authored Markdown.

## Errors

`CatalogError`

Thrown for invalid labels, manifests, duplicate ids, missing ids, invalid markdown records, and invalid parquet rows.
