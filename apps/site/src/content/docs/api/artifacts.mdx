---
title: Artifacts
description: Native catalog files produced and consumed by ChartCoach packages.
---

ChartCoach keeps generated artifacts in native formats. Package APIs return typed records. Direct file access works for tools that already read Markdown, parquet, DuckDB, or Chroma.

## Catalog Bundle

`guidelines/MANIFEST.md`

Catalog manifest that defines section roles and label families.

`guidelines/catalog.parquet`

Serialized catalog table.

```python
from chartcoach import Catalog

catalog = Catalog.from_bundle("guidelines")
```

```ts
import { readCatalog } from "@chartcoach/catalog/server";

const catalog = await readCatalog("guidelines");
```

## Catalog Parquet

`guidelines/catalog.parquet`

Serialized catalog table. Python reads it with `Catalog.from_parquet(path)`. JavaScript reads local files with `readCatalog(path)`, browser URLs with `fetchCatalog(url)`, and raw bytes with `loadCatalog(bytes)`.

```python
from chartcoach import Catalog

catalog = Catalog.from_parquet("guidelines/catalog.parquet")
```

```ts
import { readCatalog } from "@chartcoach/catalog/server";

const catalog = await readCatalog("guidelines/catalog.parquet");
```

## Authored Folder

`guidelines/<entry>/guideline.md`

Markdown source record.

`guidelines/<entry>/references.bib`

BibTeX references for that record.

Use the folder layout for authoring and review. `Catalog.from_folder` and `readCatalog("guidelines")` require `MANIFEST.md` beside the entry directories.

## DuckDB

Generated DuckDB artifacts contain derived tables such as `guidelines`, `sections`, `labels`, `guideline_labels`, `references`, `guideline_references`, and `guideline_sources`.

```python
from chartcoach.duckdb import connect_catalog, write_duckdb
from chartcoach.paths import default_duckdb_path

conn = connect_catalog(catalog)
conn.sql("select id, title from guidelines limit 5").pl()
conn.close()

write_duckdb(catalog, default_duckdb_path(), overwrite=True)
```

The default path comes from `platformdirs` through `default_duckdb_path()`.

## Chroma

Chroma indexes are content-addressed by catalog digest, document-version string, embedding identity, and collection name.

```python
from chartcoach.paths import default_index_dir
from chartcoach.search import ChromaIndex

paths = ChromaIndex.cache_paths(catalog, cache_dir=default_index_dir())
paths.chroma_path
```

The native collection name defaults to `catalog`. Use `index.collection` when caller code needs Chroma's own `query` or `get` API.

## Default Directories

`default_cache_dir(*parts)`

Platform-native ChartCoach cache directory.

`default_artifact_dir()`

Default directory for generated catalog artifacts.

`default_duckdb_path()`

Default DuckDB artifact path.

`default_index_dir()`

Default root for generated Chroma search indexes.

Default paths resolve through platform-native cache directories.
