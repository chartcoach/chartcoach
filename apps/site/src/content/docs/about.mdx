title: About
description: What Chart Coach is building and why.
---

Chart Coach is a structured, citable catalog of visualization design guidance.

The goal is to represent design knowledge in a way that is:

- readable by humans,
- usable by machines (retrieval + reasoning),
- context-aware and linkable,
- traceable to sources.

If you're evaluating retrieval strategies (or building tools that give chart feedback), the catalog is meant to be an inspection-friendly ground truth: each guideline has labeled facets, a consistent section structure, and explicit references.
