# ChartCoach brand alternatives

Three coherent brand families generated for review.

## Families

- **Bracket Window** — citation brackets framing a chart window
- **Catalog Tab** — archival tabbed-card/catalog motif
- **Margin Callout** — plotted point + annotation note motif

## Files

For each family:

- `*-emblem.png` — square seed emblem
- `*-favicon.png` — 512×512 favicon-style icon
- `*-header-logo.png` — compact horizontal header lockup
- `*-project-logo.png` — larger project logo lockup

See `brand-alternatives-contact-sheet.png` for side-by-side comparison.

Prompts used are stored in `.omx/artifacts/brand-prompts/`.
