# Start with the Guideline Catalog

Open the Guideline Catalog, filter by one label family, and inspect a Guideline Instance. The record keeps the recommendation, context, checks, citations, and BibTeX together.

<a href="/guidelines/">Open the Guideline Catalog</a>

## 1. Choose a label family

Use a broad family when you are still framing the design problem:

```text
chart
task
audience
problem
```

Use an exact label when you already know the chart or task:

```text
chart:bar
task:compare
```

The catalog count updates as filters are added, and matching records stay visible in the browser.

## 2. Open a Guideline Instance

A Guideline Instance separates advice from context, exceptions, mistakes, checks, and fixes. Follow the inline citations when the recommendation depends on source material.

## 3. Move to technical docs when needed

Use the dedicated docs site for package APIs, CLI commands, catalog files, DuckDB or LanceDB queries, and MCP tools.

<a href={docsUrl}>Open technical docs</a>
