# @chartcoach/site

Astro site for the chartcoach Guideline Catalog browser and public guideline
pages. The published site is [chartcoach.dev](https://chartcoach.dev/).

Run it locally:

```bash
pnpm --dir apps/site dev
```

Build static pages:

```bash
pnpm --dir apps/site build
```

Run lint and build checks from the repository root:

```bash
pnpm --dir apps/site lint
pnpm --dir apps/site build
```
