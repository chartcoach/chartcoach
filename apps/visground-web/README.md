# @chartcoach/visground-web

Standalone Vite app that hosts the VisGround viewer against a parquet artifact.

Place the viewer artifact at `apps/visground-web/public/data/viewer.parquet`.

Run the app with `pnpm --dir apps/visground-web dev`.

Build it with `pnpm --dir apps/visground-web build`.
