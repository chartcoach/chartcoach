---
title: Catalog Structure
description: What a ChartCoach catalog bundle contains.
---

A ChartCoach catalog bundle contains `MANIFEST.md` and `catalog.parquet`. The manifest defines one catalog instance's section roles and label families. The parquet table stores Guideline Instance records.

```text
guidelines/
  MANIFEST.md
  catalog.parquet
  <guideline-id>/
    guideline.md
    references.bib
```

## Guideline Records

Each record contains:

- `id`, `title`, and `description` for the recommendation.
- `labels` for catalog-owned metadata.
- `sections` for role-annotated guidance.
- `references` for BibTeX source entries.

## Manifest

`MANIFEST.md` must define `Section Roles` and `Label Families`. Each section role and label family is a level-3 subheading under the matching heading. Loaders validate that the manifest covers roles and label families used by `catalog.parquet`.

## Artifact Bundle

Use a bundle directory when callers need manifest validation. Use a direct parquet file only for table workflows that already know the catalog vocabulary.
