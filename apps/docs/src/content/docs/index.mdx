ChartCoach represents a Guideline Catalog as source records with labels, role-annotated sections, and source references. The package APIs, CLI, and MCP server read the same catalog bundle.

```bash
uv add chartcoach
pnpm add @chartcoach/catalog
```

Use the marketing site for browsing: <a href={siteUrl}>{siteUrl}</a>.

## Technical Entry Points

- [Catalog structure](/catalog/) defines the bundle and record model.
- [API reference](/api/) covers Python, JavaScript, browser loading, CLI, and MCP.
- [Labels and filters](/labels/) describes label syntax and matching behavior.

## Package Boundary

The catalog is source data. Derived DuckDB tables, LanceDB indexes, and browser pages are views over the same Guideline Instance records.
