---
title: Catalog Records
description: Source record shape shared by ChartCoach package APIs.
---

The public catalog record is `Guideline`. Loaders return the same flat fields whether the source is an authored folder or a generated parquet artifact.

```ts
type Guideline = {
  id: string;
  title: string;
  bibliography?: string;
  description: string;
  labels: readonly string[];
  body: string;
  sections: readonly GuidelineSection[];
  references: readonly string[];
};
```

## Guideline

`id`

Stable guideline id.

`title`

Short action-oriented title.

`description`

One-sentence summary used by listing and retrieval surfaces.

`labels`

Catalog-owned metadata labels. Label semantics live in `MANIFEST.md`.

`body`

Full markdown body.

`sections`

Role-tagged section records parsed from the body.

`references`

BibTeX entries associated with the guideline.

## GuidelineSection

```ts
type GuidelineSection = {
  role: string;
  title: string;
  content: string;
};
```

`role`

Catalog-owned section role such as `advice`, `reason`, `context`, `exceptions`, `check`, or `fix`.

`title`

Section heading.

`content`

Section markdown content.
