---
title: CLI Reference
description: Command groups and output contracts for the chartcoach command-line interface.
---

The `chartcoach` CLI is part of the Python package. It reads catalog artifacts, emits deterministic rows, writes DuckDB tables, and queries the LanceDB search index.

```bash
uv run --package chartcoach chartcoach --help
```

## prompt

`chartcoach prompt --codex|--claude|--opencode [--source PATH] [--index-dir DIR] [--guidance-mode create|feedback|explore|debug] [--task TEXT]`

Print an agent startup prompt that references the installed ChartCoach skill, catalog source, optional LanceDB full-text index, and task.

```bash
npx skills add chartcoach/catalog
codex "$(uvx chartcoach@latest prompt --codex --source guidelines)"
```

The prompt has no filesystem side effects. It tells the agent to use `MANIFEST.md` for catalog-specific role and label semantics, retrieve targeted guideline evidence, and include guideline ids plus public links when guidelines constrain an answer.

## catalog

`chartcoach catalog build --source FOLDER --out DIR`

Build a catalog artifact bundle from an authored guideline folder.

`chartcoach catalog check --source FOLDER --format table|json|jsonl|csv`

Validate a guideline folder against `MANIFEST.md`.

`chartcoach catalog manifest --source PATH --format markdown|json|jsonl`

Print the catalog manifest or list section roles and label families.

`chartcoach catalog duckdb --source PATH --out PATH [--overwrite]`

Write derived catalog tables into a DuckDB database file.

## sql

`chartcoach sql --source PATH QUERY [--limit N] [--format table|json|jsonl|csv]`

Run one read-only `SELECT` query over catalog DuckDB tables with external file access disabled.

## guidelines

`chartcoach guidelines list --source PATH [--label VALUE] [--label-prefix PREFIX] [--contains TEXT] [--limit N] [--format table|json|jsonl|csv]`

List guideline ids and summaries with deterministic filters.

`chartcoach guidelines retrieve --source PATH [--id ID] [--label VALUE] [--section ROLE] [--limit N] [--format markdown|json|jsonl|csv|table]`

Return guideline records with optional section filtering.

`chartcoach guidelines search --source PATH --index-dir DIR [--where FILTER] QUERY [--limit N] [--format table|json|jsonl|csv|markdown]`

Open an existing LanceDB index, run full-text search, and return deduplicated guideline rows. `--where` is a LanceDB SQL filter over indexed document columns such as `role` and `parent_id`.

## index

`chartcoach index build --source PATH --index-dir DIR`

Build the content-addressed LanceDB index for the current catalog digest when it is missing.

`chartcoach index status --source PATH --index-dir DIR --format table|json|jsonl|csv`

Report the resolved index root, table path, table name, document version, readiness, and document count.

`chartcoach index rebuild --source PATH --index-dir DIR --yes`

Rebuild the index path for the current catalog digest.

`chartcoach index query --source PATH --index-dir DIR QUERY --limit N --where FILTER --format json|jsonl`

Run full-text search over indexed document rows.

```bash
chartcoach index query --source guidelines \
  --index-dir "$INDEX_DIR" \
  "bar axis baseline" \
  --limit 5
```
