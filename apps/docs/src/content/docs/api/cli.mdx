---
title: CLI Reference
description: Command groups and output contracts for the chartcoach command-line interface.
---

The `chartcoach` CLI reads catalog bundles, emits deterministic rows, writes DuckDB tables, and queries optional LanceDB indexes.

```bash
chartcoach --help
```

Read-only commands use package-pinned release metadata under `https://artifacts.chartcoach.dev/catalog/releases/<version>/<digest>/metadata.json` when `--source` and `CHARTCOACH_SOURCE` are omitted. The Python package downloads the manifest and entries artifacts once into the user's platform cache directory and validates the package-pinned digest. The local cache mirrors `catalog/releases/<version>/<digest>/`. Indexed commands download default LanceDB artifacts only when an index is needed.

Human `table` output uses rounded, wrapped columns for terminal scanning. JSON, JSONL, and CSV output keep machine-readable stdout. First-download notices are written to stderr.

For agent workflows, install the top-level `$chartcoach` skill and ask the agent to use it. The CLI exposes catalog primitives and CLI-served workflow skills.

## catalog

`chartcoach catalog overview [--source PATH_OR_URL] [--format table|json|jsonl|csv]`

Summarize the current catalog source, table counts, section roles, and label families.

`chartcoach catalog manifest [--source PATH_OR_URL] [--format markdown|json|jsonl]`

Print the catalog manifest.

`chartcoach catalog labels [--source PATH_OR_URL] [--family NAME] [--prefix PREFIX] [--contains TEXT] [--limit N] [--format table|json|jsonl|csv]`

List label values and counts.

`chartcoach catalog roles [--source PATH_OR_URL] [--format table|json|jsonl|csv]`

List section roles and counts.

`chartcoach catalog list [--source PATH_OR_URL] [--label VALUE] [--label-prefix PREFIX] [--contains TEXT] [--limit N] [--format table|json|jsonl|csv]`

List entry ids and summaries.

`chartcoach catalog query [--source PATH_OR_URL] [--id ID] [--label VALUE] [--any-label VALUE] [--label-prefix PREFIX] [--contains TEXT] [--body-contains TEXT] [--section-contains TEXT] [--limit N] [--format table|json|jsonl|csv]`

Filter entries with deterministic base predicates. This command does not use LanceDB, embeddings, or ranked retrieval.

`chartcoach catalog read [--source PATH_OR_URL] ID... [--section ROLE] [--source-detail none|minimal|full] [--format markdown|json|jsonl]`

Read exact entries and selected sections. Section roles come from the current manifest.

`chartcoach catalog cite [--source PATH_OR_URL] ID... [--url-template TEMPLATE] [--format markdown|json|jsonl]`

Print guideline URLs and formatted source citations for exact ids. The default URL template is `https://chartcoach.github.io/guidelines/{id}`. Use this after `catalog read` verifies that each guideline applies.

`chartcoach catalog schema [--source PATH_OR_URL] [TABLE...] [--table NAME] [--tables] [--row-counts] [--format table|json|jsonl|csv]`

Show queryable catalog fields and tables.

Pass table names positionally or with repeated `--table`. Use `--tables` only when listing table names and optional row counts.

`chartcoach catalog values [--source PATH_OR_URL] FIELD [--contains TEXT] [--limit N] [--format table|json|jsonl|csv]`

Count values for a field alias or raw `TABLE.COLUMN`. `FIELD` accepts aliases such as `labels`, `roles`, and `label.family`. Use `--contains TEXT` to filter returned values.

`chartcoach catalog sql [--source PATH_OR_URL] QUERY [--limit N] [--format table|json|jsonl|csv]`

Run one read-only `SELECT` query over catalog DuckDB tables with external file access disabled.

## indexed discovery

`chartcoach catalog find [--source PATH_OR_URL] [--index PATH_OR_URI] [--table NAME] [--where FILTER] [--mode auto|fts|vector|hybrid] QUERY [--limit N] [--candidate-limit N] [--format table|json|jsonl|csv|markdown|compact]`

Open an existing LanceDB table, run LanceDB search, and return deduplicated guideline rows. `--where` is a LanceDB SQL filter over indexed document columns such as `role` and `parent_id`. `--mode` is passed to LanceDB and defaults to `auto`.

`chartcoach catalog index create [--source PATH_OR_URL] --index PATH_OR_URI [--table NAME] [--embedding NAME] [--embedding-option KEY=VALUE] [--embedding-var KEY=VALUE] [--format table|json|jsonl]`

Create or replace a LanceDB table for catalog document search.

`chartcoach catalog index info [--index PATH_OR_URI] [--table NAME] [--format table|json|jsonl]`

Inspect an existing LanceDB table.

## lifecycle

`chartcoach catalog build --source FOLDER --out DIR [--dry-run] [--overwrite]`

Build a catalog bundle from an authored guideline folder.

`chartcoach catalog validate [--source PATH_OR_URL] [--format table|json|jsonl|csv]`

Validate a catalog source and report table counts.

`chartcoach catalog export duckdb [--source PATH_OR_URL] --out PATH [--overwrite]`

Write derived catalog tables into a DuckDB database file.

## skills

`chartcoach skills list`

List CLI-served skills bundled with the installed package.

`chartcoach skills get NAME`

Print one CLI-served skill.

`chartcoach skills path [NAME]`

Print the skill data directory or one skill directory.

## mcp

`chartcoach mcp serve [--source PATH_OR_URL] [--index PATH_OR_URI] [--transport stdio|sse|streamable-http]`

Start the ChartCoach MCP server. Install `chartcoach[mcp]` for catalog-only tools or `chartcoach[mcp,index]` when the server should expose indexed search.
