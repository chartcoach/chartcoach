The MCP server exposes one raw catalog query tool and, when an index is configured, one raw LanceDB query tool.

```bash
chartcoach mcp serve --source guidelines
```

Pass `--index` to register the search tool backed by an existing LanceDB index.

```bash
chartcoach mcp serve \
  --source guidelines \
  --index "$CHARTCOACH_INDEX"
```

## Runtime Options

`--transport stdio|sse|streamable-http`

MCP transport. Defaults to `stdio`.

`--host HOST`

Host for HTTP transports. Defaults to `127.0.0.1`.

`--port PORT`

Port for HTTP transports. Defaults to `8000`.

`--log-level DEBUG|INFO|WARNING|ERROR|CRITICAL`

Server log level. Defaults to `INFO`.

`--index PATH`

LanceDB database directory. When omitted, the server registers only `sql`.

`--table NAME`

LanceDB table name for `search`. Defaults to `catalog_documents`.

## Catalog Tools

`sql`

Run one read-only `SELECT` query over DuckDB catalog tables. The tool accepts `statement` and optional `limit`, then returns column metadata, rows, row count, truncation state, limit, and catalog digest.

## Search Tools

Search is registered only when the server starts with `--index` or `CHARTCOACH_INDEX`.

`search`

Run LanceDB search over indexed catalog document rows. The tool accepts `search_query`, optional `limit`, optional LanceDB SQL `where` filter, and optional `mode` (`auto`, `fts`, `vector`, or `hybrid`), then returns raw indexed document rows with index path and table name metadata.
