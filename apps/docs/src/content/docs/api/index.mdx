ChartCoach APIs read the catalog as source data. A loaded catalog returns Guideline Instance records with the same fields across Python, JavaScript, browser, CLI, and MCP tools.

```bash
uv add chartcoach
pnpm add @chartcoach/catalog
```

Install extras only for search or MCP use:

```bash
uv add "chartcoach[index]"
uv add "chartcoach[mcp,index]"
```

## Sections

- [Catalog records](/api/catalog-records/) defines the shared source row shape.
- [Python API](/api/python/) loads bundles, exposes tables, writes DuckDB, and opens LanceDB indexes.
- [JavaScript API](/api/javascript/) loads records in server and shared runtime code.
- [Browser loading](/api/browser/) loads published parquet files over HTTP.
- [CLI](/api/cli/) covers command groups and output contracts.
- [MCP](/api/mcp/) covers tool names and runtime options.
