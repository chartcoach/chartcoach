---
title: Python Catalog API
description: Load ChartCoach catalogs, inspect tables, and open native DuckDB or LanceDB artifacts from Python.
---

The `chartcoach` package loads catalog bundles and exposes table views for Python workflows.

```python
from chartcoach import Catalog

catalog = Catalog.from_source("guidelines")
catalog.guidelines().select("id", "title", "description")
```

## Constructors

`Catalog.from_bundle(path)`

Load a directory containing `MANIFEST.md` and `catalog.parquet`. The loader validates section roles and label families against the manifest.

`Catalog.from_source(path)`

Load an authored guideline folder, catalog bundle, or parquet file from one path.

`Catalog.from_parquet(path)`

Load a serialized catalog parquet file without manifest validation.

`Catalog.from_folder(folder_path)`

Load an authored folder where `MANIFEST.md` sits beside guideline entry directories.

`Catalog.from_entries(entries)`

Build a catalog from Python entry objects.

## Tables

`catalog.guidelines()`

Return one row per guideline.

`catalog.sections()`

Return one row per guideline section.

`catalog.labels()`

Return distinct label segments used across the catalog.

`catalog.references()`

Return parsed BibTeX reference records.

`catalog.table(name)`

Return a named derived table.

## DuckDB

```python
from chartcoach.duckdb import connect_catalog

conn = connect_catalog(catalog)
conn.sql("select id, title from guidelines limit 5").pl()
conn.close()
```

Use DuckDB when callers need joins over guidelines, sections, labels, and references.

## Catalog Tools

```python
from chartcoach import CatalogTools

tools = CatalogTools(catalog)
tools.retrieve_guidelines(labels=["chart:bar"], roles=["advice"])
tools.sql_query("select id, title from guidelines limit 5")
```

`CatalogTools` exposes the same catalog operations used by the CLI and MCP server. Pass `index_dir` when calling search methods.

## Search Index

```python
from chartcoach import CatalogTools
from chartcoach.paths import default_index_dir

tools = CatalogTools(
    catalog,
    index_dir=default_index_dir(),
)

rows = tools.query_documents(
    "overplotted scatter plots",
    limit=3,
    where="role = 'overview'",
)["rows"]

hits = tools.search_guidelines("overplotted scatter plots")["rows"]
```

Build the index first with `chartcoach index build`. `query_documents` returns indexed document rows. `search_guidelines` deduplicates document matches to guideline rows. ChartCoach creates a LanceDB full-text table over catalog documents. Use LanceDB's schema and embedding registry directly for vector tables.
