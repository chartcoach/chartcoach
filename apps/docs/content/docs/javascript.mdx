Install the catalog loader:

```bash
npm install @chartcoach/catalog
```

## `open(options?)`

Reads the selected release from `catalog.json`, verifies the release digest,
then loads and verifies `MANIFEST.md` and `entries.parquet`.

```ts
import { open } from "@chartcoach/catalog";

const catalog = await open();
const guideline = catalog.require("compare-percentages-with-bars-not-pies");
```

Pass a Fetch-compatible function with `open({ fetch })` when the runtime needs
one.

## `openRelease(source, options?)`

Loads an exact release from an absolute `release.json` URL.

```ts
import { openRelease } from "@chartcoach/catalog";

const catalog = await openRelease(
  "https://artifacts.chartcoach.dev/catalog/releases/<digest>/release.json",
  { fetch },
);
```

The digest in the URL must match the release record and its artifact envelope.

## `loadCatalog({ entries, manifestText })`

Loads a compiled bundle from caller-provided bytes and manifest text.

```ts
import { readFile } from "node:fs/promises";
import { loadCatalog } from "@chartcoach/catalog";

const catalog = await loadCatalog({
  entries: await readFile("dist/catalog/entries.parquet"),
  manifestText: await readFile("dist/catalog/MANIFEST.md", "utf8"),
});
```

The manifest defines the valid section roles and label families for every
loaded row.

## Catalog model

Compiled rows are flat:

```ts
type GuidelineRow = {
  id: string;
  title: string;
  description: string;
  labels: string[];
  sections: Array<{ role: string; title: string; content: string }>;
  references: string[];
};
```

`Catalog` provides `guidelines`, `length`, `get(id)`, `require(id)`, `labels()`,
`sectionRoles()`, and iteration. Each `Guideline` receives a derived `body`
from its ordered sections.

## Release model

`parseCatalogRelease(value)` validates a schema 1 path-keyed record:

```ts
type ReleaseArtifact = {
  sha256: string;
  bytes: number;
};

type CatalogRelease = {
  schema_version: 1;
  digest: string;
  artifacts: Record<string, ReleaseArtifact>;
};
```

`MANIFEST.md` and `entries.parquet` are required. Profile artifacts use
`profiles/<profile>/documents.parquet` and
`profiles/<profile>/index.tar.gz`.

The package exports `Catalog`, `Guideline`, `GuidelineSection`,
`CatalogRelease`, `ReleaseArtifact`, `loadCatalog`, `open`, `openRelease`,
`parseCatalogRelease`, and `toMarkdown`.
