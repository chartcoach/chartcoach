`@chartcoach/catalog` loads verified Guideline Catalog releases in browsers and
server runtimes. This page bundles the `0.2.0` workspace package.

```ts
import { openCatalog } from "@chartcoach/catalog";

const catalog = await openCatalog(
  "https://files.peter.gy/packages/python/chartcoach/0.2.0/docs-catalog/release.json",
);
const guideline = catalog.require("direct-labels");

console.log(guideline.sections[0]?.content);
```

`openCatalog` verifies the release digest, artifact byte counts, and SHA-256
hashes before it decodes the catalog.

```python marimo
catalog_notebook = obs.Notebook(
    obs.js(
        """
        const sdk = globalThis.ChartCoachCatalog;
        if (!sdk) throw new Error("ChartCoach Catalog SDK is unavailable");

        const catalog = new sdk.Catalog(records, manifest);
        """,
        key="catalog",
        display=False,
    ),
    obs.js(
        """
        const selectedId = view(Inputs.select(
          catalog.guidelines.map((guideline) => guideline.id),
          {
            label: "Guideline",
            format: (id) => catalog.require(id).title
          }
        ));
        """,
        key="selected_id",
    ),
    obs.js(
        r"""
        const selected = catalog.require(selectedId);
        const markdown = sdk.toMarkdown(selected);

        display(md`### ${selected.title}

\`${selected.id}\`

${selected.sections[0].content}

**Labels:** ${selected.labels.map((label) => `\`${label}\``).join(" ")}
        `);

        display(html`<details>
          <summary>Generated Markdown</summary>
          <pre>${markdown}</pre>
        </details>`);
        """,
        key="selected_record",
    ),
    variables={"records": records, "manifest": manifest},
)

catalog_view = catalog_notebook.view(capture_state=False)
catalog_view
```

The initial record, labels, advice, and generated Markdown remain in the static
page output while Python and the Observable runtime start. Changing the select
reruns the dependent JavaScript cell in the browser.

## Construct from caller-provided bytes

Use `loadCatalog` when the application already owns the artifact transport:

```ts
import { readFile } from "node:fs/promises";
import { loadCatalog } from "@chartcoach/catalog";

const catalog = await loadCatalog({
  entries: await readFile("dist/catalog/entries.parquet"),
  manifestText: await readFile("dist/catalog/MANIFEST.md", "utf8"),
});
```

`Catalog` exposes `guidelines`, `length`, `get(id)`, `require(id)`, `labels()`,
`sectionRoles()`, and iteration. `toMarkdown(guideline)` serializes frontmatter
plus the body derived from ordered sections.

Use [Catalog model](/catalog) for the row and release shapes.
