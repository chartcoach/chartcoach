Install the catalog loader:

```bash
npm install @chartcoach/catalog
```

## `openCatalog(source?, options?)`

`openCatalog` accepts an absolute HTTP or HTTPS URL ending in `catalog.json` or
`release.json`. The default source is the official selected catalog.

```ts
import { openCatalog } from "@chartcoach/catalog";

const selected = await openCatalog();
const exact = await openCatalog(
  "https://artifacts.chartcoach.dev/catalog/releases/<digest>/release.json",
);

const guideline = selected.require("compare-percentages-with-bars-not-pies");
```

Pass a Fetch-compatible function when the runtime supplies one:

```ts
const catalog = await openCatalog(source, { fetch });
```

The loader verifies the release digest, artifact byte count, and artifact
SHA-256 before decoding the catalog.

## `loadCatalog({ entries, manifestText })`

`loadCatalog` constructs a catalog from caller-provided bundle data.

```ts
import { readFile } from "node:fs/promises";
import { loadCatalog } from "@chartcoach/catalog";

const catalog = await loadCatalog({
  entries: await readFile("dist/catalog/entries.parquet"),
  manifestText: await readFile("dist/catalog/MANIFEST.md", "utf8"),
});
```

## Catalog model

Compiled rows are flat:

```ts
type GuidelineRow = {
  id: string;
  title: string;
  description: string;
  labels: string[];
  sections: Array<{ role: string; title: string; content: string }>;
  references: string[];
};
```

`Catalog` provides `guidelines`, `length`, `get(id)`, `require(id)`, `labels()`,
`sectionRoles()`, and iteration. Each guideline receives a Markdown `body`
derived from its ordered sections.

## Release model

`parseCatalogRelease(value)` validates a schema 1 path-keyed record:

```ts
type CatalogRelease = {
  schema_version: 1;
  digest: string;
  artifacts: Record<string, { sha256: string; bytes: number }>;
};
```

The package exports `Catalog`, `CatalogError`, `CatalogRelease`, `FetchLike`,
`Guideline`, `GuidelineSection`, `OpenCatalogOptions`, `ReleaseArtifact`,
`loadCatalog`, `openCatalog`, `parseCatalogRelease`, and `toMarkdown`.
