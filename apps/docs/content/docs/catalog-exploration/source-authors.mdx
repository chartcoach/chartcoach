---
title: Source authors
description: Join guidelines to source records authored by a selected researcher.
icon: UserRoundSearch
---

Search `authors_text` to connect a researcher to the guidelines that cite their
work.

```bash
AUTHOR=${AUTHOR:-Heer}
LIMIT=${LIMIT:-10}

chartcoach catalog sql "
select distinct
  g.id,
  g.title,
  r.id as source_id,
  r.year,
  r.authors_text
from guidelines g
join guideline_sources gs on gs.guideline_id = g.id
join \"references\" r on r.id = gs.reference_id
where r.authors_text ilike '%${AUTHOR}%'
order by r.year, r.id, g.id
limit ${LIMIT}
"
```

`authors_text` preserves the structural BibTeX author list, including
abbreviated names from the source record.

Count the connected records before choosing examples:

```bash
chartcoach catalog sql "
select
  count(distinct r.id) as sources,
  count(distinct gs.guideline_id) as guidelines
from guideline_sources gs
join \"references\" r on r.id = gs.reference_id
where r.authors_text ilike '%${AUTHOR}%'
" --format json
```

Read the selected guideline and format its source citations:

```bash
chartcoach catalog read <guideline-id> --source-detail full
chartcoach catalog cite <guideline-id>
```

Use `guideline_sources` when the query needs guideline id and source metadata
in one row. Use `references` when the source itself is the unit of analysis.
