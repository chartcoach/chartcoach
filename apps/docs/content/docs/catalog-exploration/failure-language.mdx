---
title: Failure search
description: Search indexed mistake sections with reviewer language, then verify the selected guideline.
icon: SearchCheck
---

Use indexed search when reviewer wording maps poorly to exact titles or labels.
This example restricts retrieval to the manifest's `mistakes` role.

```bash
QUERY=${QUERY:-"uncertainty shown as exact values confidence interval misleading"}

chartcoach catalog find \
  --profile openai/text-embedding-3-large \
  --mode fts \
  --where "role = 'section.mistakes'" \
  --limit 5 \
  --format compact \
  "${QUERY}"
```

Indexed roles use `section.<role>`. `catalog read --section` receives the
manifest role itself:

```bash
chartcoach catalog read <guideline-id> \
  --section mistakes \
  --source-detail minimal \
  --format markdown
```

Use JSON when another process consumes search candidates:

```bash
chartcoach catalog find \
  --profile openai/text-embedding-3-large \
  --mode fts \
  --where "role = 'section.mistakes'" \
  --limit 5 \
  --format json \
  "${QUERY}" |
  jq '.rows[] | {id, title, role: .matched_role}'
```

An indexed match identifies a candidate document. Read the guideline before
using its text as evidence.
