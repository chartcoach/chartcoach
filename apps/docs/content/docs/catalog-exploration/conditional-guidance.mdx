---
title: Use and avoid
description: Find label topics that have both recommendation and warning records.
icon: GitCompare
---

Labels may use modifiers such as `use` and `avoid`. Compare those modifiers to
find topics whose guidance depends on task, data, or audience.

```bash
chartcoach catalog sql "
with counts as (
  select
    family,
    category,
    modifier,
    count(distinct guideline_id) as guidelines
  from guideline_labels
  where modifier in ('use', 'avoid')
  group by family, category, modifier
)
select
  use_rows.family,
  use_rows.category,
  use_rows.guidelines as use_guidelines,
  avoid_rows.guidelines as avoid_guidelines
from counts use_rows
join counts avoid_rows
  on avoid_rows.family = use_rows.family
 and avoid_rows.category = use_rows.category
 and avoid_rows.modifier = 'avoid'
where use_rows.modifier = 'use'
order by use_guidelines + avoid_guidelines desc
limit 10
"
```

Read both sides of one topic:

```bash
FAMILY=chart
CATEGORY=line

chartcoach catalog list --label "${FAMILY}:${CATEGORY}:use" --limit 5
chartcoach catalog list --label "${FAMILY}:${CATEGORY}:avoid" --limit 5
```

Then inspect the exact sections that make the condition explicit:

```bash
chartcoach catalog read <use-guideline-id>
chartcoach catalog read <avoid-guideline-id>
```

A shared label category establishes topical overlap. The guideline sections
carry the scope, conditions, exceptions, and source evidence.
