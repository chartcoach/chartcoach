chartcoach exposes the same catalog records through CLI rows, Polars frames,
DuckDB tables, and indexed LanceDB documents.

Inspect the live table contract first:

```bash
uvx --from 'chartcoach[curation]@latest' chartcoach catalog schema \
  --tables \
  --row-counts
```

The queryable tables are:

| Table                  | Grain                                           |
| ---------------------- | ----------------------------------------------- |
| `guidelines`           | One row per guideline.                          |
| `sections`             | One row per guideline section.                  |
| `guideline_labels`     | One row per guideline and label.                |
| `references`           | One row per source record.                      |
| `guideline_references` | One row per guideline and source edge.          |
| `guideline_sources`    | One enriched row per guideline and source edge. |

Use table output during terminal exploration and JSON when another process
consumes the result:

```bash
chartcoach catalog schema --tables --row-counts --format json |
  jq '.[] | {table: .name, rows}'
```
