---
title: Task matrix
description: Join chart and task labels to inspect catalog coverage.
icon: Table2
---

Build a chart-by-task matrix from normalized labels:

```bash
MIN_COUNT=${MIN_COUNT:-3}

chartcoach catalog sql "
with charts as (
  select guideline_id, category as chart, coalesce(modifier, 'general') as stance
  from guideline_labels
  where family = 'chart'
), tasks as (
  select guideline_id, category as task
  from guideline_labels
  where family = 'task'
)
select
  charts.chart,
  charts.stance,
  tasks.task,
  count(distinct charts.guideline_id) as guidelines
from charts
join tasks on tasks.guideline_id = charts.guideline_id
group by charts.chart, charts.stance, tasks.task
having count(distinct charts.guideline_id) >= ${MIN_COUNT}
order by guidelines desc, charts.chart, charts.stance, tasks.task
limit 20
"
```

Drill into one cell with repeated all-of label filters:

```bash
chartcoach catalog list \
  --label chart:line:use \
  --label task:trend \
  --limit 10 \
  --format json
```

The matrix reports catalog coverage, not design quality or recommendation
strength. Read the selected records to inspect their scope and evidence.

```bash
chartcoach catalog read <guideline-id>
```
