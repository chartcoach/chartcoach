Run the published catalog with the curation extra:

```bash
uvx --from 'chartcoach[curation]@latest' chartcoach catalog overview
```

`catalog overview` reports record counts, section roles, label families, and
the selected release digest.

## Find and read a guideline

Use `list` for deterministic filters over ids, titles, descriptions, and
labels.

```bash
uvx --from 'chartcoach[curation]@latest' chartcoach catalog list \
  --contains "legend" \
  --limit 5 \
  --format json
```

Copy an `id` from the result and read the record:

```bash
uvx --from 'chartcoach[curation]@latest' chartcoach catalog read <guideline-id>
```

Use the same id to produce a public link and source citations:

```bash
uvx --from 'chartcoach[curation]@latest' chartcoach catalog cite <guideline-id>
```

Candidate discovery and evidence retrieval are separate steps. `list`, `sql`,
and `find` produce candidates. `read` returns the exact guideline text that an
answer should check before `cite` formats its references.

## Select a catalog source

Pass `--source` to commands that read catalog records:

```bash
chartcoach catalog overview --source ./catalog-source
chartcoach catalog overview --source ./dist/catalog
chartcoach catalog overview --source <64-character-release-digest>
```

An authored folder contains `MANIFEST.md` and `entries/<id>/guideline.md`. A
compiled bundle contains `MANIFEST.md` and `entries.parquet`. A digest resolves
an immutable published release through the curation extra.

When `--source` is absent, chartcoach reads `CHARTCOACH_SOURCE`, then the
release record in `catalog.json`.
