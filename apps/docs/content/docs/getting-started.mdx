a Polars dataframe.

## Inspect one record

Each dataframe row is one compiled guideline. `row(0, named=True)` returns the
first row as a mapping, including its nested `labels`, `sections`, and
`references` values.

```python
import marimo as mo

row = df.row(0, named=True)
mo.json(row)
```

```python marimo
import marimo as mo

row = df.row(0, named=True)
mo.json(row)
```

The dataframe row is the catalog wire shape. [Python](/python) covers the
derived guideline, section, label, and reference tables. [Querying](/querying)
covers filters, SQL, and indexed search.
