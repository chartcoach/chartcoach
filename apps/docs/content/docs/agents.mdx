Install the chartcoach skills, then name the task in the agent request:

```bash
npx skills add chartcoach/skills
codex 'Use $chartcoach to review this chart for labels and accessibility.'
```

## Skills

| Skill         | Job                                                                                    |
| ------------- | -------------------------------------------------------------------------------------- |
| `core`        | Select a source, inspect vocabulary, retrieve records, and recover from command errors |
| `discuss`     | Compare design choices and trace claims to catalog sources                             |
| `visfeedback` | Review an observed chart or screenshot                                                 |
| `visrec`      | Recommend a visualization from a task and constraints                                  |
| `contribute`  | Draft a local catalog improvement issue for human review                               |

The Python package can print the same skill text for environments that install
agent instructions through another mechanism:

```bash
uvx chartcoach@latest skills
uvx chartcoach@latest skills get core
uvx chartcoach@latest skills get visfeedback
```

## Retrieval contract

An agent should make each transition visible:

```text
catalog source
  -> roles and labels
  -> candidate ids
  -> exact record sections
  -> source citations
  -> claim or recommendation
```

Inspect vocabulary before using exact labels or section roles:

```bash
chartcoach catalog overview --format json
chartcoach catalog roles --format json
chartcoach catalog labels --format json
```

Find a bounded candidate set, then read and cite the selected id:

```bash
chartcoach catalog list --contains "direct labels" --limit 5 --format json
chartcoach catalog read <guideline-id> --source-detail full --format markdown
chartcoach catalog cite <guideline-id> --format markdown
```

Search snippets and SQL rows locate candidates. The exact record owns the
advice, conditions, exceptions, checks, fixes, and source links that support an
answer.

Use the [MCP server](/mcp) when the client should call catalog SQL and index search as
tools.
