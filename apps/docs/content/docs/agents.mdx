Install the chartcoach skills, then invoke `$chartcoach` in the current agent
session.

```bash
npx skills add chartcoach/skills
codex 'Use $chartcoach to review this chart screenshot for labels and accessibility.'
```

The Python package also serves the skill text:

```bash
uvx chartcoach@latest skills
uvx chartcoach@latest skills get core
uvx chartcoach@latest skills get visfeedback
```

## Skills

| Skill         | Task                                                                                            |
| ------------- | ----------------------------------------------------------------------------------------------- |
| `core`        | Choose a catalog source, inspect vocabulary, retrieve records, and recover from command errors. |
| `discuss`     | Compare design choices and trace claims to catalog sources.                                     |
| `visfeedback` | Review an observed chart or screenshot.                                                         |
| `visrec`      | Recommend a visualization from a data task and constraints.                                     |
| `contribute`  | Draft a local catalog improvement issue for human review.                                       |

## Evidence workflow

Use a short retrieval chain:

```text
catalog vocabulary -> candidate ids -> exact record -> formatted citation -> claim
```

Inspect roles and labels before using exact catalog vocabulary:

```bash
chartcoach catalog overview --format json
chartcoach catalog roles --format json
chartcoach catalog labels --format json
```

Find candidates, then verify each selected record:

```bash
chartcoach catalog list --contains "direct labels" --format json
chartcoach catalog read <guideline-id> --source-detail minimal --format markdown
chartcoach catalog cite <guideline-id> --format markdown
```

Use `catalog sql` for relationships across catalog tables. Use `catalog find`
for broader indexed discovery. Both return candidates that still require an
exact `catalog read`.

[MCP](/mcp) exposes the SQL and indexed search steps as tool calls.
