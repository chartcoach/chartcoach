Catalog-reading commands use one source option:

```bash
uvx chartcoach@latest catalog overview \
  --source https://artifacts.chartcoach.dev/catalog.json
```

`--source` accepts a catalog folder, bundle, `catalog.json`, or `release.json`
path or URI. It defaults to `CHARTCOACH_SOURCE`, then the official catalog.

## Catalog commands

| Command            | Contract                                  |
| ------------------ | ----------------------------------------- |
| `catalog overview` | Report catalog counts and vocabulary.     |
| `catalog labels`   | List label values and counts.             |
| `catalog roles`    | List section roles and counts.            |
| `catalog list`     | Filter guideline summaries.               |
| `catalog read`     | Return exact guideline text.              |
| `catalog cite`     | Format public links and source citations. |
| `catalog schema`   | List DuckDB tables and columns.           |
| `catalog sql`      | Run one read-only `SELECT` query.         |
| `catalog find`     | Rank indexed documents with LanceDB.      |

Search selects a profile from the same release source:

```bash
uvx --from 'chartcoach[index]@latest' chartcoach catalog find \
  --source https://artifacts.chartcoach.dev/catalog.json \
  --profile sentence-transformers/all-MiniLM-L6-v2 \
  "direct labels"
```

## Build commands

```bash
chartcoach catalog validate --source ./catalog-source
chartcoach catalog build --source ./catalog-source --out ./dist/catalog
chartcoach catalog export duckdb \
  --source ./dist/catalog \
  --out ./dist/catalog.duckdb
```

## Release commands

The curation extra builds profile artifacts and writes catalog storage:

```bash
chartcoach catalog release validate ./dist/release
chartcoach catalog release publish \
  ./dist/release \
  --store s3://chartcoach
chartcoach catalog release select \
  "$RELEASE_DIGEST" \
  --store s3://chartcoach
```

Publication writes immutable objects under the release digest. Selection
verifies the published release and updates `catalog.json`.

## Agent and MCP commands

