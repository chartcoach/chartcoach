The chartcoach CLI reads an authored folder, a compiled bundle, or a published
release digest.

```bash
uvx chartcoach@latest catalog overview --source ./dist/catalog
```

Use `chartcoach[curation]` for the selected published release and storage
workflows. Use `chartcoach[index]` for local LanceDB search.

```bash
uvx --from 'chartcoach[curation]@latest' chartcoach catalog overview
uvx --from 'chartcoach[index]@latest' chartcoach catalog find \
  --source ./dist/catalog \
  --index ./dist/index \
  "direct labels"
```

## Catalog commands

| Command            | Contract                                  |
| ------------------ | ----------------------------------------- |
| `catalog overview` | Report catalog counts and vocabulary.     |
| `catalog labels`   | List label values and counts.             |
| `catalog roles`    | List section roles and counts.            |
| `catalog list`     | Filter guideline summaries.               |
| `catalog read`     | Return exact guideline text.              |
| `catalog cite`     | Format public links and source citations. |
| `catalog schema`   | List DuckDB tables and columns.           |
| `catalog sql`      | Run one read-only `SELECT` query.         |
| `catalog find`     | Rank indexed documents with LanceDB.      |

Tabular commands support `table` and `json`. `read`, `cite`, and `manifest`
support `markdown` and `json`. `find` also supports `markdown` and `compact`.

## Lifecycle commands

```bash
chartcoach catalog validate --source ./catalog-source
chartcoach catalog build --source ./catalog-source --out ./dist/catalog
chartcoach catalog export duckdb --source ./dist/catalog --out ./dist/catalog.duckdb
```

Release storage uses Obspec object keys with local file URLs or S3-compatible
URLs:

```bash
chartcoach catalog release validate ./dist/release
chartcoach catalog release publish ./dist/release --store s3://chartcoach
chartcoach catalog release select "$RELEASE_DIGEST" --store s3://chartcoach
chartcoach catalog cache pull --profile sentence-transformers/all-MiniLM-L6-v2
```

`release publish` writes immutable objects under the release digest. `release
select` verifies that digest and writes its full release record to
`catalog.json`.

## Agent and MCP commands

```bash
chartcoach skills
chartcoach skills get core
chartcoach mcp --profile sentence-transformers/all-MiniLM-L6-v2
```

The [Agents](/agents) guide covers skill routing. The [MCP](/mcp) guide covers
