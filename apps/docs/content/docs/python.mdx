```bash

```

```python
from chartcoach import open_catalog

catalog = open_catalog("dist/catalog")
print(catalog.guidelines().select("id", "title").head(5))
```

## Top-level API

The package exports `Catalog`, `CatalogManifest`, `CatalogRelease`,
`open_catalog`, `open_index`, `resolve_release`, and `paths`.

### `open_catalog(source=None)`

Loads an authored folder, compiled bundle, selected published release, or exact
release digest. Published sources require `chartcoach[curation]`.

```python
from chartcoach import open_catalog

authored = open_catalog("catalog-source")
bundle = open_catalog("dist/catalog")
published = open_catalog()
exact = open_catalog("<64-character-release-digest>")
```

Local paths must name directories. Authored folders contain `MANIFEST.md` and
an `entries` directory. Bundles contain `MANIFEST.md` and `entries.parquet`.

### `Catalog`

Every `Catalog` owns a `CatalogManifest`. Compiled rows contain `id`, `title`,
`description`, `labels`, `sections`, and `references`.

`Catalog(frame, *, manifest)` validates a flat Polars frame against the
manifest. `Catalog.from_guidelines(guidelines, *, manifest)` builds the same
object from compiled guideline values. Use `Catalog.from_folder(path)` or
`Catalog.from_bundle(path)` for local storage forms.

```python
guidelines = catalog.guidelines()
sections = catalog.sections()
references = catalog.references()

entry = catalog.entry("compare-percentages-with-bars-not-pies")
body = entry["body"]
```

`Catalog` exposes six queryable tables through `table(name)` and `duckdb()`:
`guidelines`, `sections`, `guideline_labels`, `references`,
`guideline_references`, and `guideline_sources`.

```python
with catalog.duckdb() as connection:
    rows = connection.sql("""
        select id, title
        from guidelines
        where description ilike '%legend%'
    """).fetchall()
```

### `CatalogManifest`

`CatalogManifest.from_text(markdown)` and `CatalogManifest.from_path(path)`
parse section-role and label-family definitions. Catalog construction fails
when a row uses a role or label family absent from its manifest.

### `CatalogRelease`

`CatalogRelease` contains `schema_version`, `digest`, and a path-keyed
`artifacts` mapping. `CatalogRelease.from_mapping(value)` parses a release
record. `release.artifact(path)` returns the SHA-256 and byte count for one
artifact.

### `resolve_release(reference=None)`

Returns the selected `CatalogRelease` or the release named by a digest. The
curation extra supplies the Obspec and Obstore access layer.

```python
from chartcoach import resolve_release

selected = resolve_release()
exact = resolve_release(selected.digest)
```

### `paths`

Constructs catalog object keys for local and remote stores.

```python
from chartcoach import paths

release = paths.release("<64-character-release-digest>")

paths.selected()
release.json()
release.manifest()
release.entries()
release.profile("sentence-transformers/all-MiniLM-L6-v2").documents()
release.profile("sentence-transformers/all-MiniLM-L6-v2").index()
```

### `open_index(source=None, *, profile=None)`

Returns the native LanceDB `documents` table. Local paths require
`chartcoach[index]`. Published profiles require `chartcoach[curation]`.

```python
from chartcoach import open_index

table = open_index("dist/index")
rows = (
    table.search("direct labels", query_type="fts", fts_columns="text")
    .where("role = 'overview'")
    .limit(8)
    .to_list()
)
```

Vector search accepts a vector from the calling application:

```python
query_vector = embed("direct labels")
rows = (
    table.search(
        query_vector,
        query_type="vector",
        vector_column_name="vector",
    )
    .distance_type("cosine")
    .limit(8)
    .to_list()
)
```

Native LanceDB query builders also compose filters, hybrid search, rerankers,
and application-provided embedding functions.
