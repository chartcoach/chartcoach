`open_catalog` resolves a catalog source, verifies release artifacts when a
descriptor is present, and returns a `Catalog` backed by Polars.

```bash
uv pip install \
  "chartcoach @ https://files.peter.gy/packages/python/chartcoach/0.2.0/5cc92c6f032d/chartcoach-0.2.0-py3-none-any.whl"
```

```python
from chartcoach import open_catalog

catalog = open_catalog(
    "https://files.peter.gy/packages/python/chartcoach/0.2.0/docs-catalog/release.json"
)
rows = catalog.guidelines().select("id", "title", "description").head(5)
print(rows)
```

The example pins an exact release. Pass another local or HTTP source when the
application owns the catalog lifecycle:

```python
authored = open_catalog("catalog-source")
bundle = open_catalog("dist/catalog")
exact = open_catalog(
    "https://artifacts.chartcoach.dev/catalog/releases/<digest>/release.json"
)
```

`catalog.release` contains the verified `CatalogRelease` for a descriptor or
release directory. It is `None` for an authored folder or a plain bundle.

## Inspect one record

```python
record = catalog.entry("direct-labels")

print(record["labels"])
print(record["sections"][0]["role"])
print(record["body"])
```

`entry(id)` returns `id`, `title`, `description`, `labels`, `sections`,
`references`, and the Markdown `body` derived from the ordered sections. An
unknown id raises `KeyError`.

## Query normalized tables

`Catalog` derives six tables from the compiled rows:

| Method                   | One row per                        |
| ------------------------ | ---------------------------------- |
| `guidelines()`           | Guideline                          |
| `sections()`             | Guideline section                  |
| `guideline_labels()`     | Guideline and label                |
| `references()`           | Parsed reference                   |
| `guideline_references()` | Guideline and reference edge       |
| `guideline_sources()`    | Guideline and enriched source edge |

Use `table(name)` for dynamic lookup or register the tables in DuckDB:

```python
with catalog.duckdb() as connection:
    rows = connection.sql("""
        select g.id, g.title
        from guidelines g
        join guideline_labels l on l.guideline_id = g.id
        where l.label = 'operator:uncertainty'
        order by g.id
        limit 10
    """).fetchall()
```

## Open a search index

Install the index capability, then select a profile from the same release that
owns the catalog rows:

```bash
uv pip install \
  "chartcoach[index] @ https://files.peter.gy/packages/python/chartcoach/0.2.0/5cc92c6f032d/chartcoach-0.2.0-py3-none-any.whl"
```

```python
from chartcoach import open_index

table = open_index(
    "https://artifacts.chartcoach.dev/catalog/releases/<digest>/release.json",
    profile="sentence-transformers/all-MiniLM-L6-v2",
)

matches = (
    table.search("direct labels", query_type="fts", fts_columns="text")
    .where("role = 'section.advice'")
    .limit(8)
    .to_list()
)
```

`open_index` returns the native LanceDB table. Vector and hybrid queries receive
an embedding vector from the caller.

The top-level package exports `Catalog`, `CatalogError`, `CatalogManifest`,
`CatalogRelease`, `open_catalog`, `open_index`, and `__version__`.
