```bash
uv add chartcoach
```

```python
from chartcoach import open_catalog

catalog = open_catalog()
print(catalog.guidelines().select("id", "title").head(5))
```

## `open_catalog(source=None, *, storage_options=None)`

`open_catalog` accepts an authored folder, compiled bundle, release directory,
or descriptor path or URI.

```python
authored = open_catalog("catalog-source")
bundle = open_catalog("dist/catalog")
local_release = open_catalog("dist/release")
selected = open_catalog()
exact = open_catalog(
    "https://artifacts.chartcoach.dev/catalog/releases/<digest>/release.json"
)
```

An authored folder contains `MANIFEST.md` and `entries/`. A bundle contains
`MANIFEST.md` and `entries.parquet`. Remote sources name `catalog.json` or
`release.json`.

S3, GCS, and Azure sources require `chartcoach[cloud]`. Provider settings pass
through `storage_options`. Ambient provider credentials handle the common
case.

```python
catalog = open_catalog(
    "s3://research-artifacts/chartcoach/catalog.json",
    storage_options={"region": "eu-central-1"},
)
```

`catalog.release` contains the verified `CatalogRelease` for descriptor-backed
and release-directory sources. It is `None` for authored folders and plain
bundles.

## `Catalog`

Every `Catalog` owns a `CatalogManifest`. Compiled rows contain `id`, `title`,
`description`, `labels`, `sections`, and `references`.

```python
guidelines = catalog.guidelines()
sections = catalog.sections()
references = catalog.references()

entry = catalog.entry("compare-percentages-with-bars-not-pies")
body = entry["body"]
```

`Catalog(frame, *, manifest)` constructs a catalog from a Polars frame.
`Catalog.from_guidelines(guidelines, *, manifest)` constructs one from compiled
guideline values. File input goes through `open_catalog`.

`Catalog` exposes six queryable tables through `table(name)` and `duckdb()`:
`guidelines`, `sections`, `guideline_labels`, `references`,
`guideline_references`, and `guideline_sources`.

```python
with catalog.duckdb() as connection:
    rows = connection.sql("""
        select id, title
        from guidelines
        where description ilike '%legend%'
    """).fetchall()
```

## `open_index(source=None, *, profile, storage_options=None)`

`open_index` selects a native LanceDB profile from the same release source
accepted by `open_catalog`.

```bash
uv add 'chartcoach[index]'
```

```python
from chartcoach import open_index

table = open_index(
    "https://artifacts.chartcoach.dev/catalog.json",
    profile="sentence-transformers/all-MiniLM-L6-v2",
)

rows = (
    table.search("direct labels", query_type="fts", fts_columns="text")
    .where("role = 'overview'")
    .limit(8)
    .to_list()
)
```

Standalone LanceDB directories use the LanceDB API directly.

## Top-level API

The package exports `Catalog`, `CatalogError`, `CatalogManifest`,
`CatalogRelease`, `open_catalog`, `open_index`, and `__version__`.
