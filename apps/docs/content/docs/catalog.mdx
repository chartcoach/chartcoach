The Guideline Catalog has three storage forms: an authored folder, a compiled
bundle, and an immutable release.

## Authored folder

```text
catalog-source/
├── MANIFEST.md
└── entries/
    └── direct-labels/
        ├── guideline.md
        └── references.bib
```

`MANIFEST.md` defines section roles and label families. Each `guideline.md`
contains frontmatter plus ordered Markdown sections whose headings carry a
manifest role.

## Compiled bundle

```text
catalog/
├── MANIFEST.md
└── entries.parquet
```

Every `entries.parquet` row has six fields:

```ts
type GuidelineRow = {
  id: string;
  title: string;
  description: string;
  labels: string[];
  sections: Array<{
    role: string;
    title: string;
    content: string;
  }>;
  references: string[];
};
```

The Markdown body is derived from `sections`. Reference ids point to BibTeX
entries compiled from the authored folder.

## Immutable release

A release record is a schema 1 artifact envelope. Artifact paths are the map
keys.

```ts
type CatalogRelease = {
  schema_version: 1;
  digest: string;
  artifacts: Record<
    string,
    {
      sha256: string;
      bytes: number;
    }
  >;
};
```

The digest is the SHA-256 of the canonical schema version and artifact map.
`MANIFEST.md` and `entries.parquet` are required. A release may contain any
number of embedding profiles.

```text
catalog/releases/<digest>/
├── release.json
├── MANIFEST.md
├── entries.parquet
└── profiles/
    ├── sentence-transformers/all-MiniLM-L6-v2/
    │   ├── documents.parquet
    │   └── index.tar.gz
    └── openai/text-embedding-3-large/
        ├── documents.parquet
        └── index.tar.gz
```

Each profile represents one embedding space. Its Parquet file contains native
document fields plus vectors, UMAP coordinates, and nearest neighbors:

```text
row_id
id
parent_id
role
labels
content_hash
text
vector
projection_x
projection_y
neighbors
```

`neighbors` contains `ids` and `distances`. Neighbor ids refer to `row_id`.
The profile archive contains one LanceDB table named `documents` whose source
column is `text` and vector column is `vector`.

The profile Parquet file can be loaded directly in Embedding Atlas or another
Arrow-compatible analysis tool.

## Selected release

`catalog.json` contains the full `CatalogRelease` selected for public access.
Readers resolve that record, verify its digest, then fetch artifacts from
`catalog/releases/<digest>/`.

Selecting a release updates this one mutable entry document. Published release
directories remain immutable.

## Object-key API

`chartcoach.paths` constructs the same keys for local Obspec stores and
S3-compatible stores.

```python
from chartcoach import paths

release = paths.release("<64-character-release-digest>")
profile = release.profile("sentence-transformers/all-MiniLM-L6-v2")

paths.selected()
release.root()
release.json()
release.manifest()
release.entries()
profile.documents()
profile.index()
```

## Queryable tables

Python derives six tables from the compiled rows: `guidelines`, `sections`,
`guideline_labels`, `references`, `guideline_references`, and
`guideline_sources`. Run `chartcoach catalog schema --tables --row-counts` to
inspect the current catalog before writing SQL.
