chartcoach gives you access to a versioned visualization guideline catalog from
the CLI, Python, JavaScript, or MCP. Start with the CLI.

```bash
uvx chartcoach@latest catalog query --contains "legend" --limit 5 --format table
```

Read the exact guideline before citing it:

```bash
uvx chartcoach@latest catalog read compare-percentages-with-bars-not-pies \
  --source-detail minimal \
  --format markdown
uvx chartcoach@latest catalog cite compare-percentages-with-bars-not-pies \
  --format markdown
```
