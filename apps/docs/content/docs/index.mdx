chartcoach exposes visualization design guidelines as a manifest-backed catalog
of structured records.

List candidate guidelines from the published catalog:

```bash
uvx chartcoach@latest catalog list \
  --contains "direct labels" \
  --limit 5 \
  --format json
```

Read the exact record before using it as evidence:

```bash
uvx chartcoach@latest catalog read \
  compare-percentages-with-bars-not-pies \
  --format markdown
```

Format its public URL and source references:

```bash
uvx chartcoach@latest catalog cite \
  compare-percentages-with-bars-not-pies
```
