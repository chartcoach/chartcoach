chartcoach helps you find visualization guidelines and inspect the sources
behind each recommendation. The Guideline Catalog stores each guideline with
labels for filtering, separate sections for advice and checks, and its source
references.

## Read one guideline

This command reads a guideline from a fixed three-record catalog:

```bash
uvx --from \
  "chartcoach @ https://files.peter.gy/packages/python/chartcoach/0.2.0/892f120cb377/chartcoach-0.2.0-py3-none-any.whl" \
  chartcoach catalog read directly-label-series-instead-of-using-a-color-key \
  --source https://files.peter.gy/packages/python/chartcoach/0.2.0/docs-catalog/c0f6dbec3dd31b07763b46fd458733db0b8b50c5793cf9447458119287129420/release.json \
  --format markdown
```

`uvx` downloads and runs the hosted chartcoach 0.2.0 Python package. The
`release.json` URL fixes the catalog contents, so the command returns the same
guideline on every run.

This shortened excerpt shows the guideline title and its first section:

```text
## directly-label-series-instead-of-using-a-color-key

**Directly label colored series instead of relying on a color key**

...

### advice: Move labels onto the marks

Label colored series directly on the chart instead of making readers decode
them through a color key...
```

The complete output continues through the reasons, applicable situations,
exceptions, costs, common mistakes, checks, fixes, and source list. The same
record is available in the
[catalog browser](https://chartcoach.dev/guidelines/directly-label-series-instead-of-using-a-color-key/).

## What a guideline contains

A guideline record keeps the information needed to find, apply, and cite one
recommendation:

- `id` names the guideline in commands and code.
- `labels` support exact filtering, such as `quality:accessibility`.
- `sections` separate the recommendation from its reasons, limits, checks, and
  fixes.
- `references` identify the sources cited by the sections.
