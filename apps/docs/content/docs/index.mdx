ChartCoach exposes source-traced visualization guidance as a versioned Guideline
Catalog. Each record has a stable id, retrieval labels, ordered sections, and
BibTeX references.

## Read a guideline

The CLI returns the complete record and its references:

```bash
uvx chartcoach@latest catalog read \
  directly-label-series-instead-of-using-a-color-key \
  --source-detail full \
  --format markdown
```

The record keeps its advice beside the vocabulary used to retrieve it and the
sources used to support it. Catalog releases preserve that shape across the
[Python](/python), [JavaScript](/javascript), [CLI](/cli), and [MCP
server](/mcp) interfaces.

[Getting started](/getting-started) loads a release as a dataframe and inspects
one record in the browser.
