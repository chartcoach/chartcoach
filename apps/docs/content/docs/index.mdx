chartcoach gives you access to a versioned visualization guideline catalog from
the CLI, Python, JavaScript, or MCP. The Guideline Catalog is a citable
collection of visualization design records with stable ids, role-marked
sections, labels, and source references.

Compared with standard retrieval over papers, posts, or documentation,
chartcoach searches smaller typed records first. Candidate rows point to exact
guideline ids. Exact `read` and `cite` calls return the record text and source
metadata that can support an answer.

Start with one terminal flow:

```bash
uvx chartcoach@latest catalog query --contains "legend" --limit 5 --format jsonl
uvx chartcoach@latest catalog read add-unlabeled-axis-ticks-to-continuous-color-keys \
  --source-detail minimal \
  --format json
uvx chartcoach@latest catalog cite add-unlabeled-axis-ticks-to-continuous-color-keys \
  --format json
```

Use the id from a selected JSONL row in later `read` and `cite` calls. Query and
search rows are candidates. Exact `read` output is the guideline text that can
support a claim.

## What chartcoach provides

| Piece | What it gives you |
| --- | --- |
| Guideline records | Stable ids, titles, descriptions, labels, section text, and references |
| Default Catalog | The package-pinned catalog release used when no source is passed |
| CLI | One-off inspection, agent subprocess calls, SQL, read, cite, and validation |
| Python | Polars tables, DuckDB joins, direct catalog loading, and LanceDB search |
| JavaScript | Browser and app loading from package-pinned catalog artifacts |
| MCP and skills | Agent-facing SQL, search, retrieval, citation, and evaluation workflows |

## Evidence workflow

1. Discover candidate ids with `catalog query`, `catalog sql`, `catalog find`,
   or `chartcoach.open().search(...)`.
2. Read exact guideline records with `catalog read`, `Catalog.entry()`, or the
   JavaScript catalog loader.
3. Cite sources with `catalog cite` or `citation_records(...)` before using the
   guideline in feedback.

This keeps retrieval fast to inspect and keeps evidence local to the guideline
record that supports the final answer.
