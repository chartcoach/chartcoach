chartcoach gives people and agents a searchable Guideline Catalog for creating
and reviewing charts. Each guideline entry contains a recommendation, labels,
sections such as advice and checks, and references to its sources.

For example, [directly labeling series](https://chartcoach.dev/guidelines/directly-label-series-instead-of-using-a-color-key/)
comes with advice on placement, reasons to use it, exceptions, and source
citations. Read the complete entry before applying the recommendation.

## Choose an interface

| Interface                                | Use it for                                                                    |
| ---------------------------------------- | ----------------------------------------------------------------------------- |
| [Python](/python)                        | Catalog records, Polars dataframes, DuckDB queries, and native LanceDB tables |
| [JavaScript and TypeScript](/javascript) | Catalog records in browsers and Node.js, with verified artifact access        |
| [CLI](/cli)                              | Terminal inspection, bounded SQL and search, and curation commands            |
| [MCP](/mcp)                              | Catalog tools for a client that supports the Model Context Protocol           |

Use [Catalog data](/catalog) to inspect the record fields, table relationships,
and release files shared by these interfaces.
