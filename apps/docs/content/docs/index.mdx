ChartCoach publishes a Guideline Catalog and loader packages for inspecting
visualization design guidance.

```bash
pnpm --dir apps/docs build
```

The static docs build writes exported files to `apps/docs/out`. Serve that
directory to test the same runtime contract used by deploy previews.
