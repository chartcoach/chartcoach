Start the Model Context Protocol (MCP) server over standard input and output:

```bash
uvx --from 'chartcoach[mcp]@latest' chartcoach mcp
```

The server registers `sql` for every catalog. `sql` accepts one read-only
`SELECT` and caps the returned rows.

## Add indexed search

Install the index capability and select one profile to register `search`:

```bash
uvx --from 'chartcoach[mcp,index]@latest' chartcoach mcp \
  --source https://artifacts.chartcoach.dev/catalog.json \
  --profile sentence-transformers/all-MiniLM-L6-v2
```

The catalog and index resolve through the same release descriptor. `search`
accepts a query, mode, limit, optional LanceDB filter, and an optional vector.
Vector and hybrid modes require the vector. Full-text mode does not.

Use an exact `release.json` URI when a client run must keep one catalog digest:

```bash
chartcoach mcp \
  --source https://artifacts.chartcoach.dev/catalog/releases/<digest>/release.json \
  --profile sentence-transformers/all-MiniLM-L6-v2
```

## Transports

| Transport         | Default boundary                   |
| ----------------- | ---------------------------------- |
| `stdio`           | One parent process owns the server |
| `sse`             | HTTP listener on `127.0.0.1:8000`  |
| `streamable-http` | HTTP listener on `127.0.0.1:8000`  |

Start a local streamable HTTP endpoint:

```bash
chartcoach mcp \
  --transport streamable-http \
  --host 127.0.0.1 \
  --port 8000 \
  --log-level info
```

Changing `--host` can expose the server beyond the current machine. Put
authentication and network policy in the process or platform that owns the
listener before binding a public interface.

`CHARTCOACH_SOURCE` supplies the source when `--source` is absent.
`CHARTCOACH_INDEX_PROFILE` supplies the profile when `--profile` is absent.

Use [Agent workflow](/agents) for the retrieval sequence that turns tool results into a
source-grounded claim.
