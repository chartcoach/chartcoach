Install the MCP server with the dependency boundary required by its tools:

```bash
uvx --from 'chartcoach[mcp,curation]@latest' chartcoach mcp
```

The server registers `sql`. It also registers `search` when an index is
configured.

```bash
uvx --from 'chartcoach[mcp,curation]@latest' chartcoach mcp \
  --profile sentence-transformers/all-MiniLM-L6-v2
```

`sql` runs one read-only `SELECT` over the catalog tables. `search` accepts a
query string, mode, limit, optional LanceDB filter, and an optional
caller-provided vector. Vector and hybrid modes require that vector.

## Local sources

Use a compiled catalog bundle and LanceDB directory during local development:

```bash
uvx --from 'chartcoach[mcp,index]@latest' chartcoach mcp \
  --source ./dist/catalog \
  --index ./dist/index
```

## Network transports

The default transport is `stdio`. SSE and streamable HTTP accept host, port,
and log-level settings.

```bash
chartcoach mcp \
  --transport streamable-http \
  --host 127.0.0.1 \
  --port 8000 \
  --log-level info
```

Use `CHARTCOACH_SOURCE`, `CHARTCOACH_INDEX`, and
`CHARTCOACH_INDEX_PROFILE` to configure catalog and index selection for a
managed process.
