Install the MCP server:

```bash
uvx --from 'chartcoach[mcp]@latest' chartcoach mcp
```

The server always registers `sql`. Install the index capability and select a
profile to register `search`:

```bash
uvx --from 'chartcoach[mcp,index]@latest' chartcoach mcp \
  --source https://artifacts.chartcoach.dev/catalog.json \
  --profile sentence-transformers/all-MiniLM-L6-v2
```

The catalog and profile resolve through the same release envelope. `sql` runs
one read-only `SELECT` over catalog tables. `search` accepts a query string,
mode, limit, optional LanceDB filter, and an optional caller-provided vector.
Vector and hybrid modes require that vector.

## Exact release

Use an exact `release.json` source for deterministic runs:

```bash
chartcoach mcp \
  --source https://artifacts.chartcoach.dev/catalog/releases/<digest>/release.json \
  --profile sentence-transformers/all-MiniLM-L6-v2
```

## Network transports

The default transport is `stdio`. SSE and streamable HTTP accept host, port,
and log-level settings.

```bash
chartcoach mcp \
  --transport streamable-http \
  --host 127.0.0.1 \
  --port 8000 \
  --log-level info
```

Use `CHARTCOACH_SOURCE` and `CHARTCOACH_INDEX_PROFILE` for managed processes.
