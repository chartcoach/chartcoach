Catalog queries return candidate ids through three retrieval paths.

| Question shape                           | Use            | Returns                    |
| ---------------------------------------- | -------------- | -------------------------- |
| Known id, text fragment, or exact labels | `catalog list` | Guideline summaries        |
| Relationship across tables               | `catalog sql`  | Bounded relational rows    |
| Natural-language or section-level match  | `catalog find` | Ranked document candidates |

Every path returns candidate ids. Use `catalog read` before applying a selected
guideline as evidence.

## Filter deterministic fields

```bash
chartcoach catalog list \
  --label chart:line:use \
  --label-prefix operator: \
  --contains "label" \
  --limit 10 \
  --format json
```

Repeated `--label` filters use all-of matching. Repeated `--label-prefix`
filters require a match for each prefix. Run `catalog labels` and `catalog
roles` before copying vocabulary into a script.

## Join catalog tables

Inspect the live tables and columns:

```bash
chartcoach catalog schema --tables --row-counts
chartcoach catalog schema guidelines guideline_labels
```

This query finds guidelines that combine a chart recommendation with an
uncertainty operation:

```bash
chartcoach catalog sql "
  select distinct g.id, g.title
  from guidelines g
  join guideline_labels chart
    on chart.guideline_id = g.id
  join guideline_labels operation
    on operation.guideline_id = g.id
  where chart.family = 'chart'
    and chart.modifier = 'use'
    and operation.label = 'operator:uncertainty'
  order by g.id
  limit 20
" --format json
```

`catalog sql` accepts one read-only `SELECT` and applies its own result limit.
The queryable tables are `guidelines`, `sections`, `guideline_labels`,
`references`, `guideline_references`, and `guideline_sources`.

## Search section text

Indexed roles make the matched part of a guideline explicit. Section roles use
the `section.<role>` form:

```bash
chartcoach catalog find \
  --profile sentence-transformers/all-MiniLM-L6-v2 \
  --mode fts \
  --where "role = 'section.mistakes'" \
  --limit 5 \
  --format json \
  "legend makes the lines hard to identify"
```

Read the matched role from the selected record:

```bash
chartcoach catalog read <guideline-id> \
  --section mistakes \
  --source-detail full \
  --format markdown
```

Full-text search needs no embedding provider. Vector and hybrid modes use the
profile's vector space and receive the query vector from the caller.

Use [Python](/python) when the application should compose Polars, DuckDB, or
native LanceDB queries directly.
