Use this page after [Getting started](/getting-started) when a chart question
needs filters, section text search, SQL joins, or indexed discovery. Use the CLI
for inspection, Python for dataframe work, and TypeScript when an app needs
loaded guideline records. Candidate rows provide ids for later `read` and
`cite` calls.

## Candidate rows

Find guideline ids from a chart-decision label:

```bash tab="CLI"
uvx chartcoach@latest catalog query \
  --label chart:bar:use \
  --limit 5 \
  --format jsonl
```

```python tab="Python"
import chartcoach
import polars as pl

catalog = chartcoach.open().catalog
rows = (
    catalog.guidelines()
    .filter(pl.col("labels").list.contains("chart:bar:use"))
    .select("id", "title", "labels")
    .head(5)
)
```

```ts tab="TypeScript"
import { DEFAULT_CATALOG, loadCatalog } from "@chartcoach/catalog"

const { entriesUrl, manifestUrl } = DEFAULT_CATALOG
const entries = await (await fetch(entriesUrl)).arrayBuffer()
const manifestText = await (await fetch(manifestUrl)).text()
const catalog = await loadCatalog({ entries, manifestText })
const rows = catalog.guidelines
  .filter((guideline) => guideline.labels.includes("chart:bar:use"))
  .slice(0, 5)
  .map(({ id, title, labels }) => ({ id, title, labels }))
```

## Vocabulary filters

List available values before hard-coding a label, label family, or section
role:

```bash
uvx chartcoach@latest catalog values labels --contains chart: --format jsonl
uvx chartcoach@latest catalog values roles --format jsonl
```

`chart:bar:use` finds guidelines that recommend bar charts.

```bash tab="CLI"
uvx chartcoach@latest catalog query \
  --label chart:bar:use \
  --limit 5 \
  --format jsonl
```

In Python, use `catalog.guideline_labels()` and `catalog.sections()`. In
TypeScript, use `catalog.labels()` and `catalog.sectionRoles()`.

## Read and cite

Use exact ids for final text and citations.

```bash tab="CLI"
uvx chartcoach@latest catalog read compare-percentages-with-bars-not-pies \
  --source-detail minimal \
  --format json

uvx chartcoach@latest catalog cite compare-percentages-with-bars-not-pies \
  --format json
```

```python tab="Python"
import chartcoach
from chartcoach.catalog.references import citation_records

catalog = chartcoach.open().catalog
entry = catalog.entry("compare-percentages-with-bars-not-pies")
citations = citation_records(
    catalog,
    ids=["compare-percentages-with-bars-not-pies"],
)
```

```ts tab="TypeScript"
import { CHARTCOACH_DEFAULTS, DEFAULT_CATALOG, loadCatalog } from "@chartcoach/catalog"

const { entriesUrl, manifestUrl } = DEFAULT_CATALOG
const entries = await (await fetch(entriesUrl)).arrayBuffer()
const manifestText = await (await fetch(manifestUrl)).text()
const catalog = await loadCatalog({ entries, manifestText })
const guideline = catalog.require("compare-percentages-with-bars-not-pies")
const url = CHARTCOACH_DEFAULTS.guidelineUrlTemplate.replace("{id}", guideline.id)
```

The CLI prints formatted citation output. Python exposes structured citation
records. TypeScript exposes guideline records and ids for application links.

## Search section text

Search section text when titles and descriptions are too narrow:

```bash
uvx chartcoach@latest catalog query \
  --section-contains "small differences" \
  --show-matches \
  --limit 5 \
  --format jsonl
```

## SQL joins and indexed search

Use SQL when the question spans tables. This query ranks paper authors by the
number of distinct guidelines that cite their published papers:

```bash
uvx chartcoach@latest catalog sql "
with paper_sources as (
  select
    gr.guideline_id,
    r.id as reference_id,
    unnest(r.authors) as author
  from guideline_references gr
  join \"references\" r on r.id = gr.reference_id
  where r.authors is not null
    and r.source_type in ('article', 'inproceedings', 'incollection')
)
select
  author,
  count(distinct guideline_id) as guideline_count,
  count(distinct reference_id) as source_count
from paper_sources
group by author
order by guideline_count desc, source_count desc, author
limit 5
" --format jsonl
```

```python tab="Python"
import chartcoach

catalog = chartcoach.open().catalog
conn = catalog.duckdb()
try:
    rows = conn.sql("""
        with paper_sources as (
          select
            gr.guideline_id,
            r.id as reference_id,
            unnest(r.authors) as author
          from guideline_references gr
          join "references" r on r.id = gr.reference_id
          where r.authors is not null
            and r.source_type in ('article', 'inproceedings', 'incollection')
        )
        select
          author,
          count(distinct guideline_id) as guideline_count,
          count(distinct reference_id) as source_count
        from paper_sources
        group by author
        order by guideline_count desc, source_count desc, author
        limit 5
    """).pl()
finally:
    conn.close()
```

The `source_type` predicate limits the join to academically published source
records: journal articles, conference papers, and book chapters. Remove or
change that predicate when a query should rank all catalog sources, including
standards, practitioner posts, and preprints. The result has `author`,
`guideline_count`, and `source_count` columns. Author names are counted as
stored in the catalog source records.

Use indexed discovery when keyword filters miss plausible guidelines:

```bash
uvx --from 'chartcoach[index]@latest' chartcoach catalog find \
  --mode fts \
  --limit 5 \
  --format compact \
  "overplotted scatter plot with too many points"
```

The first indexed command downloads and extracts the package-pinned index.
Python callers can use `chartcoach.open().search(...)` to resolve and query
that index without hardcoding the cache path. For TypeScript joins, use the
nested records returned by `loadCatalog()`. The [Cataloging scheme](/catalog)
lists tables, columns, source locators, and manifest vocabulary.
