---
title: Querying
description: Find, filter, read, cite, join, and search chartcoach guidelines from CLI, Python, and TypeScript.
---

Start with a catalog question. Use the CLI for inspection, Python for dataframe
work, and TypeScript when an app needs loaded guideline records. Candidate rows
provide ids for later `read` and `cite` calls.

## Candidate rows

Find guideline ids from a topic phrase:

```bash tab="CLI"
uvx chartcoach@latest catalog query \
  --contains "legend" \
  --limit 5 \
  --format table
```

```python tab="Python"
import polars as pl
from chartcoach import Catalog

catalog = Catalog.open()
rows = (
    catalog.guidelines()
    .filter(
        pl.col("title").str.contains("legend", literal=True)
        | pl.col("description").str.contains("legend", literal=True)
    )
    .select("id", "title", "labels")
    .head(5)
)
```

```ts tab="TypeScript"
import { DEFAULT_CATALOG, loadCatalog } from "@chartcoach/catalog"

const [entries, manifestText] = await Promise.all([
  fetch(DEFAULT_CATALOG.entriesUrl).then((response) => response.arrayBuffer()),
  fetch(DEFAULT_CATALOG.manifestUrl).then((response) => response.text()),
])
const catalog = await loadCatalog({ entries, manifestText })
const rows = catalog.guidelines
  .filter((guideline) =>
    guideline.title.toLowerCase().includes("legend")
    || guideline.description.toLowerCase().includes("legend")
  )
  .slice(0, 5)
  .map(({ id, title, labels }) => ({ id, title, labels }))
```

## Vocabulary filters

List available values before hard-coding a label, label family, or section
role:

```bash
uvx chartcoach@latest catalog values labels --contains chart: --format jsonl
uvx chartcoach@latest catalog values roles --format jsonl
```

`chart:bar:use` finds guidelines that recommend bar charts.

```bash tab="CLI"
uvx chartcoach@latest catalog query \
  --label chart:bar:use \
  --limit 5 \
  --format jsonl
```

In Python, use `catalog.guideline_labels()` and `catalog.sections()`. In
TypeScript, use `catalog.labels()` and `catalog.sectionRoles()`.

## Read and cite

Use exact ids for final text and citations.

```bash tab="CLI"
uvx chartcoach@latest catalog read compare-percentages-with-bars-not-pies \
  --source-detail minimal \
  --format markdown

uvx chartcoach@latest catalog cite compare-percentages-with-bars-not-pies \
  --format markdown
```

```python tab="Python"
from chartcoach import Catalog
from chartcoach.catalog.references import citation_records

catalog = Catalog.open()
entry = catalog.entry("compare-percentages-with-bars-not-pies")
citations = citation_records(
    catalog,
    ids=["compare-percentages-with-bars-not-pies"],
)
```

```ts tab="TypeScript"
import { DEFAULT_CATALOG, loadCatalog } from "@chartcoach/catalog"

const [entries, manifestText] = await Promise.all([
  fetch(DEFAULT_CATALOG.entriesUrl).then((response) => response.arrayBuffer()),
  fetch(DEFAULT_CATALOG.manifestUrl).then((response) => response.text()),
])
const catalog = await loadCatalog({ entries, manifestText })
const guideline = catalog.require("compare-percentages-with-bars-not-pies")
const url = `https://chartcoach.dev/guidelines/${guideline.id}/`
```

The CLI prints formatted citation output. Python exposes structured citation
records. TypeScript exposes guideline records and ids for application links.

## Search section text

Search section text when titles and descriptions are too narrow:

```bash
uvx chartcoach@latest catalog query \
  --section-contains "small differences" \
  --show-matches \
  --limit 5 \
  --format table
```

## SQL joins and indexed search

Use SQL when the question spans tables:

```bash
uvx chartcoach@latest catalog sql "
select g.id, g.title, s.role, s.content
from guidelines g
join sections s on s.guideline_id = g.id
where list_contains(g.labels, 'chart:bar:use')
  and s.role = 'advice'
limit 5
" --format jsonl
```

Use indexed discovery when keyword filters miss plausible guidelines:

```bash
uvx --from 'chartcoach[index]@latest' chartcoach catalog find \
  --mode fts \
  --limit 5 \
  --format compact \
  "overplotted scatter plot with too many points"
```

For Python joins, use `catalog.duckdb()`. For Python indexed search, use
`default_index_path()` with `chartcoach.search.open()`. For TypeScript joins,
use the nested records returned by `loadCatalog()`. The
[Catalog contract](/catalog) lists tables, columns, source locators, and
manifest vocabulary.
