Start with deterministic catalog navigation:

```bash
uvx --from 'chartcoach[curation]@latest' chartcoach catalog list \
  --contains "axis labels" \
  --limit 10 \
  --format json
```

Use `labels` and `roles` to inspect the manifest vocabulary before adding exact
filters.

```bash
chartcoach catalog labels --contains "bar"
chartcoach catalog roles
chartcoach catalog list --label chart:bar:use
```

## SQL

`catalog sql` runs one read-only `SELECT` over the catalog tables.

```bash
chartcoach catalog schema --tables --row-counts
chartcoach catalog schema sections guideline_sources

chartcoach catalog sql "
  select distinct g.id, g.title
  from guidelines g
  join sections s on s.guideline_id = g.id
  where s.content ilike '%uncertainty%'
  order by g.id
  limit 20
" --format json
```

The tables are `guidelines`, `sections`, `guideline_labels`, `references`,
`guideline_references`, and `guideline_sources`.

## Indexed discovery

`catalog find` searches the native LanceDB `documents` table and deduplicates
document matches by guideline id.

```bash
chartcoach catalog find \
  --profile sentence-transformers/all-MiniLM-L6-v2 \
  --mode fts \
  --where "role = 'overview'" \
  --limit 10 \
  "direct labels"
```

Vector and hybrid modes receive one `--vector` value per dimension from the
caller.

## Native LanceDB

Python callers receive the LanceDB table itself:

```python
from chartcoach import open_index

table = open_index(
    "<64-character-release-digest>",
    profile="sentence-transformers/all-MiniLM-L6-v2",
)

fts = table.search("direct labels", query_type="fts", fts_columns="text")
rows = fts.where("role = 'overview'").limit(10).to_list()
```

Compose vector search with an application-provided vector:

```python
query_vector = embed("direct labels")
rows = (
    table.search(
        query_vector,
        query_type="vector",
        vector_column_name="vector",
    )
    .distance_type("cosine")
    .limit(10)
    .to_list()
)
```

Read each selected guideline with `catalog read` before using it as evidence.
