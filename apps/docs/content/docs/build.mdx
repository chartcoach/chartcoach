`catalog build` validates an authored folder and writes a compiled bundle with
`MANIFEST.md` and `entries.parquet`.

## Author one record

Create this source tree:

```text
catalog-source/
├── MANIFEST.md
└── entries/
    └── direct-labels/
        └── guideline.md
```

Define the vocabulary in `MANIFEST.md`:

```md
# Sample Catalog

## Section Roles

### advice

Actionable guidance for applying the guideline.

## Label Families

### chart

Chart-family labels such as `chart:line`.
```

Write `entries/direct-labels/guideline.md`:

```md
---
id: direct-labels
title: Use direct labels
description: Label marks directly when space permits.
labels:
  - chart:line
---

## Advice <!-- role: advice -->

Place the label close to the mark it names.
```

An entry can name `references.bib` through its frontmatter and cite those
BibTeX records from section text.

## Compile and inspect

```bash
chartcoach catalog validate --source ./catalog-source
chartcoach catalog build \
  --source ./catalog-source \
  --out ./dist/catalog

chartcoach catalog overview --source ./dist/catalog
chartcoach catalog read --source ./dist/catalog direct-labels
```

The output directory must be new. A failed build removes the partial directory
so the next run starts from a known state.

## Build a release

Install curation dependencies and create each embedding function through the
LanceDB registry:

```bash
uv pip install \
  "chartcoach[curation] @ https://files.peter.gy/packages/python/chartcoach/0.2.0/5cc92c6f032d/chartcoach-0.2.0-py3-none-any.whl" \
  sentence-transformers==5.6.1
```

```python
from pathlib import Path

from lancedb.embeddings import get_registry

from chartcoach import open_catalog
from chartcoach.catalog.curation import EmbeddingProfile, build_release

embedding = get_registry().get("sentence-transformers").create(
    name="all-MiniLM-L6-v2",
    device="cpu",
    normalize=True,
    trust_remote_code=False,
)

release = build_release(
    open_catalog("dist/catalog"),
    Path("dist/release"),
    profiles={
        "sentence-transformers/all-MiniLM-L6-v2": EmbeddingProfile(
            embedding=embedding,
            umap={
                "n_neighbors": 15,
                "min_dist": 0.1,
                "metric": "cosine",
                "random_state": 42,
            },
        )
    },
)

print(release.digest)
```

Each profile receives its own Parquet documents, projection, neighbors, and
LanceDB archive inside the release.

## Publish and select

Validate the release, preview the remote keys, publish the immutable directory,
then select its digest:

```bash
chartcoach catalog release validate ./dist/release
chartcoach catalog release publish \
  ./dist/release \
  --store s3://chartcoach \
  --dry-run
chartcoach catalog release publish \
  ./dist/release \
  --store s3://chartcoach
chartcoach catalog release select \
  "$RELEASE_DIGEST" \
  --store s3://chartcoach
```

Publication writes `catalog/releases/<digest>/`. Selection verifies those
objects and updates `catalog.json` with the full release envelope.

Use [Catalog model](/catalog) for the row, manifest, and release contracts.
