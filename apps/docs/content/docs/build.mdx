`catalog build` compiles an authored folder into `MANIFEST.md` and
`entries.parquet`.

## Author one guideline

Create the source tree:

```text
catalog-source/
├── MANIFEST.md
└── entries/
    └── direct-labels/
        └── guideline.md
```

Define every section role and label family in `MANIFEST.md`:

```md
# Sample Catalog

## Section Roles

### advice

Actionable guidance for applying the guideline.

## Label Families

### chart

Chart-family labels such as `chart:line`.
```

Write the guideline:

```md
---
id: direct-labels
title: Use direct labels
description: Label marks directly when space permits.
labels:
  - chart:line
---

## Advice <!-- role: advice -->

Place the label close to the mark it names.
```

An entry may declare `bibliography: references.bib` in its frontmatter and cite
that file from section text.

## Build the bundle

Validate the authored folder, then compile it into a new directory:

```bash
chartcoach catalog validate --source ./catalog-source
chartcoach catalog build \
  --source ./catalog-source \
  --out ./dist/catalog
```

Read the compiled result through the same catalog API:

```bash
chartcoach catalog overview --source ./dist/catalog
chartcoach catalog read --source ./dist/catalog direct-labels
```

## Build a release

Install curation dependencies and create native LanceDB embedding functions
through the LanceDB registry.

```bash
uv add 'chartcoach[curation]' sentence-transformers
```

```python
from pathlib import Path

from lancedb.embeddings import get_registry

from chartcoach import open_catalog
from chartcoach.catalog.curation.release_builder import (
    EmbeddingProfile,
    build_catalog_release,
)

registry = get_registry()
small = registry.get("sentence-transformers").create(
    name="all-MiniLM-L6-v2",
    device="cpu",
    normalize=True,
    trust_remote_code=False,
)

release = build_catalog_release(
    open_catalog("dist/catalog"),
    root=Path("dist/release"),
    profiles={
        "sentence-transformers/all-MiniLM-L6-v2": EmbeddingProfile(
            embedding=small,
            umap={
                "n_neighbors": 15,
                "min_dist": 0.1,
                "metric": "cosine",
                "random_state": 42,
            },
        ),
    },
)

print(release.digest)
```

Add another mapping entry for each vector space. An on-device model and a
hosted model can share one release while preserving their separate vectors,
projections, neighbors, and LanceDB metadata.

The release directory contains the core catalog and one artifact pair per
profile:

```text
release/
├── release.json
├── MANIFEST.md
├── entries.parquet
└── profiles/
    └── sentence-transformers/all-MiniLM-L6-v2/
        ├── documents.parquet
        └── index.tar.gz
```

The profile Parquet file is ready for Embedding Atlas:

```bash
embedding-atlas \
  dist/release/profiles/sentence-transformers/all-MiniLM-L6-v2/documents.parquet \
  --text text \
  --vector vector \
  --x projection_x \
  --y projection_y \
  --neighbors neighbors
```

## Publish and select

Release publication writes through the Obspec storage contract. Obstore
provides local and S3-compatible implementations.

```bash
chartcoach catalog release validate ./dist/release
chartcoach catalog release publish \
  ./dist/release \
  --store s3://chartcoach \
  --dry-run
chartcoach catalog release publish \
  ./dist/release \
  --store s3://chartcoach
chartcoach catalog release select \
  "$RELEASE_DIGEST" \
  --store s3://chartcoach
```

Publication writes immutable objects under
`catalog/releases/<digest>/`. Selection reads that published release and writes
its full record to `catalog.json`.

Prefetch the selected catalog and one profile into the local platform cache:

```bash
chartcoach catalog cache pull \
  --profile sentence-transformers/all-MiniLM-L6-v2
```

Cache entries are disposable. A missing or incomplete entry is downloaded
again on the next pull or open operation.
