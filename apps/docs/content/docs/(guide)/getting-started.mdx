This example opens the public catalog, reads a guideline about direct
labels, and retrieves its citations. It needs network access on the first run.

## Set up Python

Use [uv](https://docs.astral.sh/uv/), the Python environment manager, to create
an environment and install chartcoach. In a POSIX shell:

```bash
uv venv
source .venv/bin/activate
uv pip install chartcoach
```

Keep this environment active for the Python and CLI examples in these docs.
For Node.js setup, see [JavaScript and TypeScript](/javascript#install).

## Read a guideline

Save this as `read-guideline.py`:

```python title="read-guideline.py"
from chartcoach import open_catalog

catalog = open_catalog()
guideline_id = "directly-label-series-instead-of-using-a-color-key"
record = catalog.read(ids=[guideline_id])[0]
print(record["title"])
```

Run it:

```bash
python read-guideline.py
```

Expected output:

```text
Directly label colored series instead of relying on a color key
```

`record` contains the guideline's labels, ordered sections, and parsed source
details. `open_catalog()` opens the currently selected public release,
verifies downloaded files, and keeps them in your user cache.

## Read the advice and cite its source

Add these lines to the same file and run it again:

```python
for section in record["sections"]:
    if section["role"] == "advice":
        print(section["content"])

citation = catalog.cite(ids=[guideline_id])[0]
print(citation["guideline_citation"])
for source in citation["sources"]:
    print(source["citation"])
```

The output contains the advice, a link to the guideline, and its source
citation. Use [Find guidelines](/querying) to choose records for your own task,
or [Open and cache catalogs](/catalogs) to use another catalog.
