The Guideline Catalog stores visualization guidelines with their labels,
sections, and BibTeX references. This live Python example opens a fixed catalog
release, displays its entry rows as a Polars dataframe, and renders the first
record as JSON.

## Open a catalog release

The `release.json` URL identifies one exact set of files. `open_catalog`
verifies those files before it returns the catalog.

```python marimo echo=true
from chartcoach import open_catalog

catalog = open_catalog(
    "https://files.peter.gy/packages/python/chartcoach/0.2.0/docs-catalog/c0f6dbec3dd31b07763b46fd458733db0b8b50c5793cf9447458119287129420/release.json"
)
df = catalog.to_frame()
df
```

`df` contains one row per guideline entry. Its six columns hold the entry ID,
title, description, labels, sections, and references.

## Inspect the first guideline

`named=True` returns a dictionary keyed by the dataframe column names.
`mo.json` displays the nested labels, sections, and references as expandable
JSON in a scrollable panel.

```python marimo echo=true
import marimo as mo

row = df.row(0, named=True)
mo.Html(
    '<div tabindex="0" role="region" aria-label="Guideline JSON" '
    f'style="max-height:32rem;overflow:auto">{mo.json(row).text}</div>'
)
```

The dataframe gives a compact overview of the catalog. The dictionary shows
all six fields stored in the selected dataframe row.
