chartcoach follows the open
[Agent Plugins specification](https://agent-plugins.org/). An Agent Plugin is a
package directory that exposes Agent Skills and Model Context Protocol (MCP)
servers through fixed, portable locations. Installing chartcoach carries those
components beside the Python library at the same version.

## Call chartcoach from code mode

Install chartcoach in the Python environment used by the agent:

```bash
uv add chartcoach
```

A code-mode agent can inspect the module workflow, search for candidates, read
the selected record, and retain its source citations:

```python
import chartcoach.agent as cc

help(cc)
tools = cc.Tools.open()
catalog = tools.catalog
candidates = cc.query_entries(
    catalog,
    contains="direct labels",
    limit=5,
    include_body=False,
).to_dicts()

guideline_id = candidates[0]["id"]
record = cc.retrieve_entry_records(
    catalog,
    ids=[guideline_id],
    source_detail="full",
)[0]
citations = cc.citation_records(catalog, ids=[guideline_id])
```

`Tools.open()` binds SQL and optional indexed search to the same catalog
release. `query_entries()` returns candidate rows. `retrieve_entry_records()`
returns the full guideline, and `citation_records()` retains its public link
and source citations.

## Inspect the Agent Plugin

`cc.agent_plugin()` returns the installed `agent_plugins.Plugin`. Its skills
and MCP configuration match the installed chartcoach version:

```python
plugin = cc.agent_plugin()
core = plugin.skill("core")

print(plugin.tree())
print(core.source)
print(core.file("SKILL.md"))

if plugin.mcp is not None:
    print(plugin.mcp.servers)
```

The Python package contains five focused Agent Skills:

| Skill         | Task                                                             |
| ------------- | ---------------------------------------------------------------- |
| `core`        | Choose a catalog, find records, read them, and format citations  |
| `discuss`     | Compare visualization choices and explain tradeoffs              |
| `visfeedback` | Review a rendered chart or screenshot                            |
| `visrec`      | Recommend a chart from the data, task, audience, and constraints |
| `contribute`  | Draft a catalog issue for human review                           |

`cc.agent_skills()` returns them in chartcoach workflow order.

[marimo](https://docs.marimo.io/) is one environment for code-mode agents. It
discovers `chartcoach.agent` through the installed `marimo.agent.capability`
entry point. Other agents can import the same module or inspect the standard
Agent Plugin directory through their own client integration.

## Use the terminal workflow

Agents that operate through a terminal can read the same packaged instructions
through the CLI. This workflow assumes `uv` and the Codex CLI are available:

```bash
uv tool install \
  "chartcoach @ https://files.peter.gy/packages/python/chartcoach/0.2.0/892f120cb377/chartcoach-0.2.0-py3-none-any.whl"
chartcoach --version
chartcoach skills get core --full > chartcoach-core.md
```

`chartcoach-core.md` contains the catalog workflow and its command reference.

### Find a guideline

Set the catalog once, then search its IDs, titles, and descriptions for
`direct labels`:

```bash
CATALOG_SOURCE="https://files.peter.gy/packages/python/chartcoach/0.2.0/docs-catalog/c0f6dbec3dd31b07763b46fd458733db0b8b50c5793cf9447458119287129420/release.json"

chartcoach catalog list \
  --source "$CATALOG_SOURCE" \
  --contains "direct labels" \
  --limit 5 \
  --format json
```

The result includes this ID:

```bash
GUIDELINE_ID="directly-label-series-instead-of-using-a-color-key"
```

### Read and cite it

Candidate results contain summaries. Read the selected record for its full
advice, reasons, limits, checks, fixes, and source information:

```bash
chartcoach catalog read "$GUIDELINE_ID" \
  --source "$CATALOG_SOURCE" \
  --source-detail full \
  --format markdown

chartcoach catalog cite "$GUIDELINE_ID" \
  --source "$CATALOG_SOURCE" \
  --format markdown
```

The first command provides the text an agent should evaluate against the
current chart. The second provides the public guideline link and formatted
source citations.

### Ask the agent

Save the chart as `chart.png`, then give the image and instructions to the
agent:

```bash
codex -i chart.png \
  'Read chartcoach-core.md, then review the attached chart for labels and accessibility.'
```

A sound answer connects each suggested change to a visible fact about the
chart, the applicable guideline section, any tradeoff or uncertainty, and the
source citation.
