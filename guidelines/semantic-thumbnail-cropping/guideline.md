## The Rule <!-- role: advice -->
When creating thumbnails for data visualizations, crop or carve the image to retain the title and the most visually salient data regions (often the extremes), rather than simply shrinking the image or cropping the geometric center.

## The Logic <!-- role: reason -->
Standard resizing makes text illegible, and center cropping often misses the title or axis labels required for context. Importance-driven retargeting preserves the "energy" of the image (high-importance pixels).
*   **The Principle:** Information Preservation.
*   **The Evidence:** User studies in [@bylinskii_learning_2017] showed that participants found visualizations significantly faster (1.96 clicks vs 3.25 clicks) when navigating a database using thumbnails generated by importance-driven cropping compared to standard resizing. The model prioritized titles, legends, and graph extremes.

## Where to Apply <!-- role: context -->
*   **User Goal:** Browsing a gallery or database of reports/dashboards to find a specific file.
*   **Data Type:** Collections of charts, dashboards, or infographics.
*   **Audience:** Users performing visual search tasks.

## When to Break It <!-- role: exceptions -->
*   **Scenario:** Precise layout evaluation.
*   **Reason:** If the user is browsing templates to judge whitespace or overall page balance, a cropped thumbnail misrepresents the actual layout.

## The Price <!-- role: costs -->
*   **The Sacrifice:** Contextual completeness. You lose the "less important" data points.
*   **The Risk:** Misrepresentation. If the "most important" region is an outlier, the thumbnail might suggest a trend that doesn't exist in the full data.

## Common Mistakes <!-- role: mistakes -->
*   **The Wrong Fix:** Uniform scaling (shrinking).
*   **Why it fails:** Text becomes illegible, rendering the thumbnail useless for distinguishing between similar chart types with different topics.

## How to Check <!-- role: check -->
*   **Visual Sign:** Can you read the title in the thumbnail?
*   **The Test:** Look at the thumbnail grid. Can you verbally describe the topic of each chart without opening it?

## How to Fix <!-- role: fix -->
*   **Quick Fix:** Always ensure the top header/title region is included in the crop.
*   **Best Fix:** Use an importance-detection algorithm (or manual selection) to create a composite thumbnail that stitches the title and the main chart area together, removing empty space.
