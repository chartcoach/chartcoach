## The Rule <!-- role: advice -->

Do not treat different icon types in icon arrays as equivalent; test icon type as a design variable when evaluating risk communication outcomes.

## The Logic <!-- role: reason -->

- **The Principle:** Seemingly “cosmetic” graphical details can alter cognitive processing and downstream outcomes.
- **The Evidence:** The study found significant differences across icon types in recall, and differences in perceived-to-actual risk correlations within higher numeracy/graph literacy subgroups; restroom icons and photos often outperformed blocks/other icons on key outcomes [@zikmund-fisherBlocksOvalsPeople2014].

## Where to Apply <!-- role: context -->

- **User Goal:** Reliable, reproducible effects of a risk visualization (e.g., in decision aids, risk calculators, patient education).
- **Data Type:** Any icon array where you care about comprehension/recall/calibration, not just aesthetics.
- **Audience:** Especially mixed-ability populations where numeracy and graphical literacy vary.

## When to Break It <!-- role: exceptions -->

- **Scenario:** You are locked into a single mandated icon set (e.g., regulatory template) and cannot change icons.
- **Reason:** Testing icon type is impossible; focus evaluation effort on other adjustable parameters (not covered by this paper) [@zikmund-fisherBlocksOvalsPeople2014].

## The Price <!-- role: costs -->

- **The Sacrifice:** More design and research time (multiple variants, recruitment, analysis).
- **The Risk:** Without careful control, icon tests can be confounded by other visual differences (e.g., spacing/visual density noted as a plausible mechanism) [@zikmund-fisherBlocksOvalsPeople2014].

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Reporting results for “an icon array” without specifying the icon type.
- **Why it fails:** If icon type affects outcomes, lack of specification reduces interpretability and comparability across studies/tools [@zikmund-fisherBlocksOvalsPeople2014].

## How to Check <!-- role: check -->

- **Visual Sign:** Design discussions frame icon choice as purely decorative (“any pictograph will do”).
- **The Test:** Hold all else constant (denominator, colors, layout) and swap only icon type; measure recall and preference, and examine perceived-vs-actual risk alignment [@zikmund-fisherBlocksOvalsPeople2014].

## How to Fix <!-- role: fix -->

- **Quick Fix:** Run a small internal A/B comparing your current icon to restroom icons on delayed recall.
- **Best Fix:** Build icon type into your evaluation plan as a factor, and report icon choice explicitly in documentation/publications [@zikmund-fisherBlocksOvalsPeople2014].
