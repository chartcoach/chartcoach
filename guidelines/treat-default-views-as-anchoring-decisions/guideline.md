## The Rule <!-- role: advice -->

Treat the initial state (default view, default variable, default zoom) as an editorial choice that anchors interpretation—set it deliberately.

## The Logic <!-- role: reason -->

Procedural rhetoric includes anchoring via default views and fixed comparisons; the first view becomes the interpretive starting point and makes some patterns more probable than others.

- **The Principle:** Anchoring through interaction defaults
- **The Evidence:** [@hullmanVisualizationRhetoricFraming2011a]

## Where to Apply <!-- role: context -->

- **User Goal:** Quickly “get the story” on first load
- **Data Type:** Multi-view or multi-variable interactive narratives
- **Audience:** Casual readers who may not explore beyond the first view

## When to Break It <!-- role: exceptions -->

- **Scenario:** Tools meant for open-ended exploration rather than a specific story
- **Reason:** A strong default can over-constrain and bias exploration paths [@hullmanVisualizationRhetoricFraming2011a].

## The Price <!-- role: costs -->

- **The Sacrifice:** Neutrality (a default inevitably privileges something)
- **The Risk:** Users may mistake the default framing as the only valid framing.

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Picking a default that is easiest to implement rather than most defensible
- **Why it fails:** Convenience-driven defaults still anchor interpretation, just unintentionally [@hullmanVisualizationRhetoricFraming2011a].

## How to Check <!-- role: check -->

- **Visual Sign:** The “story” changes drastically when a different variable/view is selected first
- **The Test:** Swap the default to an alternative plausible view; if the takeaway changes, the default is rhetorically powerful and must be justified.

## How to Fix <!-- role: fix -->

- **Quick Fix:** Add a short annotation explaining why the default view is shown first.
- **Best Fix:** Provide multiple entry points (e.g., “Start with: A / B / C”) when editorial goals are plural.
