## The Rule <!-- role: advice -->
Do not duplicate spoken narration with simultaneous on-screen text. Choose one modality (preferably narration for animations) or the other.

## The Logic <!-- role: reason -->
Reading text and listening to the same words simultaneously causes the user to split attention between the auditory and visual streams to reconcile them.
*   **The Mechanism:** This creates incidental processing (Type 4 Overload). The learner wastes capacity checking if the text matches the audio, rather than processing the visual animation the text is supposed to support [@mayer_nine_2003].
*   **The Evidence:** This is the *Redundancy Effect*. Non-redundant presentations (narration only) resulted in better learning than redundant ones (narration + text) with a median effect size of 0.69 [@mayer_nine_2003].

## Where to Apply <!-- role: context -->
*   **User Goal:** Watching an animation or dynamic graphic while receiving an explanation.
*   **Data Type:** Narrated animations or video explanations.
*   **Audience:** General learners with normal hearing and language proficiency.

## When to Break It <!-- role: exceptions -->
*   **Scenario:** There is no animation/graphic present.
*   **Reason:** If the screen is static or blank, verbal redundancy does not overload the visual channel.
*   **Scenario:** Non-native speakers or accessibility needs.
*   **Reason:** Users struggling with the language may need text support to verify auditory input.
*   **Scenario:** Short key terms.
*   **Reason:** Displaying *only* key words (signaling) while narrating is helpful; displaying the full sentence is not.

## The Price <!-- role: costs -->
*   **The Sacrifice:** You cannot simply "paste" the script onto the screen.
*   **The Risk:** Users might miss a word if they get distracted (since the text isn't there to verify).

## Common Mistakes <!-- role: mistakes -->
*   **The Wrong Fix:** Reading bullet points off a PowerPoint slide while the audience reads them.
*   **Why it fails:** The audience reads faster than the speaker speaks, causing cognitive interference.

## How to Check <!-- role: check -->
*   **Visual Sign:** Is the screen filled with the exact text the narrator is speaking?
*   **The Test:** If you can read the script on screen, delete it.

## How to Fix <!-- role: fix -->
*   **Quick Fix:** Delete the text blocks, leaving only the animation.
*   **Best Fix:** Move the text to the "Notes" section (for reference) and keep the visual channel clear for the graphics/animation.
