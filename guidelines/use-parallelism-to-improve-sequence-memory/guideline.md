## The Rule <!-- role: advice -->

Structure your narrative so that multi-step transition patterns repeat across comparable parts of the story (i.e., use parallelism), and avoid reversing those patterns.

## The Logic <!-- role: reason -->

Parallelism (repeating a transition pattern) acts as a global structural cue; the study found better memory for “perfect” parallel sequences than for reversed variants, even though reversed variants could have lower summed local transition costs [@hullmanDeeperUnderstandingSequence2013].

- **The Principle:** Global structure (parallelism) supports memory beyond local transition cost
- **The Evidence:** In the parallelism experiment, non-reversed (“perfect” parallel) sequences produced significantly better sequence memory than reversed treatments [@hullmanDeeperUnderstandingSequence2013].

## Where to Apply <!-- role: context -->

- **User Goal:** Remember the order/structure of a multi-slide narrative
- **Data Type:** Two or more comparable groups/chapters where each has analogous views (e.g., the same views repeated for different groups or periods)
- **Audience:** Learners, meeting audiences, or readers who must recall the narrative later

## When to Break It <!-- role: exceptions -->

- **Scenario:** Your content does not naturally partition into comparable blocks with analogous views.
- **Reason:** Parallelism depends on having repeatable “slots” (comparable slides) to mirror [@hullmanDeeperUnderstandingSequence2013].

## The Price <!-- role: costs -->

- **The Sacrifice:** Reduced freedom to reorder locally “optimal” transitions if that disrupts global pattern repetition.
- **The Risk:** If the repeated pattern is not meaningful, it can feel formulaic.

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Creating a parallel pattern but reversing it mid-way (e.g., A→B→C in one block, then C→B→A in the next).
- **Why it fails:** The paper shows reversed variants harmed memory relative to the non-reversed parallel sequences [@hullmanDeeperUnderstandingSequence2013].

## How to Check <!-- role: check -->

- **Visual Sign:** Comparable story segments don’t “line up” (users can’t predict what comes next in the next segment).
- **The Test:** Write the transition types for each segment (e.g., {general→specific, then time step}); verify they repeat in the same order across segments.

## How to Fix <!-- role: fix -->

- **Quick Fix:** Reorder slides within segments so the same transition sequence repeats.
- **Best Fix:** Design the narrative as repeated motifs (transition-type patterns) across groups/chapters, and keep motif direction consistent [@hullmanDeeperUnderstandingSequence2013].
