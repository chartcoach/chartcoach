## The Rule <!-- role: advice -->

Use highlighting (color, size, boldness, motion) and connecting devices (arrows, shaded trails) to guide viewers through key story points.

## The Logic <!-- role: reason -->

The paper’s case analyses show that narrative pathing can be suggested rather than dictated: emphasis and connectors create a “soft” path that draws the eye to the intended sequence while preserving reader freedom.

- **The Principle:** Attention can be steered via salience and visual linkage to create narrative flow.
- **The Evidence:** [@segelNarrativeVisualizationTelling2010]

## Where to Apply <!-- role: context -->

- **User Goal:** Understand the intended takeaway in a multi-part, single-screen layout (e.g., poster-like compositions).
- **Data Type:** Multi-section layouts with multiple charts/images competing for attention.
- **Audience:** General audiences.

## When to Break It <!-- role: exceptions -->

- **Scenario:** The visualization is meant for open-ended analysis with no intended narrative order.
- **Reason:** Implied pathing may bias exploration and interpretation [@segelNarrativeVisualizationTelling2010].

## The Price <!-- role: costs -->

- **The Sacrifice:** Additional visual elements can add clutter.
- **The Risk:** Over-highlighting can drown out the data or make everything feel equally “important” [@segelNarrativeVisualizationTelling2010].

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Making many regions equally saturated/bold to “ensure visibility.”
- **Why it fails:** It removes hierarchy, so nothing guides attention [@segelNarrativeVisualizationTelling2010].

## How to Check <!-- role: check -->

- **Visual Sign:** Viewers’ eyes bounce randomly between sections; no clear starting point.
- **The Test:** Squint at the page; the intended first and next focal points should remain obvious through relative emphasis [@segelNarrativeVisualizationTelling2010].

## How to Fix <!-- role: fix -->

- **Quick Fix:** Reduce emphasis everywhere except the first/next narrative points.
- **Best Fix:** Add explicit connectors (arrows/shaded paths) that link narrative-related sections and reinforce hierarchy [@segelNarrativeVisualizationTelling2010].
