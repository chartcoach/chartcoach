## The Rule <!-- role: advice -->

If an on-screen element is important but static, make it attention-getting by revealing it (or otherwise changing its state) at the moment it matters.

## The Logic <!-- role: reason -->

Static elements can be neglected compared to moving or newly revealed ones; in the study, the static DNA label received far fewer fixations than the revealed photolyase label [@faradayDesigningEffectiveMultimedia1997].

- **The Principle:** Salience prioritization (onset/motion over static)
- **The Evidence:** [@faradayDesigningEffectiveMultimedia1997]

## Where to Apply <!-- role: context -->

- **User Goal:** Correctly notice and encode key terms/states.
- **Data Type:** Mixed static and dynamic components on the same screen.
- **Audience:** Novices who need stronger guidance on what matters.

## When to Break It <!-- role: exceptions -->

- **Scenario:** The content must remain continuously visible for reference.
- **Reason:** Repeated state changes may distract from continuous comparison tasks.

## The Price <!-- role: costs -->

- **The Sacrifice:** More transitions can increase cognitive load if overused.
- **The Risk:** Too many reveals reduce the “signal” of what is actually important.

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Leaving critical labels static while animating secondary objects.
- **Why it fails:** Users attend to the animated elements and miss the critical static information [@faradayDesigningEffectiveMultimedia1997].

## How to Check <!-- role: check -->

- **Visual Sign:** Users recall animated objects but omit key static labels/states.
- **The Test:** Free-recall scoring by proposition: if static-only propositions are missing, the static info wasn’t salient enough.

## How to Fix <!-- role: fix -->

- **Quick Fix:** Reveal the label/caption at the exact point it becomes relevant.
- **Best Fix:** Time salience: reveal or highlight the key static element, then hold the scene steady to allow inspection and encoding [@faradayDesigningEffectiveMultimedia1997].
