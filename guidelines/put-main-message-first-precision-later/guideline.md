## The Rule <!-- role: advice -->

Write the first-read text (especially the title) conversationally and memorably; put precise definitions, time windows, and constraints in less prominent text (description/notes).

## The Logic <!-- role: reason -->

Prominent precise wording can distract from the core message. Leading with the takeaway improves what readers notice and remember, while secondary text preserves accuracy for those who need details.

- **The Principle:** Prioritize gist first, then details
- **The Evidence:** [@muth_text_in_data_visualizations_2022]

## Where to Apply <!-- role: context -->

- **User Goal:** Grasp the main point quickly; optionally verify details
- **Data Type:** Explanatory storytelling charts where there is a clear main statement
- **Audience:** Mainstream audiences; readers skimming headlines and embeds [@muth_text_in_data_visualizations_2022]

## When to Break It <!-- role: exceptions -->

- **Scenario:** The precise definition is essential to avoid a likely misinterpretation of the main statement.
  - **Reason:** If gist-first would mislead, you must elevate the precision into the title or a prominent annotation [@muth_text_in_data_visualizations_2022].

## The Price <!-- role: costs -->

- **The Sacrifice:** Some readers may take away only the simplified message and miss nuance.
- **The Risk:** If secondary precision is too hidden, readers may not see important caveats [@muth_text_in_data_visualizations_2022].

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Packing the title with technical terms (e.g., statistical jargon) for mainstream audiences.
  - **Why it fails:** Slows comprehension and weakens memorability of the message [@muth_text_in_data_visualizations_2022].
- **The Wrong Fix:** Omitting precise definitions entirely.
  - **Why it fails:** Leaves readers unable to judge what exactly is measured or compared [@muth_text_in_data_visualizations_2022].

## How to Check <!-- role: check -->

- **Visual Sign:** The title reads like a variable definition rather than a statement a person would say.
- **The Test:** Can a reader understand the “what’s happening” message from the title alone, and then find the “exactly what is measured” in the description/notes? If not, rebalance [@muth_text_in_data_visualizations_2022].

## How to Fix <!-- role: fix -->

- **Quick Fix:** Rewrite the title in plain language, and move measurement windows/definitions into the description.
- **Best Fix:** Establish a clear hierarchy: title = takeaway, description = what is measured (timeframe/metric), notes = constraints/definitions [@muth_text_in_data_visualizations_2022].
