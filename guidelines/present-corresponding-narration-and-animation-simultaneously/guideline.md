## Synchronize words and pictures in time <!-- role: advice -->

Present narration at the same time as the corresponding animation rather than presenting all narration before or after all animation.

## Why synchronization reduces representational holding <!-- role: reason -->

When verbal and visual explanations are separated in time, learners must hold one representation in working memory while processing the other, consuming capacity needed for selecting, organizing, and integrating the explanation. Simultaneous presentation reduces the need for representational holding, making it easier to connect narration to the relevant visual events as they occur.

**Mechanism:** Temporal alignment minimizes working memory load spent on holding earlier information until its counterpart appears, supporting integration between verbal and pictorial models.

**Evidence:** Transfer was higher for simultaneous narration-plus-animation than for successive presentations across multiple experiments, consistent with a temporal contiguity effect [@mayerNineWaysReduce2003].

**Notes:** The holding burden is reduced when successive presentation is broken into small alternating segments.

## When timing gaps force memory holding <!-- role: context -->

- **User Goal:** Connect described steps to depicted steps accurately.
- **Task:** Integrate narration with matching visual events.
- **Data:** Time-ordered causal process with clear correspondence between words and images.
- **Chart Setting:** Multimedia lesson that can be scheduled as simultaneous or successive.
- **Audience:** Learners who may struggle to retain verbal/visual details across delays.
- **Success Criterion:** Improved transfer via better word–picture integration.

## When full synchronization is not possible <!-- role: exceptions -->

**Break it when:** System constraints force narration and animation to be delivered in separate blocks. **Why:** The required temporal contiguity cannot be achieved, so holding demands remain.

## Tradeoffs of synchronizing content <!-- role: costs -->

**Sacrifice:** Less flexibility for learners who want to first read/hear everything, then watch everything. **Risk:** Poorly synchronized pairing can create confusion if narration does not match the on-screen event. **Mitigation:** Ensure correspondence between each spoken phrase and the concurrent visual event.

## Common timing anti-patterns <!-- role: mistakes -->

**Mistake:** Playing the full narration first and then showing the full animation (or vice versa). **Why it fails:** Learners must retain one stream while processing the other, increasing cognitive load.

## Checks for temporal contiguity <!-- role: check -->

**Failure Sign:** Learners can repeat steps but cannot match them to visual events or explain causal links. **Quick Check:** For each key visual change, verify the corresponding narration occurs during that change. **Stronger Test:** Compare transfer for simultaneous versus successive versions with identical content.

## What to do if you must separate streams <!-- role: fix -->

- Break the lesson into small alternating chunks of narration and matching animation.
- Segment the experience so learners can control pacing between corresponding chunks.
- Pretrain component names and functions so less capacity is needed during integration.
- Signal key visual events so learners can more easily connect them to the verbal explanation.
