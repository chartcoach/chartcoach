## The Rule <!-- role: advice -->
Replace repetitive text or abstract dates with representative icons (such as flags or symbols) to add visual interest and break the "spreadsheet" look.

## The Logic <!-- role: reason -->
Tables often feel boring or intimidating because they look like raw data dumps. Using icons (like a soccer ball for a game or a flag for a country) makes the table feel like a designed visualization. It allows "fun" without sacrificing clarity, provided the total counts are listed elsewhere [@mintzer_compact_tables_2024].

## Where to Apply <!-- role: context -->
*   **User Goal:** Engaging the reader while showing categorical outcomes or event occurrences.
*   **Data Type:** Nominal data (countries, teams) or binary events (game played vs. not played).
*   **Audience:** General public or casual readers who might be turned off by dense text.

## When to Break It <!-- role: exceptions -->
*   **Scenario:** Precise data lookups.
*   **Reason:** If the user specifically needs to know the exact date (e.g., "June 29th") rather than just "a game occurred," replacing the date with a ball icon removes necessary information.

## The Price <!-- role: costs -->
*   **The Sacrifice:** Granular detail. Replacing a date string with an icon obscures the specific timestamp.
*   **The Risk:** Misinterpretation if the icons are not universally understood or labeled.

## Common Mistakes <!-- role: mistakes -->
*   **The Wrong Fix:** Using different colored text to represent categories.
*   **Why it fails:** It is often less accessible and visually distinct than an icon.

## How to Check <!-- role: check -->
*   **Visual Sign:** Is the table filled with repetitive text strings?
*   **The Test:** unexpected squint test—does the table look like an Excel screenshot or a graphic?

## How to Fix <!-- role: fix -->
*   **Quick Fix:** Add an emoji or icon next to the text.
*   **Best Fix:** If the specific text details (like exact dates) are secondary to the count/existence of the event, replace the text entirely with an icon.
