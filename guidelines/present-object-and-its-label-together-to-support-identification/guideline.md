## Show labels at the same time as the labeled object <!-- role: advice -->

Ensure the object and its label appear together so viewers can map the name to the visual referent during the same attention window.

## Co-presented label and object encourage gaze switching that integrates meaning <!-- role: reason -->

Viewers naturally shift fixation between a visible object and its visible label, supporting integration and identification; separating them in time or cueing one without the other can reduce correct mapping.

**Mechanism:** Alternating fixations between label and object supports binding of text to visual referent during working-memory processing.

**Evidence:** Eye tracking showed repeated fixation shifts between objects and their static labels when both were present, and speech-cued labels were re-fixated; recall was better for items reinforced with labels than for speech-only facts [@faradayDesigningEffectiveMultimedia1997].

**Notes:** This guideline targets identification (what the thing is), not necessarily deep understanding (what it does).

## When synchronized label-object presentation is essential <!-- role: context -->

- **User Goal:** Learn names of entities and distinguish similar entities.
- **Task:** Identify parts of a diagram/animation while following narration.
- **Data:** Multiple labeled objects, some visually similar or unfamiliar.
- **Chart Setting:** Narrated animation with on-screen labels and limited time per step.
- **Audience:** Low domain-knowledge viewers encountering new terminology.
- **Success Criterion:** Viewers can correctly name the object and reference it in recall.

## When it can be acceptable to decouple label and object <!-- role: exceptions -->

**Break it when:** The object is already familiar and the label is redundant. **Why:** Simultaneous labeling may add clutter without improving identification.

## Tradeoffs of always labeling with the object <!-- role: costs -->

**Sacrifice:** More on-screen text can reduce visual simplicity. **Risk:** Label clutter can create competing reading targets. **Mitigation:** Use brief labels and limit the number of simultaneous labeled items.

## Common mistakes with labels and objects <!-- role: mistakes -->

- **Mistake:** Showing labels without making the referenced object salient. **Why it fails:** Viewers may read the word but not bind it to the correct visual referent.
- **Mistake:** Introducing the object first and labeling it much later. **Why it fails:** The mapping opportunity is lost when attention has moved on.

## Quick checks for label-object integration <!-- role: check -->

**Failure Sign:** Users recall terms but misattribute them to the wrong visual element. **Quick Check:** Ask a viewer to point to each labeled object immediately after the label appears. **Stronger Test:** In recall scoring, look for correct object mentions paired with correct role/action.

## What to do instead if labels cannot be shown concurrently <!-- role: fix -->

- Add a symbol cue (e.g., arrow) that clearly indicates the labeled target at the moment the label is spoken.
- Use a short caption that includes both the name and a brief descriptor while the object is visible.
- Reduce simultaneous items by staging labels across time.
- Reposition the label nearer to the object so gaze shifts are shorter.
