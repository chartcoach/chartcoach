## The Rule <!-- role: advice -->

Remove common clutter elements (busy gridlines, heavy borders/backgrounds, excessive markers/ticks, excessive color variety, rotated text, redundant labels, 3D cues) so the data and labels remain, but the “plotting debris” does not.

## The Logic <!-- role: reason -->

Decluttering reduces non-data visual competition, making the display read as more “professional” to viewers.

- **The Principle:** Reduce non-data signal competing with the data
- **The Evidence:** In Ajani et al., decluttered designs were rated significantly more professional than cluttered designs across six topics, with no strong evidence that decluttering improved trustworthiness beyond a trend [@ajaniDeclutterFocusEmpirically2022a].

## Where to Apply <!-- role: context -->

- **User Goal:** Presenting data in professional settings; communicating rather than exploratory analysis
- **Data Type:** Common business/communication charts (bar, stacked bar, line) with multiple categories/series
- **Audience:** General audiences (e.g., students/organizational viewers)

## When to Break It <!-- role: exceptions -->

- **Scenario:** You need viewers to read values very precisely across the plot area.
- **Reason:** Removing too many reference cues (e.g., supports for value reading) can make precision harder; the paper notes declutter can trade off with precision in some cases (e.g., fewer guides for comparison) [@ajaniDeclutterFocusEmpirically2022a].

## The Price <!-- role: costs -->

- **The Sacrifice:** Some familiar “Excel-like” structure and scaffolding.
- **The Risk:** Some viewers may find the result “boring” or overly minimal, reducing subjective appeal for some audiences [@ajaniDeclutterFocusEmpirically2022a].

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Deleting supporting structure so aggressively that axes/labels become hard to interpret.
- **Why it fails:** Minimalism that impairs reading replaces clutter with ambiguity, which can reduce clarity and engagement [@ajaniDeclutterFocusEmpirically2022a].

## How to Check <!-- role: check -->

- **Visual Sign:** The chart has many competing elements: multiple bright colors, dense gridlines/ticks, thick borders, rotated labels, markers on every point, or redundant numbers everywhere.
- **The Test:** Briefly glance for 2 seconds—if your eye goes to decoration before the data pattern, it’s likely cluttered relative to the paper’s manipulated “clutter” condition [@ajaniDeclutterFocusEmpirically2022a].

## How to Fix <!-- role: fix -->

- **Quick Fix:** Remove heavy backgrounds/borders, reduce gridline/tick/marker prominence, and eliminate 3D/shadow effects.
- **Best Fix:** Rebuild the chart into a restrained, whitespace-supported layout with simpler typography and only necessary reference elements, keeping the core data and labels intact [@ajaniDeclutterFocusEmpirically2022a].
