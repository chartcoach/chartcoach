## The Rule <!-- role: advice -->

For sorting or ordering judgments on daily patterns, choose a single 24-hour linear bar chart rather than a radial rose chart.

## The Logic <!-- role: reason -->

- **The Principle:** Linear arrangements support faster comparative scanning and rank judgments than radial arrangements.
- **The Evidence:** For sort, accuracy ranks E-4 highest; time ranks E-4 fastest, with radial variants slower [@waldnerComparisonRadialLinear2020]. This is part of the broader structured evidence collation intended for recommendation rules [@zengReviewCollationGraphical2023].

## Where to Apply <!-- role: context -->

- **User Goal:** Sort/order bins (e.g., determine which hours are higher/lower).
- **Data Type:** Daily (24-hour) binned quantitative data.
- **Audience:** Non-expert users.

## When to Break It <!-- role: exceptions -->

- **Scenario:** The task is not to sort values but to convey a cyclical “day” motif without any ordering judgments.
- **Reason:** The evidence is task-specific; it supports ordering performance rather than thematic communication [@waldnerComparisonRadialLinear2020].

## The Price <!-- role: costs -->

- **The Sacrifice:** Reduced visual novelty vs radial displays.
- **The Risk:** If the chart is styled poorly, users may still struggle—but the study’s comparison indicates layout choice is a key factor [@waldnerComparisonRadialLinear2020].

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Choosing a radial rose chart to depict “cycle,” then asking users to rank/sort hours by magnitude.
- **Why it fails:** Radial designs (E-1/E-2) rank below E-4 in both accuracy and time for sort [@waldnerComparisonRadialLinear2020].

## How to Check <!-- role: check -->

- **Visual Sign:** Users take longer to answer “Which hour is higher/lower?” questions or make inconsistent rank judgments.
- **The Test:** Do a short timed sort task A/B test; linear 24-hour bars should outperform as recorded [@waldnerComparisonRadialLinear2020].

## How to Fix <!-- role: fix -->

- **Quick Fix:** Switch to a 24-hour linear bar chart.
- **Best Fix:** Encode a recommendation preference for E-4-like linear designs for sort tasks on daily patterns, aligning with the collated knowledge base framing [@zengReviewCollationGraphical2023; @waldnerComparisonRadialLinear2020].
