## The Rule <!-- role: advice -->

Create a test blueprint that cross-tabulates visualization types (contents) against visualization-reading tasks, and only write items that map to blueprint cells.

## The Logic <!-- role: reason -->

A blueprint is the explicit plan that guides item generation and supports content-validity claims; it prevents ad-hoc coverage and makes later expert review and item analysis interpretable. VLAT’s blueprint operationalizes “visualization literacy” by specifying which tasks are most suitable for each chart type and dataset type.

- **The Principle:** Blueprinting ensures content coverage and defensible validity evidence
- **The Evidence:** [@leeVLATDevelopmentVisualization2017]

## Where to Apply <!-- role: context -->

- **User Goal:** Creating or auditing an assessment (or curriculum) for chart-reading competence
- **Data Type:** Multiple visualization types; mixed dataset structures
- **Audience:** Non-experts and general-public test takers

## When to Break It <!-- role: exceptions -->

- **Scenario:** You are running a narrow diagnostic on a single chart type (e.g., only line charts).
- **Reason:** A full cross-type blueprint may be unnecessary overhead when the construct is intentionally constrained. [@leeVLATDevelopmentVisualization2017]

## The Price <!-- role: costs -->

- **The Sacrifice:** More upfront planning and documentation.
- **The Risk:** Over-structuring can tempt you to include unsuitable task–chart pairings; VLAT marks only “more suitable” intersections rather than assuming everything is possible. [@leeVLATDevelopmentVisualization2017]

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Writing many questions first, then “backfilling” a blueprint to justify them.
- **Why it fails:** It reverses the logic needed for content validity and leads to uneven coverage. [@leeVLATDevelopmentVisualization2017]

## How to Check <!-- role: check -->

- **Visual Sign:** Some chart types or tasks dominate the test without justification.
- **The Test:** For every item, confirm you can point to a single blueprint cell (chart type × task) that motivated it. [@leeVLATDevelopmentVisualization2017]

## How to Fix <!-- role: fix -->

- **Quick Fix:** Label each existing item with (chart type, task); delete items that do not map cleanly.
- **Best Fix:** Recreate the blueprint first, then regenerate items cell-by-cell (as VLAT did). [@leeVLATDevelopmentVisualization2017]
