## The Rule <!-- role: advice -->

Write a chart description that precisely states what is shown, including key qualifiers (e.g., fiscal vs. calendar periods, geography, units, and time range).

## The Logic <!-- role: reason -->

Readers did not follow your analysis process; a precise description re-establishes shared context and prevents misinterpretation about what the chart shows exactly, which Muth emphasizes as the final step after building the visuals [@muth_better_charts_2017].

- **The Principle:** First-time-reader orientation (explicit framing)
- **The Evidence:** [@muth_better_charts_2017]

## Where to Apply <!-- role: context -->

- **User Goal:** Understand the chart without guessing definitions, scope, or measurement details.
- **Data Type:** Any chart where units, time framing, selection, or scope could be misunderstood (e.g., “fiscal quarter,” “selected products”).
- **Audience:** Broad audiences, including readers unfamiliar with domain assumptions.

## When to Break It <!-- role: exceptions -->

- **Scenario:** Space is extremely constrained and the chart is embedded in a context where the description is redundantly stated immediately adjacent in the text.
- **Reason:** You may be able to shorten—but Muth’s point is that these details are easy to forget and often matter for correct reading [@muth_better_charts_2017].

## The Price <!-- role: costs -->

- **The Sacrifice:** More text and slightly more reading effort.
- **The Risk:** Overly long descriptions can feel dense and reduce scanability [@muth_better_charts_2017].

## Common Mistakes <!-- role: mistakes -->

- **The Wrong Fix:** Writing a description that repeats what the reader can already see (e.g., only “iPhone sales”) while omitting crucial qualifiers.
- **Why it fails:** Readers may assume the wrong scope (calendar vs. fiscal, complete vs. selected items, current vs. older time frame) [@muth_better_charts_2017].

## How to Check <!-- role: check -->

- **Visual Sign:** A new reader could ask “What exactly am I looking at?” (unit, scope, time frame).
- **The Test:** Have someone unfamiliar with the project answer: what, where, when, and in which units—using only the description and chart. If they can’t, revise [@muth_better_charts_2017].

## How to Fix <!-- role: fix -->

- **Quick Fix:** Add missing qualifiers (unit, geography, time range, selection note) to the description.
- **Best Fix:** Rewrite the description as a compact spec sentence (What + Unit + Breakdown + Time frame), matching Muth’s example style [@muth_better_charts_2017].
