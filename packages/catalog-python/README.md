# chartcoach

Python package and CLI for creating, loading, indexing, and serving the ChartCoach guideline catalog.

Import `chartcoach` to work with catalog records. Install `chartcoach[search]`
when you need Chroma-backed indexing and semantic retrieval.

Run the CLI with `uv run --package chartcoach chartcoach --help`.

Run the tests with `pnpm --dir packages/catalog-python test`.
